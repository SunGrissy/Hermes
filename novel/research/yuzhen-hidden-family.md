# 玉真的隐秘家庭 + 李豫线设计

> 2026.03.14 | 基于史料推演和讨论确认

---

## 一、史料基底

| 来源 | 记载 | 性质 |
|---|---|---|
| 《新唐书·公主传》 | "终身未嫁" | 正史（宋代编纂，距事件300年） |
| 出土墓志铭 | 育有二子，次子张倜官至鸿胪卿 | 正史级别（当年下葬时刻石） |

**矛盾：** 正史说她没结过婚。墓志说她有两个儿子。墓志是762年下葬时制作的，比《新唐书》（1060年）早300年，属于一手材料。

---

## 二、正史为什么隐去？——多层原因

### 第一层：道教国教面子

唐以道教为国教。玉真是"上清玄都大洞三景法师"——道教在皇室的形象代言人。一个出了家的公主有丈夫有孩子？这不是私德问题——是**国教公信力问题**。

### 第二层：张某的身份

儿子姓张。张某可能：
- **出身不够**——不是高门大户。公主的婚姻是国家工具，嫁了一个"不够格"的人 = 政治不正确。公开了对方会成为靶子
- **和某次政治风暴有关联**——也许他自己或家族在韦坚案、杜有邻案等某次清洗中被波及。这种关联一旦暴露，可以牵连玉真和整个道门
- **已经去世或远离长安**——最简单也最不分散注意力的处理

### 第三层：744年削号 = 保护家人

玉真在744年（天宝三年）主动削去公主名号、归还食邑。正史解读为"清高"。

实际推演：此时李林甫独揽大权，"交构东宫"杀人利器已经出鞘。如果玉真还顶着公主名号——她的一切关系都在聚光灯下。**削号 = 摘掉靶心 = 降低儿子被连累的概率。**

没有公主名号的"玉真道人"：
- 不在弹劾范围内
- 和她有关的人更安全——不是"公主的人"
- 儿子们以张家名义做官，不再是"公主之子"

### 第四层：墓志 ≠ 公开

墓志是刻在石头上、和棺材一起埋进地下的。活人看不到。它是写给地府的身份证明。**把"育有二子"刻进墓志，不是公开真相——是在地下留一份只有死人和石头知道的记录。**

### 第五层：宋代史官的信息缺失

《新唐书》编于1060年。宋代史官根据现有唐代官方文档编写——而官方文档从来没承认过玉真的婚育。"终身未嫁"不是762年的决定——**是300年后史官根据不完整材料延续的官方口径。**

## 三、小说中的版本——确定设定

### 张某（玉真的男人）——"卫尉张卿"

**史料线索：** 李白有诗题《玉真公主别馆苦雨赠卫尉张卿二首》——一个姓张的四品官（卫尉卿，掌宫廷仪仗武库），和李白一起住在玉真公主的私人别馆。这是目前唯一一条从同时代文献中挖出的、指向"玉真身边有一个姓张的男人"的实证。

| 条目 | 设定 |
|---|---|
| 身份 | "卫尉张卿"——卫尉卿（正四品上）。不是顶级高门，但也不是无名之辈。有实权的武官 |
| 相识 | 约710-720年代。也许在道观圈子或宫廷周边认识 |
| 关系性质 | 真心的。不是政治婚姻。玉真一生中唯一一段不是表演的关系 |
| 和李白的交集 | **李白认识他。** 在玉真别馆同住并写诗相赠。这为卷二李白线提供了一个隐秘的连接点——李白也许会在某个时刻提到"我以前在真人别馆住过，有个姓张的人……" |
| 命运 | **待定。** 也许早逝，也许远离长安。不在卷一展开 |

**733年张果老拒婚的背景：** 玄宗在开元二十一年（733）要把玉真嫁给方士张果（后来传说中的张果老），被拒绝。此时玉真很可能已有孩子。这场"提亲"也许是玉真自己操作的——找一个不可能答应的人提亲，被拒后顺理成章地"继续不嫁"，堵住哥哥再次提婚的路。一场戏。

### 儿子们

| 条目 | 长子 | 次子 张倜 |
|---|---|---|
| 年龄（746年） | 约二十多岁 | 约二十岁 |
| 身份 | 张家名义。低调 | 张家名义。后来做到鸿胪卿（正四品上） |
| 和玉真的关系 | 不公开。通过沈姑姑或道门网络间接联系 | 同左 |
| 婚姻 | 待定 | **娶蔡国公主幼女尚简**——蔡国公主是睿宗之女，即玉真的姐妹。这是亲上加亲：皇室知道张倜的身世并安排了这桩婚事。公开的秘密 |
| 在长安的存在 | 极隐蔽 | 鸿胪卿掌管外国使节接待——安禄山入朝时他在接待方 |
| **最终命运** | 待定 | **肃宗上元年间（760-761）被流放岭南，卒于岭南** |

### 张倜铭文的沉默

《九华观尚简道师铭》记载了张倜是玉真次子、娶蔡国公主幼女。但按唐代惯例应有的父系世系介绍——**父亲的名字、爵位、职衔——全部没有。** 刻意省略。刻铭文的人知道父亲是谁，但不能写。

### 玉真保护李亨 → 李亨流放张倜——全书最深的背叛

**玉真对李亨做了什么：**

从韦坚案（746）到安史之乱（755），玉真观是太子一家极少数安全的避风港。正月来拜年不是"交构东宫"——是去看老姑母。在李林甫的绞杀机器把李亨身边的人一个一个碾碎的十年里，玉真：

- 提供了一个不会被弹劾的安全空间
- 看着韦妃被休、杜良娣被废、王忠嗣被夺兵权——她无法阻止，但她让道观的门一直开着
- 也许通过暗线为李亨传递过信息、提供过庇护
- 看着李豫从孩子长成沉默的青年——她照看了这个侄孙

**李亨做了皇帝后对张倜做了什么：**

肃宗上元年间（760-761），张倜因某事被流放岭南。死在那里。铭文没说原因。

玉真762年去世——**在知道儿子被流放之后。** 也许在知道儿子死在岭南之后。

她花了几十年保护侄子和侄子的家人。侄子做了皇帝，流放了她的亲儿子。

**这不一定是李亨有意的恶。** 也许张倜确实卷入了肃宗朝的某次政治风暴（张皇后/李辅国乱政期间极不稳定）。也许李亨不知道或不记得张倜是姑母的儿子——这个秘密藏了太久了。也许他知道，但在皇帝和姑母之间选择了皇帝。

但对玉真来说——**结果是一样的。她保护的人碾碎了她保护的另一个人。**

这是全书最深的结构性悲剧。不是某个坏人做了坏事——是帝国的齿轮不分亲疏。谁站在齿轮边上谁就会被碾到。玉真一辈子试图让自己的人远离齿轮。最终没有一个人逃得掉。

### 和鱼的共振

- 玉真在"壳"里活了几十年——她的"壳"是自己选的
- 鱼在一个不是自己的身体里活——她的"壳"是命运给的
- 两个人都在表演。都在隐藏真实的自己。这是她们之间最深的连接
- 玉真对鱼说"不要怕"的时候，也许有一层她自己都不知道的投射——她想对自己说但一直没说出口的话
- **鱼不是玉真的亲人——是余家的姑娘。** 她们之间没有血缘。但玉真对鱼的关注里也许有一层隐秘的投射：一个不能公开照看自己孩子的女人，在照看别人的孩子时格外用力
- 俄狄浦斯闭环的另一层：鱼的行动最终"完成了历史"——历史中包括李亨成为皇帝、张倜被流放。**鱼帮助了一个会碾碎玉真儿子的人走上皇位。** 她不知道。玉真也不知道。没有人知道

### 卷一种子（已埋）

| 位置 | 内容 | 读者体验 |
|---|---|---|
| **Ch1 Section四** 太子拜年 | 随从中"一个年轻些的，没佩刀，眼睛低着"——这是李豫 | 第一遍：无感。一个随从而已。回头看：那就是后来的皇帝 |
| **Ch2 Section一** 金仙观散步 | 回廊拐角小室——茶具洗过，蒲团没灰。一间"已故之人"的道观里有人在用的空间 | 第一遍：也许是维护人员？回头看：那是儿子来看母亲的地方 |

### 卷二—三可埋的种子

| 时机 | 可能的内容 |
|---|---|
| 鱼在余懃家做客时听到老夫人提到"张家" | 一笔带过。老夫人认识很多人。不特别 |
| 鱼在后宅送货时遇到一个姓张的年轻官员 | 也许就是张倜。鱼不知道他和玉真的关系。一面之缘 |
| 玉真某次谈话中提到"有人帮我办了一件事" | 不说是谁。鱼不追问 |

### 卷三揭示时机（建议）

安禄山754年最后入朝时，鸿胪寺负责接待。如果鱼的情报线触碰到鸿胪寺的信息——她也许会发现"鸿胪卿姓张"。然后某个时刻，信息拼在一起了。

揭示不需要一个"啊原来如此"的大场面。也许就是鱼在某个夜晚回想金仙观回廊里那间小室的干净茶具——忽然明白了。

## 五、李豫线设计

### 基本设定

| 条目 | 内容 |
|---|---|
| 初名 | 李俶（后改名李豫） |
| 生年 | 726/727年 |
| 746年 | 18-19岁。广平郡王 |
| 父亲 | 太子李亨 |
| 生母 | 吴氏（地位不高） |
| 养母 | 韦妃（746年韦坚案中被迫离婚） |
| 性格 | 在学习沉默的少年→安静得不像皇孙。不是怯懦——是精确的自保 |

### 746年韦坚案对他的冲击

韦妃是养大他的人。746年正月她被迫离婚——四个孩子（两子两女）和母亲分离。

李豫19岁。看着养母被从身边撕走。不能哭。不能求。不能说一个字。

### 和玉真的关系——被保护者的儿子

- 玉真观是太子一家极少数安全的避风港。正月来拜年不是"交构东宫"——是去看老姑母
- 李豫从小跟着父亲来。见过玉真。也见过小满。玉真看着他长大
- **玉真保护了他的父亲和他的家人十年。** 韦妃被休时也许是通过玉真的渠道安排了去处。王忠嗣出事时也许是玉真在暗中传递消息。李豫不一定知道这些——但他父亲知道
- **他的父亲做了皇帝后，流放了玉真的亲儿子。** 李豫762年即位时，张倜也许已经死在岭南了
- **他允许了墓志上的真相——也许是补偿。** 他父亲对姑母做的事，他无法挽回。但他可以让石头记住她的儿子。这是一个新皇帝对姑祖母一生亏欠的、唯一能给的、极微小的偿还

### 在小说中的轨迹

| 阶段 | 存在方式 |
|---|---|
| **卷一** | Ch1随从中一个低头的年轻人。之后不出场 |
| **卷二** | 不出场或极微量存在（通过太子线间接提及） |
| **卷三** | 也许在安禄山入朝场合中以"广平郡王"身份出现——鱼不认识他 |
| **卷四** | 安史之乱。天下兵马元帅。收复两京。**从沉默者变成行动者** |
| **番外/尾声** | 762年。皇帝。玉真去世。他默许了墓志上的真相 |

### 和鱼的回响

鱼和李豫是同龄人（鱼穿越时15，李豫19）。他们在故事的两端——一个在学说话，一个在学不说话。一个从零开始建身份，一个把身份压缩到接近零。

卷四他们也许会正面相遇。到那时候鱼也许会想起正月初一那个低着头的年轻随从。

但更有力的是：她想不起来。她从来没有注意过他。一个未来的皇帝曾经从她眼前走过，她连一个多余的念头都没给过他。

**这就是天宝——所有人都在看别的方向。没有人知道谁会活到最后。**

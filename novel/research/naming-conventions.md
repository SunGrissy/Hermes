# 唐代称谓规范（天宝年间）

> 写作用参考。所有对话和内心独白中的称谓必须遵循本文档。
> 2026.03.15 初稿

## 一、绝对禁止（影视剧常见错误）

| ❌ 禁用 | ✅ 正确用法 | 说明 |
|---|---|---|
| "父皇" | 阿耶 / 圣人 | 唐人不用"父皇"。私下叫阿耶，正式场合称圣人 |
| "母后" | 阿娘 | 同上 |
| "大人"称官员 | 姓+官职（李相、杨中丞） | 唐代"大人"仅指父母，绝不用于官员 |
| "万岁"日常叫 | 圣人 / 陛下 | "万岁"仅限重大典礼山呼 |
| "道姑" | 女冠 | 正统道教无"道姑"一词 |
| "老爷""夫人" | 阿郎 / 娘子 | 明清用法，唐代不用 |
| "爹""爹爹" | 阿耶 / 耶耶 | "爹"字唐代罕见，宋元以后才成主流 |
| "奴才""奴婢"自称 | 某 / 奴 / 儿 | "奴才"是清代满族用法 |
| "小女子" | 儿 / 奴 / 某 | 女性自称用"某"（最常见）或"儿"（对长辈） |

**道门专用称谓：**
- **炼师**：对有修为的道士/女冠的尊称。如称李含光为"李炼师"
- **真人**：最高道门尊号。玉真的全称是"上清玄都大洞三景法师"，日常只叫"真人"
- **法师**：正式的道教教职称谓
- **女冠**：唐代女道士的通称（因戴黄冠得名）

## 五、市井 / 社交称谓

### 排行称呼（唐代最显著的特色）

唐代人极重排行，几乎所有场合都可以用"姓+排行"或"排行+郎/娘"相称。

| 格式 | 示例 | 适用 |
|---|---|---|
| 排行+郎 | 三郎、五郎 | 男性，亲切 |
| 排行+娘 | 七娘、大娘 | 女性，亲切 |
| 姓+排行 | 元九（元稹）、杜二（杜甫） | 文人/朋友圈 |
| 排行+兄/弟 | — | 同辈间 |

## 七、写作注意事项

1. **"某"是万能自称。** 不确定时用"某"，男女皆可，从皇帝到百姓都用。
2. **避讳规则从简。** 玄宗名"隆基"，严格说"隆"字要避，但本书不做过度避讳处理（会损害可读性）。只在特定场景中体现即可。
3. **叙述语言 vs 对话语言。** 叙述者（全知视角）可以用"父亲""母亲"等书面词。对话和内心独白必须用口语体（阿耶、阿娘）。
4. **鱼的特殊情况。** 鱼失忆后不记得称呼习惯，但身体会自动用出正确的词。"阿耶"从她嘴里出来时，她自己会觉得这个词"对"但不知道为什么。这是身体记忆的一部分。
5. **"姑姑"在唐代。** 可以泛指年长女性（非血亲），沈姑姑的"姑姑"属于此用法，不改。
6. **三叔的称呼。** 三叔是走丝路的粗人，说话直，可能混用"你阿耶"和偶尔的"二哥"。不需要百分百统一——口语允许灵活。

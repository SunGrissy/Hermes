# 写作原则——创作铁律

> 从两次审查中提炼。所有章节初稿完成后、交付前，必须对照本文件逐条检查。

---

## 一、身份弧线：鱼不知道自己是穿越者

**这是全书最底层的规则。违反即崩塌。**

鱼的记忆被彻底清除。她没有"前世"的记忆。她有现代人的思维方式（分析、交叉比对、读人）但不知道这些能力从哪来。她真心认为自己是"除夕发作后严重失忆的余小满"。

### 禁止出现的措辞（鱼的视角/内心独白中）

| ❌ 禁用 | ✅ 替代 | 理由 |
|---|---|---|
| "穿越以来" | "醒来以后" / "发作以来" | 她没有"穿越"这个概念 |
| "这具身体" | "身体" | "这具"暗示身体不是她的 |
| "原身" | "发作之前的自己" / "以前的自己" | "原身"是穿越者术语 |
| "人设" | 不用 | 现代网络用语 |
| "不是她的手/心跳/身体" | "手很陌生" / "说不清为什么" | 陌生感 ≠ 否认所有权 |
| "住在这副骨头里" | 不用 | 明确的外来灵魂视角 |
| "她只是住在了……" | 不用 | 同上 |
| "不是他侄女/不是小满" | "记不清" / "答不上来" | 她IS小满（在她的认知中） |
| "不需要演的人" | "不需要她'记得'什么的人" | 她不在"演"——在补记忆空洞 |

### 身份认知的螺旋上升

| 阶段 | 章节 | 鱼怎么理解自己 | 裂缝给谁看 |
|---|---|---|---|
| "我是失忆的小满" | Ch1-2 | 工作假设，完全相信 | 读者（隐约）、玉真（简体字） |
| "身体记得脑子不记得" | Ch2-3 | 纸册天赋强化了小满身份 | 读者 |
| "我的脑子有点不一样" | Ch3-4 | 分析能力过强，她归因为"也许发作改变了什么" | 三叔（"你靠算"）、沈姑姑 |
| "我身上在发生我解释不了的事" | Ch3-4 | 通感无法用"失忆"解释 | 鱼自己开始不安 |
| "有人说我身上的东西不是长出来的" | Ch5 | 先生的判断。鱼被戳中但没有框架理解 | 先生、玉真 |
| "我不需要知道我是谁" | Ch5-7 | 实用主义接受。身份焦虑退居后台 | — |

**每次写鱼的内心独白时自问：她此刻处于哪一级？这个想法/措辞是否越级了？**

---

## 二、每章必须有事件——"稳不是戏"

**氛围、质感、观察、感悟都不是"事件"。事件 = 主角被迫做出有风险的选择。**

### 每章检查清单

| # | 检查项 | 不通过的症状 |
|---|---|---|
| 1 | **本章鱼做了什么有风险的选择？** | "她观察了/感受了/存了/记住了"——全是被动 |
| 2 | **本章有谁在给鱼制造压力？** | 全章没有对手/障碍/意外 |
| 3 | **本章结束时鱼的处境和开头有什么不同？** | 如果答案是"没变"，这章就是过渡——过渡在第三章出现太早 |
| 4 | **读者在章末有什么具体的问题想知道答案？** | "写得真好"但不急着翻下一页 = 没有钩子 |
| 5 | **把本章的观察/感悟全删掉，还剩什么？** | 如果剩下的撑不起一个段落，这章缺骨头 |

### "散文"vs"戏"的判断标准

| | 散文 | 戏 |
|---|---|---|
| 结构 | 主角感受世界 | 世界对主角做了一件事，主角必须回应 |
| 读者状态 | "写得真好" | "她会怎么办？" |
| 信息流向 | 主角→内心 | 外部→主角→选择→后果 |
| 功能 | 建立氛围（辅料） | 推动情节（主菜） |

**一章可以有散文段落，但不能整章都是散文。每章至少一个"戏"——一个外部力量逼迫鱼做选择的时刻。**

## 三、能力必须被戏剧化地测试

**"鱼很聪明"不能靠叙述——必须靠场景。**

### 反面示例

> 她记住了每一个客户的习惯。"穿蓝袍那个要好纸。""赵先生只要剡藤纸。"

这是叙述。读者被告知鱼很能干。但读者没有**亲眼看到**她在压力下运用这种能力。

### 正面示例

> 有人拿了一批纸来问真假。鱼摸了一下："不对。纤维是仿的。"对方脸色变了。第二天刘老板来说你得罪的那个人背景不简单。

读者亲眼看到了能力→选择→后果。这才是"展示"。

### 规则

**每一种核心能力（辨纸、读人、分析、通感）在首次出场时，必须通过一个有对手或有风险的场景来呈现。** 日常运用可以之后再写——但第一印象必须是"在压力下展示"。

---

## 四、政治天气必须落到主角身上

**"这座城在怕什么"不能只是鱼的旁观感悟——必须让恐惧具体地碰到她。**

### 反面示例

> 三叔说王忠嗣被免了。鱼存了这条信息。

信息被鱼存了。然后呢？这条信息对她的生活有什么影响？如果没有——它就只是背景板。

### 正面示例

> 鱼去送货。到了才发现那家封了。管事的跑了。她手里两刀纸没人收。货款也拿不到了。
> 
> 三叔回来时她说了这事。三叔的脸变了："哪家？"——听完之后沉默了很久。然后说了句："以后送货之前先打听一下那家还在不在。"

政治恐怖从"新闻"变成了"我今天白跑了一趟、亏了两刀纸的货款"。**落在主角身上的天气才是天气。**

---

## 五、关系必须有摩擦

**没有摩擦的关系是散文，不是戏。**

两个人相处愉快、互相理解、温暖收场——这不是关系发展，这是读后感。关系发展需要**碰撞**。

| 类型 | 散文版 | 戏版 |
|---|---|---|
| 鱼和杜甫 | 他来买纸，说了几句感人的话，走了 | 他说的某句话碰到了鱼不想面对的东西。鱼的反应让他也停了一下。两个人之间多了一根看不见的线 |
| 鱼和三叔 | 三叔很支持她，她很感激 | 三叔说了句"你靠算"——鱼听出了言外之意：**你不像你阿耶。** 这到底是夸还是什么？ |
| 鱼和玉真 | 玉真在观察她，她感到被注视 | 玉真做了一个鱼看不懂的决定。鱼第一次意识到：这个人在下棋，而自己可能是棋子 |

**每段关系每次出场，至少要推进一步——要么更近，要么更远，要么揭示了新的层面。原地踏步 = 废笔。**

---

## 六、通感必须有外部后果

**通感不是"内心体验"——它必须在鱼的现实世界留下痕迹。**

| 级别 | 内部体验 | 外部后果 |
|---|---|---|
| ½ (Ch2 法事) | 极微弱的"场"变化 | 无（合理，太弱了） |
| 1 (Ch3 凉州曲) | 沙、马蹄、铁锈天空 | **必须有：** 打翻了什么 / 被人看到异常 / 掌心破皮后被三叔追问 / 第二天手抖影响了裁纸 |
| 2 (Ch4 郁轮袍) | 过载、哭、站不住 | 被扶到侧室。玉真走进来。"你看到了什么？" |
| 3 (Ch7 识谎) | 情绪质地不匹配 | 做出正确判断——第一次"有用" |

**规则：通感强度 ≥ 1 时，必须至少有一个外部后果（物理的、社交的、或商业的）。纯内心体验 + 回家手抖 = 不够。**

---

## 七、伏笔必须锚定具体物件或具体人

**抽象的伏笔（"她觉得不安"）读者记不住。具体的伏笔（一张不对的纸、一枚铜钱、一幅字）读者忘不掉。**

| ❌ 抽象 | ✅ 具体 |
|---|---|
| "鱼觉得长安在变" | 胡饼摊每天少卖二十个——鱼数过 |
| "政治气氛紧张了" | 一个客户的名字从账本上消失了 |
| "三叔提到范阳不太对" | "安大帅练兵——练什么兵要那么多粮？"——三叔原话，鱼存了 |
| "通感让她不安" | 掌心一道浅疤——攥刀留的。三叔问了一次她没答 |

**每个伏笔必须挂在一个读者能"看到"的东西上。**

---

## 八、章末必须有钩子

**章末不是情绪收束——是问题打开。**

| ❌ 散文式结尾 | ✅ 钩子式结尾 |
|---|---|
| "壳子还在。壳子里面的人开始动了。" | "壳子还在。壳子里面的人开始动了。" + **前一段是"这座城在怕什么"** |
| "她在这个世界已经快一年了。" | 她回到观里——偏院住了一个脸色发灰的陌生女人。沈姑姑："别问。" |
| "手在被子底下还在抖。" | 手在抖——然后有人敲门。三叔："小满，你手怎么了？" |

**规则：每章最后 200 字必须包含一个读者想知道答案的具体问题。不是情绪——是问题。**

---

## 九、称谓零容忍

详见 `research/naming-conventions.md`。以下是最高频的错误提醒：

- "爹" → **阿耶**
- "父皇" → **阿耶 / 圣人**
- "大人"称官员 → **姓+官职**
- "道姑" → **女冠**
- "老爷/夫人"（明清式） → **阿郎/娘子**

**每次写对话前花三秒想：这个人在唐代会怎么叫对方？**

## 十、密度标尺

| 指标 | 最低要求 |
|---|---|
| 每章字数 | 5,000—10,000 中文字 |
| 每章事件数 | ≥ 1 个有风险的选择 |
| 每章新信息 | ≥ 1 个改变鱼处境的外部事实 |
| 每章关系推进 | ≥ 1 段关系发生了不可逆的变化 |
| 每章伏笔 | ≥ 1 个挂在具体物件/人上的种子 |
| 每章钩子 | 最后 200 字必须包含一个具体问题 |
| 鱼的主动选择 | ≥ 1 个（不能全章被动） |
| 鱼的能力展示 | 至少 1 次在压力下的运用（不是日常运用） |

---

## 使用方式

1. **初稿完成后**：对照第二节"每章检查清单"逐条过
2. **修改时**：重点检查"事件是否存在""选择是否有风险""结尾是否有钩子"
3. **每次写对话前**：查称谓规范
4. **每次写鱼的内心独白时**：检查身份弧线——她此刻在第几级？措辞是否越级？

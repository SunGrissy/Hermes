### 732年 · 开元二十年 · 金仙公主去世 `[史]`

五月。金仙公主卒于洛阳开元观。享年44岁。

|---|---|---|
| **金仙** | 洛阳 | `[虚]` 通感持续燃烧二十余年。窗大墙薄。最终承载不住，灯灭了 |

#### 746年正月 · 韦坚案 `[史]`

> **这不是一次冲突——是两年布局+精确触发+赢者通吃的政治歼灭战。**

**前史：明升暗夺（744年）。** 韦坚在742年任水陆转运使后，控制了漕运——帝国的财政命脉。李林甫不正面打压，用"升为刑部尚书"的方式**剥夺了转运使实权**。名升实降。转运使职掌交给了杨慎矜（李林甫的打手）。从此漕运/财政体系在李林甫手里。

**监视（744-746年初）。** 杨慎矜受命监视韦坚。两年间记录了韦坚的交游——和左相李适之的来往、和皇甫惟明（河西节度使）的友谊、和太子通过韦妃的血缘联系。**这些本身不是罪——但在李林甫手里是一堆等待被点燃的柴。**

**触发：上元节（正月十五）。** 太子李亨微服出游。街上**碰到了韦坚**（也许巧合，也许被安排）。**同一个晚上**，韦坚和皇甫惟明在一个商人家喝酒。杨慎矜全程在场或有人盯梢。

**这不需要真的有密谋。** 三条线在同一个晚上交汇——太子+妻兄+边将——这幅画面本身就够了。李林甫拿着这幅画面去见玄宗：**"韦坚与皇甫惟明交构东宫。"** 四个字。对一个杀过三个亲儿子的六十一岁皇帝来说，"也许"等于"一定"。

| 人物 | 位置 | 反应/变化 |
|---|---|---|
| **唐玄宗** | 长安 | 亲自审问太子，确认太子无罪——**但允许李林甫处置韦坚和皇甫惟明。** 这是他的标准操作：查太子查不出问题，但仍然要杀太子身边的人——"我相信你是清白的。但你身边的人不清白" |
| **李林甫** | 长安 | 让杨慎矜告发。**两年布局在这一刻兑现。** 他不只是要杀韦坚——要一次性清除太子身边所有支撑 |
| **韦坚** | 长安→贬缙云→再贬江夏→流放岭南 | 全族被灭。弟韦兰、韦冰、韦芝和长子韦谅被杀。家产籍没。**李林甫令江淮地方搜集"证据"，株连无数人，甚至有人裸死狱中** |
| **皇甫惟明** | 长安→贬播州 | 贬出朝廷。**747年正月被罗希奭追至贬所赐死。** 他的罪不只是和韦坚喝酒——他曾当面向玄宗建议罢免李林甫。直接触了逆鳞 |
| **左相李适之** | 长安 | 和韦坚有交往→主动请辞→**被贬宜春太守→在恐惧中服毒自杀。** 其子李适被杖杀。**从此朝中再无左相——李林甫独相** |
| **太子李亨**（35岁） | 东宫 | **被迫休掉太子妃韦氏**（已有两子两女，包括长子李豫/未来的代宗）。四个孩子与母亲分离。他身边的支撑被一次性清除：妻族灭了、朝中盟友死了、军方靠山杀了。只剩一个空壳太子 |
| **韦妃** | 东宫→出家为尼 | 被休。出家为尼。**娘家满门被灭——她连"回娘家"都不可能了。** 从太子妃到尼姑。`[推]` 也许在长安某座尼寺。也许玉真通过某种渠道照看过她 |
| **李豫**（19岁） | 东宫 | `[推]` 看着养母被撕走。四个孩子（他+三个弟妹）与母亲分离。**不能哭。不能求。不能说一个字——说了就是"交构东宫"** |
| **高力士** | 宫中 | `[推]` 看着他当年推上太子位的人被一刀一刀剜。不能出手。"交构东宫"是死罪——连皇帝最信任的人都不敢保护太子 |
| **杨慎矜** | 长安 | **此案第一功臣。** 告发者+证人+李林甫的打手。因此获得更大的信任和权力——但等他自己坐大了，李林甫会用同样的方式灭掉他（747年杨慎矜案） |
| **王鉷** | 长安 | 此案中角色较小。但**漕运/财政体系的最终受益者是他——到748年他兼领20余使职**，掌管全国财税 |
| **杨国忠** | 长安 | 此案中角色较小。在旁观察。在等 |
| **罗希奭** | 长安→各地 | **执行者。** 后来沿途追杀被贬的韦坚、皇甫惟明等人。"从青州一路杀到岭南" |

**李林甫一方通过此案获得的利益：**

| 获得什么 | 具体内容 |
|---|---|
| **财政命脉** | 转运使在744年已夺给杨慎矜。韦坚死后翻盘无望。最终王鉷接手→掌控全国财税 |
| **独相** | 左相李适之自杀后再无人制衡。李林甫成为唯一宰相——唐代罕见 |
| **太子孤立** | 李亨妻族灭了、朝中盟友死了、军方靠山杀了。**从此没有任何人敢和太子走近** |
| **边将换血** | 皇甫惟明被杀后，河西/陇右节度使换了更听话的人 |
| **恐怖信号** | "交构东宫"四个字成了悬在所有人头顶的刀。**从此整个朝堂被恐惧统治** |

| **玉真**（~54岁） | 长安·玉真观 | `[推]` 她的侄子（太子）被剜掉了第一块肉。韦妃——正月初二来道观拜年、蹲下来给小满压胜钱的那个女人——被休了、出家了。**"交构东宫"是死罪——任何和太子扯上关系的人都会死。正常渠道全死了。也许这是她决定更积极运作暗线的转折点** |
| **先生** | 茅山 | `[推]` 通过道门网络知道长安出了大案。朝堂的空气在变 |
| **鱼**（刚穿越半个月） | 玉真观 | 观中气氛骤变。不知道发生了什么。**但她记得那个给她铜钱的女人——那个女人再也没有来过** |
| **清漪** | 玉真观 | `[推]` 感受到观内气氛紧张。有些常来走动的官员夫人不来了。新面孔出现了 |
| **杜甫**（34岁） | 长安 | `[推]` 在长安街头求生。所有人在低声议论 |
| **王维**（45岁） | 长安/辋川 | `[推]` 沉默。辋川的墙又厚了一层 |
| **李白**（45岁） | 江南漫游 | 不在长安。但消息会传到他耳中 |

#### 746年十一月 · 杜有邻案 `[史]`

鱼穿越后约两个月。她还在适应这个世界。外面就爆发了天宝最血腥的案件之一。

| 人物 | 位置 | 反应/变化 |
|---|---|---|
| **唐玄宗** | 长安 | 下令处置。告密者柳勣和被告者杜有邻**一起被杖毙**——说明他知道案子有问题但不追究 |
| **李林甫** | 长安 | 让王鉷+杨国忠联手审讯——**两个未来的死敌第一次公开合作** |
| **杜有邻** | 长安 | **杖毙。** 罪名："妄称图谶，交构东宫" |
| **柳勣**（告密者） | 长安 | **也被杖毙。** 告密者和被告一起死——这案子的荒谬之处 |
| **太子李亨** | 东宫 | **半年内第二次失去女人——杜良娣被废为庶人。** 36岁的他身边只剩张良娣 |
| **王鉷** | 长安 | 作为审讯者走上前台。**第一次展现他的"双料工具人"价值** |
| **杨国忠** | 长安 | 和王鉷联手。在李林甫体系中积累了更多资本 |
| **罗希奭** | 长安→各地 | 天宝六年正月（747年初），受命追杀此前被贬的韦坚、皇甫惟明等——在贬所赐死或杖杀 |
| **李邕**（74岁·北海太守） | 北海→被杖杀 | 被牵连进杜有邻案。74岁的老人被杖杀 |
| **李适之**（前左相） | 贬所 | 在恐惧中服毒自杀。其子李适被杖杀 |
| **玉真** | 玉真观 | `[推]` 长安在杀人。"图谶"成了死罪。她收留着道门的谶语秘密和一个刚"醒来"的异人——**她坐在两颗炸弹上面。** 但她不退缩。她开始更认真地观察鱼——"这个人到底能做什么？" |
| **鱼**（穿越后~2个月） | 玉真观 | `[推]` 还在学习用这具身体活着。但她已经感受到了观内气氛的变化——人们在低声说话，有人在哭。她不知道发生了什么，但她的分析本能在后台运转：**"这个地方在怕什么"** |
| **清漪** | 玉真观 | `[推]` 对外部消息比鱼敏感得多。她知道杜有邻案的大概。她的第一反应是："不要出事。现在千万不要出事" |
| **先生** | 茅山或赶往长安途中 | `[推]` "图谶"成了杀人的罪名——**如果有人知道道门有谶语传承……** 他更急着来长安了。不是为了谶语——是为了那个女孩。"灯还在吗？" |
| **杜甫** | 长安 | `[推]` 杜有邻姓"杜"。杜甫的族兄弟杜位是李林甫的女婿。整个"杜"姓在长安此刻是敏感的。杜甫在底层——没人注意他。但他看到了一切 |

**"图谶"这个词从这一刻起成了长安上空的一把刀。** 任何涉及预言、天命、未来的言论都可以致死。道门的谶语传承——在这个语境下——是一份灭门的罪证。

### 747年 · 天宝六年

#### 正月 · 追杀收尾 `[史]`
罗希奭受命追杀此前被贬的韦坚、皇甫惟明、李邕、裴敦复——赐死或杖杀。

#### 年中 · "野无遗贤" `[史]`
科举无一人录取。李林甫对玄宗说"野无遗贤"。**杜甫参加了这次科举——交了白卷或写了但无用。**

#### 年中 · 王忠嗣案 `[史]`
王忠嗣——四镇节度使，唐代最能打的将领，太子李亨的童年好友——被诬告"欲拥兵尊奉太子"。夺兵权，贬为汉阳太守。

| 人物 | 位置 | 反应/变化 |
|---|---|---|
| **唐玄宗** | 长安 | 夺了最能打的将军的兵权。`[推]` 也许他心里知道王忠嗣是冤的——但王忠嗣说过"以数万命换一城不值"，这句话让他不高兴 |
| **李林甫** | 长安 | 指使魏林诬告。目标仍然是太子——剪掉最后一个有兵权的太子友人 |
| **太子李亨** | 东宫 | 从小一起长大的兄弟被夺了兵权。`[推]` 他身边现在**一个人都没有了** |
| **哥舒翰** | 陇右 | **接替了王忠嗣的位置。** 两年后（749年）他会用数万人命攻下石堡城——正是王忠嗣拒绝做的事 |
| **鱼**（穿越后~1年） | 玉真观 | `[推]` 在观中逐渐站稳。开始帮玉真做简单的事务——也许是整理文书、陪同出席某些场合。她的分析能力在不自觉中显露。玉真在观察 |
| **玉真** | 玉真观 | `[推]` 帝国最能打的将军被废了——边防出了洞。她也许是长安最早意识到"东北方向不对劲"的人之一。同时她在测试鱼——给她一些小事做，看她怎么处理 |
| **清漪** | 玉真观 | `[推]` 开始发现鱼"不一样了"——不是变笨了，是**变聪明了**。以前的小鱼不会用这种方式看人、这种方式说话。清漪心里画了一个问号 |
| **王维** | 长安 | `[史]` 这一年迁为库部员外郎。稳步升迁。沉默如常 |

#### 十一月 · 杨慎矜案 `[史]`

李林甫灭掉了自己曾经的打手。**卢铉袖藏谶书栽赃——中国历史上最著名的栽赃现场。**

| 人物 | 位置 | 反应/变化 |
|---|---|---|

| **王鉷** | 长安 | **主要构陷者。** 从杨慎矜的合作者变成了灭他的人——李林甫挑拨了他们 |
| **杨国忠** | 长安 | 参与告发。秦国夫人（杨贵妃的姐姐）是这案子的信息传递者——杨家的后宫线在此案中发挥了作用 |

| **秦国夫人** | 宫廷/长安 | 从宫中获知"明珠"事件→告诉杨国忠→触发了整条告发链。后宫→外廷的信息通道 |
| **杨慎矜** | 长安→自缢 | 三兄弟自缢。全族流放 |
| **先生** | `[推]` 长安或茅山 | **"谶书"被用来灭人全族。** 这对道门的威胁是存在性的。如果朝廷对所有"谶书"进行彻查…… 先生此刻的判断：`[推]` 必须更加小心。谶语传承不能有任何泄露的可能。但同时——鱼的存在越来越像谶语描述的模式。最危险的时刻和最重要的时刻重叠了 |
| **玉真** | 玉真观 | `[推]` "谶书"灭族——她收留着道门的谶语+一个谶语可能的应验者。她比以前更清楚地知道自己坐在什么上面。但她不退。**她已经看到了鱼的潜力——这把刀值得冒险** |
| **鱼**（穿越后~1年） | 玉真观 | `[推]` 也许在这段时间她第一次在一次后宅社交中帮玉真做了一件事——分析了某位夫人话中的矛盾，提取了一条别人没注意到的信息。玉真看到了。"她能做这个" |

**`[推]` 鱼在某次任务中触碰到了一条指向杨慎矜案真相的线索——也许是一笔不对劲的钱、一个人的不合理行踪、或一份文书的异常。她把它交给了玉真。玉真通过某种渠道将信息传了出去——最终到了赵奉章手里，成为二十条罪状中的一条。**

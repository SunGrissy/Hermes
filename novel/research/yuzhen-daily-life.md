# 玉真的称谓、日常节奏与道门年节

> 2026.03.15 | 基于道教文献、唐代礼制、历史考证综合推演

## 一、谁叫她什么——称谓分层

### 称谓总表

| 称呼者 | 称呼 | 场合 | 说明 |
|---|---|---|---|
| **观内女冠、丫鬟** | **真人** | 日常 | 最通用。唐代对道行高深者的尊称。观内上下一律叫"真人"，不带姓——直接说"真人"即可，如"真人说让你好好歇着"（第一章已用） |
| **沈姑姑** | **真人** | 当着人 | 公事公办。和其他人一样叫"真人" |
| **沈姑姑** | 也许偶尔叫**公主** | 极私密时 | 老人之间的旧称。沈姑姑跟了玉真几十年，在只有两人的时候也许还是会说"公主"。这是她们之间的私人纽带——"真人"是对外的，"公主"是留在旧日子里的 |
| **鱼（穿越初期）** | **真人** | 跟着别人叫 | 身体的惯性——原身叫了两年"真人"。鱼不知道为什么这么叫，但嘴会自动说 |
| **鱼（站稳后）** | **真人** | 在人前 | 正式场合不变 |
| **鱼（和玉真独处）** | 也许什么都不叫 | 两人之间 | 鱼慢慢发现在只有两人时，她可以不加称呼直接说话。玉真没有纠正。这本身就是一种亲近——在这个等级森严的世界里，"不需要叫名字"比"叫什么名字"更亲密 |
| **清漪** | **真人** | 始终 | 清漪永远用标准称呼。她比任何人都在意这种分寸 |
| **太子李亨** | **姑母** | 私下 | 他是玉真的亲侄子。正月拜年时叫"姑母"或"姑姑"。有时也许恭敬地叫"姑真人" |
| **韦妃** | **姑姑** | 私下 | 比太子松一些。她的温暖体现在称呼的随意上 |
| **李豫** | **姑祖母** 或 **姑真人** | 拜年时 | 晚辈。极正式。也许磕完头起来后就不再单独开口了 |
| **尚简（侄女/秘密儿媳）** | **姨母** | 来访时 | 公开身份。蔡国公主之女看姨母。"姨母"两个字在她嘴里也许比平常人叫的轻——沈姑姑也许注意到了，也许没有 |
| **张倜（外甥女婿/秘密次子）** | **姨母** 或 **真人** | 极少来 | 在场合中一定叫"真人"。也许在金仙观那间小室里叫"姨母" |
| **先生（李含光）** | **公主** 或 **持盈** | 私下 | 他们是对等的人。先生不叫她"真人"——那太客套了。他也许叫她的本名"持盈"（李持盈），或者直接叫"公主"。这种叫法在观里其他人面前不会出现——是两人之间的旧交情 |
| **外部文人** | **玉真公主** 或 **玉真真人** | 社交场合 | 虽然 744 年削号，但"玉真公主"的名号太响了——没有人真的改口。正式提及时说"玉真真人"或"玉真法师"。私下还是说"玉真公主" |
| **皇帝（玄宗）** | **妹** 或 **持盈** | 如有对话 | 亲兄妹。但天宝年间两人见面已极少 |
| **道门内部** | **大洞法师** 或 **三景法师** | 道门正式场合 | "上清玄都大洞三景法师"是她的全称法号。日常简称"大洞法师"。只在极正式的道门内部场合使用 |
| **朝廷公文** | **玉真长公主** | 削号前 | 744年削号后公文中不再出现。但宫中人提起时还是说"玉真公主" |

### 关于"道长"

**唐代不用"道长"这个称呼。** "道长"是后世（主要是明清以后）教外人士对道士的泛称。唐代的正式尊称是**真人、法师、先生、炼师**。写作中避免使用"道长"。

### 关于"道姑"

**正统道教中没有"道姑"这个称呼。** 这是后世民间的俗称。唐代正式称呼女道士为**女冠**（因戴黄冠而得名）。

### 称谓的叙事功能

- **"真人"是玉真观的呼吸。** 这个词每天被说无数遍——"真人说了""真人在书斋""真人今日不见客"。它是日常的、无处不在的、像空气一样的。鱼在这个词中浸泡，直到它也成为她世界的一部分
- **谁用什么称呼暴露了关系的远近。** 先生叫"持盈"——说明他们的关系超出了道门上下级。沈姑姑偶尔叫"公主"——说明她记得更早的时候。鱼什么都不叫——说明她们之间形成了不需要名字的东西

## 二、玉真观的一天——日常节奏

### 唐代道观的时间框架

需要先说明一个关键事实：**唐代道观没有后世那种严格的"早晚功课"制度。** 全真道的丛林早晚课体系是金元以后才建立的，明清才普及。唐代上清派的日常修持更灵活——以个人的存想、诵经、坐忘为主，没有全体上殿齐诵的硬性要求。

但皇家道观有自己的规矩——不是纯粹的修行道观，也是一个机构。所以玉真观的"功课"是一种混合物：**道门修持的柔性节奏 + 皇家机构的管理刚性 + 玉真个人的生活习惯。**

### 一天的时间表（推演）

```

  │  值日女冠给天尊殿供水、供茶、烧香、扫殿
  │

  │  【诵经】——不是全体上殿，是各人在各处

  │  诵什么：《太上老君说常清静经》《道德经》
```

### 关于玉真的个人节奏

玉真的一天和观里其他人不太一样。她不做杂务、不值殿。她的"功课"是：

| 时段 | 她在做什么 | 说明 |
|---|---|---|
| 早起 | 也许自己泡一壶茶。也许在院子里站一会儿 | 她的清晨是私人的。丫鬟不进来，等她叫 |
| 上午 | 书斋。处理文书。有时接见来客 | "处理文书"覆盖很多事——道门通信、朝中消息、经济事务（食邑虽然交了但还有其他收入来源） |
| 午后 | 最灵活。散步、见人、或什么都不做 | 她和人见面多在午后。金仙观散步也是午后 |
| 傍晚 | 也许去天尊殿上一炷香 | 不是功课——是习惯。几十年的习惯 |
| 夜晚 | 书斋。灯亮到很晚 | 她是一个停不下来的人。白天的事做完了，她会写字、读经、或者只是坐着——但不是放松的坐，是"还有事没想完"的坐 |

**她最不忙的时候是最危险的。** 因为一旦停下来，几十年压着的东西就会涌上来。所以她不停。

## 三、道门的年节——以 745/746 年为例

### 正月初一：天腊日

这是道门**五腊日**之首。道教将正月初一称为**"天腊"**——不只是世俗意义上的"新年第一天"，而是**五帝攒会、酆都北阴天帝考校鬼魂善恶**的日子。

| 层面 | 内容 | 在玉真观怎么做 |
|---|---|---|
| **世俗** | 新年。贺岁。互相拜年 | 穿新衣（至少换一件干净的）。准备年宴残留的果品摆在堂上。互相道贺 |
| **道门** | 天腊。五帝考校。诸神下降 | 天尊殿前供品更丰——果品、糕饼、清酒。烧香。诵经时间比平日长。也许沈姑姑带所有人在殿前集体行礼 |
| **皇家** | 宫里赏赐下来 | 红漆食盒——"年年都有"（第一章）。由宫中差役送来。沈姑姑出去接 |

### 除夕夜：驱傩 + 屠苏酒 + 守岁

这是第一章已经写过的场景。补充道门层面的含义：

**驱傩**不是纯世俗的"跳大神"——在道门看来，这是**驱除一年积累的邪气、为新的天地循环扫清道路**的仪式。方相氏的金面四目能"看穿"鬼魅。侲子的红衣是"镇邪"之色。这些在第一章已经写到了。

**屠苏酒**的道门含义：屠苏酒配方出自道教养生传统（大黄、白术、桂心、防风等泡井水一夜）。"从幼到长"的饮序有道门讲究——**年幼者先饮，是道门对"生气"的敬重。新生命先接触新年的气。**

**守岁**：道教有"庚申守岁"的传统——庚申之夜人体内三尸神会趁人睡着时上天禀报过失。守岁原意之一就是"不让三尸有机可乘"。除夕夜虽然不一定是庚申日，但道观的守岁比民间更有宗教色彩——通宵诵经或坐忘。

### 正月初二—初八：待客与祭祀

| 日期 | 内容 | 在玉真观 |
|---|---|---|
| **初二—初三** | 走亲访友。回娘家（世俗）。道观接待来客 | 太子携韦妃来拜年（第一章）。其他与皇室有关的人也许陆续来 |
| **初五** | 破五。送穷。商家开市 | 西市周边开始恢复营业。鱼后来在这天开过铺子（未来） |
| **初九** | **玉皇大帝圣诞（天公生）** | 道观的正式节日。天尊殿大型法事。全观参加。也许是除夕之外最隆重的一天 |

### 正月十五：上元节

**道门三元之首。** 天官赐福之日。这不只是"元宵节看灯"——在道门看来，这一天**天官降临人间，考察善恶，赐福于人。**

| 层面 | 内容 | 在玉真观 |
|---|---|---|
| **世俗** | 全城放灯。坊门不闭。万人空巷 | 鱼第一次走出道观看到长安灯火（第一章已写） |
| **道门** | 天官赐福日。建斋祈福 | 也许白天在观内做一场法事。晚上允许女冠外出看灯——但要结伴 |
| **政治** | 唯一合法的"全城不宵禁"夜晚（天宝年间宵禁已松，但上元节是规制允许的） | 鱼在灯火中看到太子一行人的那个场景（第一章） |

## 四、道门仪式的感官细节（写作用）

### 诵经

- 不是佛寺那种整齐的木鱼伴奏——唐代上清派的诵经更接近**吟唱**。声调悠长，有旋律但不是"唱歌"。像介于说话和唱之间的某种东西
- 多人同时诵但不齐——各自节奏。声音在院子里混成一片，像几条溪流汇在一起
- 法器：**磬**（铜磬或石磬。一声极清脆的"叮"——标记节奏的起止）。也许有**铃**（小型手铃。摇三下）
- **鱼的体验：** "嘴唇自动动了——念出她不理解含义的经文。身体知道什么时候停、什么时候换气。她像一个旁观者住在一台自动运转的机器里"（第二章已写到类似感受）

### 斋醮（法事）

- 比日常诵经正式得多。在天尊殿内进行
- 主持者（也许是玉真本人，也许是资深女冠）穿法服——戴莲花冠、着紫帔
- **踏罡步斗**：在地上按星象方位走特定的步法。脚步声有节奏。从外面看像在跳一种极慢的、极严肃的舞
- **焚表**：将写有祈愿的黄纸（表文）在铜炉中焚化。火焰在殿内跳了一下
- **香**：大量的香。不是线香——是在铜炉中焚降真香或沉檀。烟雾弥漫整个殿堂。光线在烟中变得朦胧
- **时长**：大型法事可持续数个时辰。普通斋醮也要一两个时辰

### 除夕驱傩（已在第一章写到，补充道门层面）

- 方相氏的金面四目——**道门认为四目能看到四个方向的鬼魅**。不只是装饰
- 侲子的红衣——**赤色在道门中是"镇邪"之色**（第一章已说"不是喜庆的红"）
- 驱傩结束后也许有一个**"谢坛"**的环节——主持人向四方行礼，表示驱傩完成
- 玉真观的傩戏规模不大（十几个侲子）——远不如宫廷大傩的几百人。但仪式的核心元素一样

### 供品

| 供品 | 场合 | 说明 |
|---|---|---|
| 清水三杯 | 每日晨供 | 放在天尊殿几案上。代表天、地、人三才 |
| 鲜果 | 节日 | 随季节变化。苹果、梨、枣、柿子 |
| 糕饼 | 年节 | 枣面虎头糕（除夕年宴已出现） |
| 清酒一盏 | 节日 | 不是浊酒——是过滤后的清酒 |
| 香 | 每日 | 降真香或沉香。三炷（或一炷。上清派有自己的规矩） |

## 五、对已有文本的校验

### 已确认正确的

- **"真人"的称呼**——观内一律用，正确 ✅
- **"身体会自动做功课"**——穿越后的身体惯性，合理 ✅
- **正月初一的安静**——"像一个空壳"（第一章），正确 ✅ 除夕闹过之后初一确实安静
- **初二太子拜年**——合理 ✅ 正月走亲是规矩
- **"宫里赏的。年年都有"**——皇家道观有宫中例赏 ✅
- **屠苏酒从幼到长**——"长一岁少一岁，少一岁的人先饮"（第一章）✅ 完全正确

### 需要注意的

- **"晨课"这个词**——唐代上清派没有"早课"的硬性制度（那是全真道的）。现有文本中鱼"做功课""诵经"的描写是对的，但如果后续用到"早课""晚课"这种词汇，建议改为"诵经"或"功课"，避免暗示一个当时不存在的制度
- **磬 vs 木鱼**——story-bible 提到"木鱼"是"道观用木鱼少于佛寺，但不禁止"。建议实际写作中以**磬**为主（铜磬、石磬），更贴合上清派的气质。木鱼偶尔用可以
- **全观集体上殿诵经**——唐代不太可能。更可能是各自在各处诵。只有重大法事才集体到殿中

## 六、玉真的一天——叙事可用版

> 以下是一段"标准的一天"的描写素材——可以拆散用在不同章节中。

**卯时。** 天还没亮透。院子里有脚步——是值日的女冠在开殿门。然后是磬声。一声。极清脆。从天尊殿那个方向传过来，在冬天的空气里跑了很远。

玉真已经醒了。她醒得比磬早。也许她没怎么睡——书斋的灯刚灭不到两个时辰。

丫鬟在门外等着。不进来。等里面叫。

过了一会儿，门从里面开了。玉真已经穿好了。石青道袍。玉簪。没有多余的东西。她走到院子里的井边——亲自打了一桶水，洗了手和脸。不让丫鬟帮。这是她几十年的习惯——"手碰了冷水人就醒了。"

**辰时。** 早膳送到书斋。粟米粥，一碟咸菜，两枚蒸饼。她吃的和普通女冠差不多——不是刻意清苦，是不在乎。但粥碗是她自己的——一只旧的青瓷碗，用了很多年。

**巳时。** 书斋。沈姑姑来汇报——谁来了帖子、谁送了东西、库房的纸该进了、偏院那位客人的情况。玉真听。偶尔问一句。大部分时候点头。沈姑姑说完了，退出去。

然后她一个人。铜炉里焚了降真香。展开一封信——也许是道门网络传来的。也许是朝中旧友的。光线从侧窗进来，落在她的手上。手很稳。

**午后。** "今天天气好。小鱼跟我走一趟。"——也许只有这一句。鱼放下手里的事，跟着她出去。

去金仙观。或者只是在观内走走。走的时候不太说话。但走着走着，她会指一样东西——也许是一棵树，也许是檐角的一只鸟——说一句看似随意的话。鱼后来发现那句话并不随意。

**酉时。** 天尊殿前。她会在这个时候去上一炷香。不是功课。是习惯。三炷香。站了一会儿。然后回书斋。

**亥时。** 书斋的灯还亮着。隔着纸窗能看到一个人坐着的影子。不动。也许在读什么。也许什么都没读。也许只是坐着——用"还有事没做完"骗自己不用面对安静。

观里的人都知道：真人是最晚熄灯的。没有人问为什么。

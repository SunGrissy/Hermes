## 〇、唐代服饰通则速查

### 面料等级（从贵到廉）

| 面料 | 特征 | 谁穿得起 | 触感描写 |
|---|---|---|---|
| **锦** | 彩色丝线织成的提花织物。工艺最复杂。有经锦（古法）和纬锦（新法） | 皇室、高级贵族、赏赐品 | "厚的、密的、用手指捻一下能感到纹路凸起来" |
| **绫** | 斜纹地起斜纹花。表面有山形暗纹。盛唐最流行的中高档面料 | 中上层通用。官服多用绫 | "滑的、有光泽但不刺眼。迎光看有隐隐的花纹浮出来" |
| **罗** | 经纱绞缠形成网状小孔。轻薄透气 | 夏季用。中上层 | "像有人在丝绸上扎了无数极小的孔。透气。隔着它能看到皮肤的颜色" |
| **纱** | 比罗更薄更疏。方孔均匀分布 | 夏季用。帔帛多用纱 | "几乎是透明的。风一吹就飘。像雾凝成了布" |
| **绢** | 平纹丝织物。紧密、轻薄、坚韧。最基础的丝织品 | 各阶层。经济往来的硬通货 | "光滑、平整、没有花纹。朴素但结实" |
| **绮** | 平纹地起斜纹花。类似绫但等级略低 | 中层 | "像绫但纹路更浅" |
| **布（麻布）** | 麻纤维织成。粗糙但耐用 | 平民日常、僧道常服 | "粗的、涩的、新的时候硌皮肤，洗几次就软了" |
| **葛** | 葛藤纤维织成。夏季清凉 | 平民夏装、道士常服 | "比麻布细一点。凉的" |

### 颜色等级与禁忌

| 颜色 | 等级/含义 | 谁可穿 | 实际色感 |
|---|---|---|---|
| **赭黄** | 帝王专用 | 仅天子 | 赤黄色。绝对禁区 |
| **紫** | 三品以上 | 高官、受赐者 | 用紫草或蓝靛套染红花。偏暗红的紫 |
| **绯（深红/浅红）** | 四品、五品 | 中高级官员 | 茜草染。深的近暗红，浅的近粉红 |
| **绿（深/浅）** | 六品、七品 | 中级官员 | 蓝靛套染黄栌。深绿偏暗，浅绿偏嫩 |
| **青（深/浅）** | 八品、九品 | 低级官员 | 蓝靛染。深青近藏蓝，浅青偏灰蓝 |
| **石青** | 道教常用 | 道士/女冠 | 深蓝偏灰。沉稳。玉真的标志色 |
| **白** | 无官者/丧服 | 平民、文人、居丧者 | 未染的素绢本色。微微泛黄 |
| **皂（黑）** | 低级/仆役 | 差役、奴仆 | 蓝靛多次浸染至极深 |
| **鸦青** | 半正式 | 道士、文人 | 极深的蓝灰。近黑但泛蓝 |
| **缃色** | 日常 | 中下层女性 | 浅黄色。柔和 |

### 男装基本结构

```
幞头（黑色纱罗头巾，有硬框撑起）
  ↓
圆领袍衫（窄袖或中袖，长至膝下或脚踝。右衽）
  ↓
革带（銙带，缀金/银/玉/铜銙。品级不同材质不同）
  ↓
内穿汗衫、袴（裤）
  ↓
足蹬乌皮靴（官员）/ 布鞋 / 草履（平民）
```

### 女装基本结构

```
发髻（多种样式。可加义髻增高）+ 簪/钗/步摇/花钿/梳
  ↓
衫子/襦（上衣。短，至腰。对襟或交领。窄袖至中袖）
  ↓
裙（高束至胸下或腰间。六幅以上。长曳地）
  ↓
帔帛（长条形薄纱。搭肩绕臂。飘飘然）/ 半臂（短袖外套。至腰）
  ↓
足穿云头履 / 绣花鞋 / 草履
```

## 一、玉真公主

**身份：** 皇帝之妹。出家女冠。上清玄都大洞三景法师。744 年削号后名义上是"玉真道人"，但实际生活水平仍为皇室。

**服饰核心词：** 石青。银线。极简中的极贵。

### 日常（观内）

| 部位 | 具体 | 描写 |
|---|---|---|
| **道袍** | 石青色绫制。交领右衽。宽袖但不拖沓——袖长刚好盖住手背。领口和袖缘有**银线暗纹**（极淡的一道，不凑近看不见）。这是第一章已确立的核心视觉 | "石青道袍上跑着火光，银线暗纹亮了一瞬——领口和袖缘极淡的一道" |
| **内衬** | 月白色绢。领口露出一线。冬天加厚——也许是素面的丝棉夹袄 | 翻领处隐约可见的白 |
| **发式** | 不戴冠。发挽成简单的**道髻**（类似飞仙髻，但更紧实朴素），用一根**玉簪**固定。不饰花，不加义髻。五十四岁的头发也许已有些白——但她不染 | "头发用一根玉簪绾着"（第一章） |
| **鞋** | 素面布履。圆头。灰色或青色。底是千层布纳的 | 走路声极轻（金仙观散步时"五十四岁的人走路不应该这么轻"） |
| **配饰** | **几乎没有。** 这是她最核心的服饰特征——一个本可以满头珠翠的皇室公主，身上只有一根玉簪。但那根玉簪的玉质，行家一看就知道价值连城 | "她身上唯一的饰物是那根簪——脂白的、温润的，像被人体温焐了很多年" |
| **香** | 不佩香囊。但她的衣服上有降真香的气味——从书斋的铜炉上沾的。是"住"在身上的香，不是"戴"在身上的 | "不是香料的甜——是一种干燥的、木质的、像松脂但更沉稳的气味" |

### 正式场合（月宴、接待重要客人）

| 部位 | 具体 |
|---|---|
| **道袍** | 换一件更好的——也许是深紫绫制（紫是三品以上之色，她虽削号但这个等级没人敢说她不配）。暗纹可能更复杂——云鹤纹或缠枝纹，织在绫面上迎光才可见 |
| **冠** | 戴**莲花冠**（芙蓉冠）。金箔制，形如莲花。扣覆于髻上，以簪绾系。这顶冠也许是旧的——几十年前皇帝赐的。金箔的光泽已经暗了，但形制完好 |
| **帔** | 紫纱帔。轻薄。搭在肩上，两端垂至膝下。这是道门法服的一部分——"帔"象征"披扬道德" |
| **腰** | 也许系一条素色丝绦，上挂一枚小型玉佩或香囊 |

### 核心设计原则

**玉真的穿着是"做减法做到极致"的结果。** 不是她穿不起——是她选择不穿。这种"主动放弃华丽"本身就是一种权力展示：只有拥有过一切的人才会这样穿。她的石青道袍在满室锦绣中反而是最显眼的——因为它太安静了。

## 二、鱼（余小满）

**身份演变：** 杂务女冠 → 叔父铺子帮手"小余" → 余懃家旁支女眷 → 玉真身边的人。服饰随身份升级而变化。

**服饰核心词：** 灰色起步。逐渐有了自己的颜色。但永远不出挑。

### 阶段一：杂务女冠（746 正月—秋）

| 部位 | 具体 | 描写 |
|---|---|---|
| **常服** | 灰色麻布道袍。旧的——原身穿了两年的。没有暗纹、没有绣花。交领。袖子略长（不太合身——也许是观里统一发的） | "墙上挂着一件灰色衣服"（第一章）；"半旧的灰衣"（丫鬟穿着类似） |
| **内衬** | 白色粗麻里衣。冬天加一件夹袄——棉不够厚，她怕冷 | "这具身体比她觉得应该有的更怕冷" |
| **发式** | 简单的单螺髻或低垂髻。用木簪固定。没有多余装饰。穿越后的鱼也许绾得不太好——原身的手可以自动做，但手法不如以前利索 | "头发随便挽着"（丫鬟）——鱼也差不多 |
| **鞋** | 布鞋。灰色。底薄。冬天冷得受不了 | — |
| **配饰** | 无。只有原身留下的一枚暖白色玉佩——不戴在外面，收在箱子里。以及韦妃给的铜压胜钱 | "一枚玉佩，暖白色，摸起来有极细的纹路。不贵。但被人攥过很久" |

### 阶段二：余家纸墨行"小余"（747—748）

| 部位 | 具体 |
|---|---|
| **常服** | 开始穿**世俗女装**出门做生意。短襦 + 裙——不是道袍了。衫子是缃色（浅黄）或月白色的绢制。裙是深青或赭石色。**不花哨——是一个做生意的年轻女子该有的得体。** 不出挑但整洁 |
| **外罩** | 冬天加一件半臂或夹袄。三叔给买的——料子比观里好。也许是细麻或粗绢 |
| **发式** | 离开道观后可以梳更世俗的发式。也许是**双丫髻或低垂百合髻**——年轻未婚女子常见发式。插一根银簪（三叔给买的。不贵。但比木簪好看） |
| **鞋** | 换了好一点的布鞋。三叔给的。底厚了，冬天好过一些 |
| **围裙/袖套** | 在铺子里裁纸时也许会套上一个粗布围裙和袖套——保护衣服不沾墨 |

### 阶段三：余懃旁支女眷 + 玉真身边的人（749—）

| 部位 | 具体 |
|---|---|
| **出席场合的衣着** | 升级明显。衫子改用**绫或绮**。颜色可以选更多——也许是浅碧、淡紫（不到品服的紫，是民间可用的淡紫）、或鹅黄。裙用细绢或绫，可以有暗花。帔帛——一条薄纱帔帛搭在肩上，是"我有资格出现在这种场合"的信号 |
| **回观时** | 仍然穿回道袍。但质地升级了——从粗麻变成了**细麻或葛布**。也许颜色从灰变成了更深的鸦青。玉真也许让沈姑姑给她做了一件新的 |
| **首饰** | 开始有了一两件像样的东西。也许余家姑娘（余令微）送了她一支银钗。也许大伯母送了一块好料子。鱼不太习惯戴——"觉得头上多了东西，走路分心" |
| **核心原则** | **永远比在场的贵族差一档。** 不是穿不起——是她刻意控制。"不出挑"是她的生存本能。如果清漪穿细绫，她就穿粗绫。如果某位夫人戴金钗，她就戴银的。**她的穿着是精密计算的"刚好得体"。** |

## 三、清漪

**身份：** 玉真观资深女冠。落魄官宦之女。在观中十年。

**服饰核心词：** 比规定的好一点点。恰到好处的用心。

### 日常

| 部位 | 具体 |
|---|---|
| **道袍** | 灰青色——比新人的灰深一点、比玉真的石青浅一点。用的是**细麻或葛布**——不是绢（她没有那个经济来源），但比普通女冠的粗麻好。经过十年的积攒和人情往来，她的衣服比身份应有的好半格 |
| **缝制** | 自己缝的。针脚极细——这是官宦之女的手艺。领口也许绣了一道极细的暗纹——不是规制要求的，是她自己加的。不出格，但显手艺 |
| **发式** | 简洁但不随便。低垂螺髻，银簪固定。簪子也许是她从家里带出来的——是她全部"前世"的遗存之一 |
| **整体印象** | "每一道褶子都在该在的位置的讲究"——不是鱼第二章看到的那个年轻女访客（尚简），而是清漪自己也有这种气质。区别在于：尚简的讲究来自不需要操心的富足，清漪的讲究来自**拼命维护的体面** |

### 特殊场合（月宴等）

- 换一件更好的衣裳——"不是为了漂亮，是这种场合的分寸"（第四章已写到）
- 也许是深青色的绢制道袍。上面有一点暗花。比平日穿的好，但绝不会比玉真出彩

## 四、胡（康默）

**身份：** 粟特商人之子。多语言。丝路上长大。

**服饰核心词：** 胡汉混搭。实用至上。不经意的异域感。

### 日常

| 部位 | 具体 | 描写 |
|---|---|---|
| **上衣** | **翻领窄袖长袍**——粟特人的传统款式。三角翻领。腰束革带。这不是汉人的圆领袍——领子是对折翻出来的，露出内衬的颜色 | "不是汉人常穿的圆领袍，是翻领窄袖、腰束革带的款式"（三叔的描写可参照） |
| **颜色** | 驼色、褐色、深赭——丝路上耐脏的颜色。不是鲜亮的——是沙子和泥土的颜色 | "颜色像把沙漠穿在身上了" |
| **面料** | **毛织物**（羊毛/驼毛）为主，混搭丝绸。粟特人从中亚带来的纺织传统——冬暖夏凉，耐磨。和汉人全丝的审美完全不同 | "不是丝的那种滑——是粗的、厚的、摸上去有羊的气味" |
| **腰带** | 宽革带。上面可能缀了几枚银銙或铜銙。挂着一个皮囊（装钱或小物件）。也许还有一把小刀——不是武器，是日用（开包裹、切绳子） | 腰间叮叮当当的声音 |
| **头** | 不戴幞头——戴**毡帽**或干脆光头裹布巾。在中原待久了也可能偶尔戴幞头以融入——但戴的方式不太标准，总有一点歪 | "头巾歪了但他不在乎" |
| **靴** | 高筒皮靴。尖头。磨损严重——走了太多路。但擦得干净（这一点和三叔一样——丝路上的人对靴子有执念，靴子是命） | "脚上的靴子磨得很旧，但擦得干净" |
| **配饰** | 也许有一串不起眼的珠子（玛瑙或琥珀）缠在手腕上——不是装饰，是**护身符**，从母亲那里来的。也许有一个粟特式的银耳环——单只。左耳 | 手腕上那串珠子在他递东西时会露出来 |

### 在场合中

- 如果需要融入汉人社交圈，他会换圆领袍。但穿法总有些不伦不类——也许领子系的方式不太对，也许腰带扎的位置偏高（粟特习惯）。**他不是不会穿汉服——是穿了也藏不住骨子里的异域感**
- 鱼注意到他换装后的违和感可以成为一个性格细节："他穿圆领袍的样子像一匹狼穿了羊的衣服——毛是对的，但走路的姿势不对"

## 五、道门先生（李含光）

**身份：** 茅山宗宗师。六十五岁。修行者。

**服饰核心词：** 旧得不像话。但干净。

### 日常（唯一模式——他没有"正式场合"的概念）

| 部位 | 具体 | 描写 |
|---|---|---|
| **道袍** | 灰色粗麻布。**洗得发白了。** 不是破——是穿了太多年。布料的纤维已经变软了，失去了新布的硬挺。补过——也许在肘部或下摆有补丁，但补得很仔细 | "穿着一件洗得发白的灰色道袍。不是破——是穿了太多年"（第五章） |
| **鞋** | 布鞋。沾了泥。也许是刚才在院子里看猫的时候踩的 | "脚上的布鞋沾了泥" |
| **头** | 也许不戴冠。头发挽一个最简单的道髻，用一根木簪（不是玉——是普通的木头）。也许头发已全白 | — |
| **身上** | 什么配饰都没有。腰间也许系了一根旧布条权当腰带。唯一随身的"配饰"是那只**旧茶壶**——不离手 | 手里永远端着一个旧茶壶 |
| **气味** | 茶。他身上的气味是茶。不是名贵的那种——是泡了千百壶之后渗进衣服纤维里的茶叶底味 | "靠近他的时候有一种淡淡的茶味——不是喝茶的味道，是煮过了千百遍的老叶子的味道" |

**与玉真的对比极其强烈：** 玉真是"做减法做到极致"——石青绫制、银线暗纹、价值连城的玉簪。先生是"压根没考虑过这个问题"——穿什么都行，能盖住身体就行。**一个是有意识的极简。一个是无意识的不在乎。差距极大但殊途同归——两个人都不被衣服定义。**

## 六、太子李亨

**身份：** 太子。正月初二来拜年那场是他在全书的第一次（也许是仅有的几次）出现。

### 第一章拜年时的穿着

| 部位 | 具体 | 描写 |
|---|---|---|
| **袍** | **圆领窄袖袍**。便服——不是朝服，是拜年走亲戚的衣服。颜色推测为**赭黄或明黄**——太子在非正式场合也许穿偏暖的黄色系，但不到皇帝的赭黄。**也可能刻意选偏暗的颜色**——紫檀色或深赭——因为天宝年间太子处境艰难，穿得太亮会被说"僭越" | "穿的是便服——一件不算太华丽的圆领袍。但料子的光泽安静地说着'这个人不需要华丽'"（第一章） |
| **面料** | 细绫或绮。不用锦——便服不适合。但绫的质地是顶级的——经纱密度极高，手感软而有分量 | "料子的光泽"——绫特有的、不张扬的、迎光才可见的光泽 |
| **腰带** | 銙带。也许是**金銙**（太子品级够用金）。但銙的数量和大小也许比他有资格戴的少——低调 | — |
| **幞头** | 标准幞头。系法规矩。黑色 | — |
| **靴** | 乌皮靴。新的或半新——正月出门拜年总要穿好一点 | — |
| **整体气质** | **有意识的不显眼。** 料子是最好的，但颜色选偏暗；带子是金的，但不让它反光；袍子剪裁合身，但不突出任何一处。**一个活在"被弹劾恐惧"里的人穿出来的衣服** | "笑容得体。肩膀是紧的" |

## 七、韦妃

**身份：** 太子妃。初二拜年同行。两周后"被休"（韦坚案）。

### 拜年时的穿着

| 部位 | 具体 | 描写 |
|---|---|---|
| **衫裙** | 便装——不是命妇礼服。衫子也许是**浅绯色或淡紫色的绫**。裙是**石榴红**——正月穿红，吉庆。裙幅宽大，曳地。走路时裙摆在砖地上拖出一道弧 | "裙摆铺在砖地上"（第一章·她蹲下来时） |
| **帔帛** | 一条薄纱帔帛搭在肩上。也许是淡金色的——映着她的脸，温柔 | — |
| **发式** | 也许是**高髻**——正月出门拜年的正式发式。不是最夸张的义髻——太子妃不适合太招摇。但也不寒酸。用金钗固定 | — |
| **步摇** | 领口别了一枚**小小的金步摇**——"走路时微微在晃"（第一章已写到）。这是她全身最显眼的饰物。小。金。在晃。像她这个人——温暖的、活的、会动的 | "领口别了一枚小小的金步摇，走路时微微在晃" |
| **鞋** | 云头锦履。也许是红色的。鞋头翻卷如意云。从裙摆下偶尔露出一角 | — |
| **整体气质** | 和太子的刻意低调不同，韦妃穿得**恰如其分地好看**——不是张扬，是一个本身就温暖的人穿什么都温暖。她的衣服不是为了展示身份——是为了让人看着舒服 | "气质极好……笑是松的、真的" |

**叙事功能：** 她穿的这些东西——石榴红裙、金步摇、云头履——在两周后都不属于她了。被休的时候什么都带不走。读者在后来想起正月初二她笑着蹲下来、裙摆铺在砖地上的画面时，会更痛。

## 九、李白（卷二出场参考）

## 十四、写作注意事项

### 不要做的事

1. **不要一次性描写全身。** 鱼的视角是碎片式的——先看到一根簪，过两段看到袖口的颜色，再过一章注意到鞋。"一个从头到脚的全身描写"是时装秀，不是小说
2. **不要用现代面料名。** 没有"丝绸""棉布"这种统称。用具体名——绢、绫、罗、麻布、葛布。（注意：唐代中国没有棉花，棉布要到宋元才普及。保暖靠丝棉/麻絮/动物皮毛）
3. **不要让鱼"认出"面料。** 她不是纺织专家。她能分辨"滑的/粗的/厚的/薄的"，但她不会说"这是蜀锦"。**除了纸——纸她认得。**
4. **不要让道观里的人穿得太好。** 普通女冠穿的是粗麻灰袍。只有沈姑姑、清漪这种资深人员稍好。鱼一开始穿的和丫鬟差不多

### 要做的事

1. **用触感而非视觉。** 鱼摸纸是她的天赋——让她用手感受面料。"这件衣服的料子比道观里的滑"——这就够了
2. **用穿着暴露性格。** 玉真的减法、清漪的拼命维护、胡的不在乎、先生的真不在乎——衣服是性格的延伸
3. **用衣服标记身份变化。** 鱼从灰麻道袍到缃色绢裙到淡碧绫衫——每一次换装都是身份升级的物理证据
4. **用细节埋伏笔。** 韦妃的金步摇、玉真的银线暗纹、杜甫发白的旧袍——这些细节在后文中会回响

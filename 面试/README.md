# 面试资料（根目录汇总）

本目录为工作空间根下**面试相关材料的统一入口**。

## 结构说明

| 路径 | 说明 |
|------|------|
| **[interviews/](interviews/)** | 按候选人/场次归档的面试清单、README、评价等（由根目录 `interviews/` 迁入） |
| **[已面试索引.md](已面试索引.md)** | 已面试/已有清单的人员索引，供初筛交叉提示与人工维护 |
| **`performeval/面试/`**（子模块内） | 简历初筛清单、初试/复试记录、历史初审报告等，与绩效仓库同步 |
| **`performeval/面谈准备/`**（子模块内） | 面谈用 HTML 等准备材料 |

初筛清单技术路径未变：`performeval/面试/简历初筛/`（`resume_screen`、Skills 仍按此加载）。

## 维护约定

1. **新建候选人资料包**：优先放在 `面试/interviews/{岗位或日期}_{姓名拼音}/`，与既有子目录命名风格一致。
2. **已面试索引**：每进入「已生成面试清单 / 已面试」流程，在 `已面试索引.md` 表追加一行，便于检索与初筛命中。
3. **子模块内文档**：仍在 `performeval` 仓库内维护、提交；若未来要物理合并到本目录，需在子模块内做迁移 PR。

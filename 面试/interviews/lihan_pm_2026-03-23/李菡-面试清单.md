# PM 二面执行清单（李菡）

## A. 面试前准备（10 分钟）
- [ ] 阅读 `README.md`，统一对齐本次二面目标
- [ ] 明确岗位职责边界（战略 PM / 执行 PM / 复合 PM）
- [ ] 准备 1 个团队真实问题案例（用于现场拆解）
- [ ] 准备评分表（建议四维：业务判断、产品方法、组织协同、落地韧性）

## B. 必问主线（按优先级）

### B1 战略到执行能力（最高优先级）
- [ ] 让候选人用一个真实项目回答：目标如何定义、里程碑如何拆解、如何防偏航
- [ ] 追问“版本目标冲突”时如何取舍（收入、体验、产能三角）
- [ ] 追问“跨时区/跨团队协作”中如何建立节奏和对齐机制
- [ ] 要求给出可复用模板（周会机制、风险看板、升级机制）

### B2 数值体验深度（重点补缺验证）
- [ ] 让候选人拆解一个“付费体验链路”（如 super win -> 情绪峰值 -> 付费触发）
- [ ] 追问其如何定义“数值体验好”的指标（不仅看收入，还看留存/情绪曲线）
- [ ] 给出异常情境：ARPDAU 上升但留存下滑，要求给出排查路径
- [ ] 要求说明 A/B 测试设计：假设、样本、观察窗口、成功阈值

### B3 产品感与用户心理
- [ ] 让候选人说明“美术表达如何服务产品目标”，看其是否能把审美转成业务语言
- [ ] 追问一个失败迭代案例：错在哪里、如何复盘、如何避免复发
- [ ] 验证其是否能区分“短期刺激”与“长期体验资产”

### B4 团队管理与人才建设
- [ ] 追问其 OKR/评估体系怎么落地，如何处理低绩效成员
- [ ] 验证其是否有“机制先行”习惯，而非仅靠个人盯进度
- [ ] 让其给出“前 90 天组织动作”与关键产出清单

## C. 场景题（建议二选一）
- [ ] 场景题 1：版本上线后首周数据平，要求 15 分钟给出诊断与动作顺序
- [ ] 场景题 2：美术、策划、技术目标冲突，要求给出决策框架和沟通话术

## D. 风险识别清单
- [ ] 是否过度依赖既有品类经验，迁移到新题材是否仍有效
- [ ] 是否只会“推动”而缺少“建模”（指标体系、实验设计、反事实思维）
- [ ] 是否在压力场景下仍能保持优先级稳定
- [ ] 是否对本团队阶段目标有现实预期（避免高配低用或角色错位）

## E. 录用建议输出模板（面试后 5 分钟）
- [ ] 结论：录用 / 备选 / 不录用
- [ ] 级别建议：P4（或调整建议）
- [ ] 关键证据（3 条）：写明“事实 -> 判断 -> 风险”
- [ ] 入职 30/60/90 天目标草案（若录用）
- [ ] 需要补充背调项（若有）

---

## 快速评分参考（1-5 分）
- 业务判断：是否能把目标转成可执行路径
- 产品方法：是否具备指标与实验闭环能力
- 协同能力：是否能在跨团队环境中形成稳定推进
- 韧性与复盘：是否有面对失败的结构化改进能力

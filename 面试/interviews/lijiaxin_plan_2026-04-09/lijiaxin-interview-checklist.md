## 四、面试主线（按优先级排序）

### 第一优先级：方向意愿 — 你为什么来做商业化捕鱼？

> **考察目标**：这是决定性问题。候选人简历画像是「独立叙事游戏开发者」，来捕鱼团队的动机直接决定录用可行性。

- [ ] **开场题**：「你的求职意向写的是叙事/关卡/系统，个人项目也是独立叙事游戏。我们是一个商业化捕鱼产品——80 人团队、日活百万级、核心收入来自重度付费用户。你为什么会投我们？你觉得自己在这样的团队里能做什么？」
  - 追问 1：「你理想中 3 年后的职业状态是什么？是回去做独立游戏，还是在商业化团队深扎？」
  - 追问 2：「如果入职后发现工作内容大部分是 Boss 表演设计、活动配置、数值调优，而不是叙事设计，你能接受吗？」
- [ ] **认知题**：「你觉得独立叙事游戏的设计思维和商业化捕鱼游戏的设计思维，最大的区别是什么？有没有共通的地方？」
  - 关键判定：是否理解「为用户体验服务」vs「为用户付费行为服务」的差异和共性
- [ ] **底线判断**：如果回答完全是「想积累经验然后回去做独立游戏」或「不太了解捕鱼只是海投」→ 方向不匹配，后续问题可精简

### 第二优先级：WHAT 层 — 设计思维的可迁移性

> **考察目标**：他在独立游戏中展现的设计思维（目标→方案→验证→迭代）能否迁移到商业化产品。

- [ ] **迁移题**：「你在《忘川摆渡人》里把执念值设计成隐性反馈（船灯颜色而非数值条），核心考虑是什么？如果现在让你给捕鱼游戏设计一个'玩家运气系统'——让玩家感觉到'今天手气好/差'但不直接告诉他概率——你会怎么做？」
  - 关键判定：能否把「隐性反馈」的设计思路迁移到完全不同的品类
  - 追问：「这个运气系统会影响付费行为吗？你希望它让玩家多充还是少充？」
- [ ] **目标定义题**：「你复盘了早期方案'操控空间不足、碎片叙事理解断裂'——这些问题是怎么发现的？你用什么标准判断'方案成功了/失败了'？」
  - 追问：「如果换成商业化游戏，'方案成功'的标准会变成什么？」
- [ ] **取舍题**：「你在忘川摆渡人里把主线记忆和可选记忆分开——这个决策的 trade-off 是什么？为什么不全做成可选？或者全做成主线？」
  - 关键判定：是否有清晰的取舍逻辑，而非「我觉得这样好」

### 第三优先级：HOW 层 — 方案深度与文档能力

> **考察目标**：独立开发者做方案可能「直接写代码验证」，但团队协作需要可交付的文档。

- [ ] **文档题**：「你在宸冠做的武器系统、解谜电路——方案文档长什么样？程序拿到能直接做吗？有没有写过异常情况——比如同时触发两个解谜机关会怎样？」
  - 追问：「你在《忘川摆渡人》里有没有写设计文档？还是直接在 UE5 里边想边做？如果你把这个项目交给另一个策划继续，他看你留下的资料能接手吗？」
- [ ] **配表题**：「你用 Excel 管理武器属性和敌人属性——表结构是什么样的？字段怎么定的？如果要加一种新武器类型，表要怎么改？」
- [ ] **场景拆解题**：「假设让你设计一个捕鱼游戏里的新 Boss——从选题到表现到数值到上线，你会怎么拆这个任务？你需要跟哪些人协作？交付物是什么？」
  - 关键判定：能否从「独立开发者」视角切换到「团队分工协作」视角

### 第四优先级：商业化认知 — 从零探底

> **考察目标**：商业化认知是最大空白，不期望他已经懂，但需要看他有没有学习的基础和意愿。

- [ ] **体验题**：「你有没有玩过捕鱼类游戏？或者其他重度付费手游？你自己在游戏里花过多少钱？花钱的时候是什么心理？」
- [ ] **付费设计题**：「你设计的忘川摆渡人是免费/买断制——如果要把它改成 F2P（免费+内购），你会在哪里加付费点？你觉得加了之后对体验有什么影响？」
  - 关键判定：是否能理解「付费设计是体验设计的一部分」而非「付费破坏体验」
- [ ] **用户差异题**：「你觉得玩独立叙事游戏的玩家和玩捕鱼游戏的核心玩家，他们追求的'爽'有什么本质区别？」
  - 追问：「如果让你设计一个让 40 岁男性玩家愿意每月花 5000 块的功能，你第一反应是什么？」

### 第五优先级：技术转化与 AI

> **考察目标**：技术能力是他的明显优势，但需要验证能否转化为策划工作中的实际价值。

- [ ] **技术优势题**：「你独立开发用了 UE5 蓝图+C++。如果入职后你是策划不是程序，这些技术能力在日常工作中怎么用？能举一个场景吗？」
- [ ] **工具题**：「你用 Python 批量处理图片来解决美术和程序的格式不匹配——这个决策是你主动做的还是被安排的？你觉得策划应该有这种'自己写工具解决问题'的能力吗？」
- [ ] **AI 题**：「你简历里没提到 AI 工具——你日常用 AI 吗？用在什么场景？在《忘川摆渡人》的开发中有用 AI 辅助吗？」
  - 追问：「如果让你用 AI 提升策划工作效率，你觉得哪个场景最有价值？」
  - 关键判定：是否完全没有 AI 意识（红旗），还是用了但简历没写

### 第六优先级：协作与成长

- [ ] **独立→团队题**：「你过去 2 年基本是独立开发——一个人决定做什么、怎么做、什么时候做。如果入职一个 80 人团队，制作人说'这个 Boss 我们不做叙事，只做数值翻倍表演'，你会怎么想？怎么做？」
  - 关键判定：能否接受商业化团队的决策约束，而非「我觉得应该这样设计」
- [ ] **工作经历题**：「你在宸冠和乐城堡各做了几个月就离开了——什么原因？这两段经历你最大的收获是什么？」
- [ ] **复盘迭代题**：「你做了 3 轮迭代（GameJam→溺星→忘川摆渡人重构）——如果让你再重来一次，你会跳过哪一步？为什么？」

## 五、场景题（二选一深入）

### 场景 A：商业化设计迁移（推荐，直接测思维迁移天花板）

> 「我们的捕鱼游戏要做一个新的集卡系统——玩家通过打鱼收集卡片，集齐一套可以兑换大奖。这个系统要同时做到三件事：①让普通玩家觉得有趣不无聊；②让付费玩家觉得花钱能加速且值得；③让数据上看到付费率和留存都有提升。给你 8 分钟，现场设计。」

**评判标准**：
- 是否追问用户分层（免费/小R/大R 分别怎么体验？）
- 是否考虑了「投入-产出」循环（卡从哪来、稀有度怎么定、兑换奖励怎么定价）
- 是否想到付费加速的设计（买卡包？概率提升？保底机制？）
- 是否考虑了生命周期（一个赛季多久？集完了怎么办？）
- 加分：是否主动提到数据验证（怎么知道成功了？看什么指标？）

### 场景 B：方案重构决策

> 「你负责一个捕鱼 Boss 的表演设计，已经做了一版并通过了内部评审。美术资源已经开始制作了。但上线前一周，数据组告诉你同类 Boss 的付费转化率连续 3 个月下降。制作人问你：'要不要推翻重做？'你怎么分析这个问题？给出你的建议。」

**评判标准**：
- 是否先追问数据（下降是因为 Boss 本身还是大盘？具体哪个环节转化差？）
- 是否考虑沉没成本 vs 机会成本
- 是否提出「小改验证」而非「全推翻」或「不改」的二元选择
- 是否考虑时间约束（一周内能做什么、不能做什么）

| **方向不匹配（最大风险）** | 第一优先级全部 | 若动机是「过渡」「海投」「退而求其次」→ 直接影响录用；若能说出「商业化设计也是设计，我想学习用户付费心理」→ 可接受 |
| **商业化认知空白** | 第四优先级全部 + 场景 A | 完全无法理解付费设计逻辑 → 培养成本过高；能从「体验设计」角度切入付费 → 可培养 |
| **独立开发者心态** | 第六优先级 独立→团队题 | 无法接受商业化约束、团队决策覆盖个人判断 → 协作风险高 |
| **AI 意识缺失** | 第五优先级 AI 题 | 完全不用 AI、没有意识 → 与团队进化力要求冲突；用了但简历没写 → 无风险 |
| **文档协作能力** | 第三优先级 文档题 | 「我直接写代码不需要文档」→ 团队协作风险；有文档习惯只是独立开发时没写 → 可培养 |
| **运营能力空白** | 全栈评估 | 运营方向几乎无信号，若其他方向也不够强 → 全栈培养 ROI 存疑 |
| **短期离职风险** | 第六优先级 工作经历题 | 两段工作各 4-6 个月，需确认原因；若与职业方向探索有关（后去读研）→ 可接受 |

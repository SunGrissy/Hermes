# 面试清单生成

基于候选人简历，生成一份**可直接携带进面试现场**的执行清单。清单需覆盖：预审对齐、必问主线、场景题、风险识别、评分表、结论模板。

## 何时使用

- 用户提供简历（PDF/文本/图片）并要求生成面试清单
- 用户提到：面试清单、初面清单、考察清单、面试准备、interview checklist
- 用户指定岗位和候选人，要求准备面试问题

## 执行步骤

### 1. 确定岗位与候选人

- 从用户说明或简历内容判断目标岗位和级别
- 支持的岗位：系统策划 / 战斗策划 / 运营策划 / 主策划 / 应届生 / PM / 其他（用户指定）
- 记录候选人姓名、目标岗位、目标级别

### 2. 加载参考数据

按优先级查找参考数据：

1. **仓库内路径**（MyAgents 工作区内）：`performeval/面试/简历初筛/简历初筛清单_{岗位}.md`
2. **SKILL 附带参考**（自包含场景）：本目录下的 `reference/` 子目录
3. **无参考数据**：根据下方「各岗位核心能力标准」和模板结构直接生成

### 3. 提取简历信息

从简历中提取：

- 基础信息：姓名、年龄、学历、联系方式、当前状态
- 职业轨迹：逐段经历（时段、公司、职位、项目、时长）
- 核心产出：量化成果、主导/参与的区分
- 技能关键词
- 个人游戏经历（如有）

### 4. 生成清单

按下方模板结构输出完整清单。

## 清单模板结构

### 附一：资料包概要

```markdown
### 候选人基础信息
- 姓名 / 性别 / 年龄 / 学历 / 目标岗位与级别
- 当前状态（在职/离职）/ 联系方式

### 职业轨迹
| 时段 | 公司 | 职位 | 核心项目 | 时长 |
|------|------|------|----------|------|

### 初筛结论
- 初筛结果：通过/待定/不通过
- 核心亮点：（与岗位匹配的关键证据）
- 待验证：（面试需重点确认的点）
- 硬伤预警：（如有）
```

### 附二：简历全文

简历原文（分段排版，便于面试时快速翻阅）。

### A. 面试前准备（5 分钟）

- 明确岗位定位和级别要求
- 准备评分维度
- 心理预期（简历呈现的能力水位预判）
- 需特别关注的风险点

### B. 必问主线（按优先级排序）

每个模块包含：

```markdown
### B1 模块名（对应能力维度）
> **考察目标**：一句话说明在测什么

- [ ] **必问题**：具体问题（基于简历内容定制）
  - 追问 1：...
  - 追问 2：...
- [ ] **移植题/延伸题**：将经验迁移到新场景
  - 关键判定：什么样的回答 = 达标，什么 = 不达标

**🔴 红灯信号：**
- 出现以下回答说明能力不足的具体表现
```

**必问主线的模块应覆盖该岗位的全部核心能力维度**（见下方「各岗位核心能力标准」）。

### C. 场景题（1-2 道）

- 基于岗位设计开放式情境题
- 明确评判标准
- 场景题应能区分"只会执行"和"能做判断"两种水位

### D. 风险识别清单

```markdown
| 风险项 | 探测方式 | 判定标准 |
|--------|----------|----------|
| （从简历中识别的每个风险点） | 对应哪道题可以探测 | 什么回答 = 风险确认 |
```

### E. 加分项探测（时间允许时）

- AI 工具使用
- 行业视野
- 玩家身份与付费习惯
- 其他岗位相关加分项

### F. 评分表

```markdown
| 维度 | 权重 | 评分标准（1-5） | 得分 | 备注 |
|------|------|-----------------|------|------|
| （覆盖该岗位全部核心能力维度） | | 5=...; 3=...; 1=... | | |

**评分等级参考：**
- 4.0-5.0：强烈推荐
- 3.5-3.9：推荐
- 3.0-3.4：待定（需二面验证）
- 2.5-2.9：谨慎
- <2.5：不推荐
```

### G. 结论区

```markdown
### 预判（面试前填写）
- 整体评价：...
- 主要优势：...
- 主要风险点：...

### 初试后填写
| 项目 | 内容 |
|------|------|
| 结论 | 录用 / 备选 / 不录用 |
| 级别判定 | L? |
| 核心理由 | |
| 关键证据（3条）| 事实→判断→风险 |
| 突出亮点 | |
| 主要顾虑 | |
| 二面建议考察重点 | |
| 面试官签名/日期 | |
```

## 各岗位核心能力标准

### 运营策划（L3）

| # | 能力维度 | 考察方向 |
|---|----------|----------|
| 1 | 活动 Owner 能力 | 能独立负责活动从目标设定到上线复盘的全流程 |
| 2 | 数据驱动优化 | 基于埋点/看板数据做归因分析并持续优化活动效果 |
| 3 | 商业化理解 | 理解分层付费与大 R 用户需求，能兼顾体验与营收目标 |
| 4 | 节奏与协同 | 可统筹排期并与研发、美术、数据等团队高效协作 |
| 5 | 方法沉淀 | 能把活动经验沉淀为模板或机制，提升团队复用效率 |

### 系统策划（L3）

| # | 能力维度 | 考察方向 |
|---|----------|----------|
| 1 | 多系统耦合 | 有多个系统间数据流转和接口边界设计经验 |
| 2 | 框架扩展 | 能从具体系统中抽象可复用框架，设计可扩展架构 |
| 3 | 快轨复用 | 能设计配置化/模板化机制，让同类系统快速搭建 |
| 4 | WHAT→HOW→BUILD 全链路 | 能独立定义需求并产出可开发文档 |
| 5 | Spec 交付 | 有清晰规格文档与配表产出能力 |

### 战斗策划（L3）

| # | 能力维度 | 考察方向 |
|---|----------|----------|
| 1 | 战斗系统化能力 | 能构建战斗规则与节奏体系，非单点技能 |
| 2 | 体验与数值平衡 | 能在手感、节奏与数值之间做取舍 |
| 3 | 全流程落地 | 文档/配置/联调/验收闭环 |
| 4 | 跨职能协作 | 能与程序/动画/特效有效协作 |
| 5 | 复盘迭代 | 基于数据与反馈持续优化战斗体验 |

### 主策划（L4）

| # | 能力维度 | 考察方向 |
|---|----------|----------|
| 1 | 方向定义 | 能定义产品玩法方向与长线节奏 |
| 2 | 全局架构 | 有跨系统顶层规划能力 |
| 3 | 团队管理 | 有团队机制建设与人才培养经验 |
| 4 | 跨职能决策 | 可与主美/主程/运营达成关键共识 |
| 5 | 品类与商业 | 对目标用户和商业化有体系认知 |

### 应届生（通用）

| # | 能力维度 | 考察方向 |
|---|----------|----------|
| 1 | 游戏热情与玩家理解 | 玩什么、为什么玩、花多少钱 |
| 2 | 思维逻辑与问题拆解 | 场景题中的结构化思考能力 |
| 3 | 学习速度与自驱探索 | 有无自发学习游戏设计/工具的证据 |
| 4 | 协作意识与表达能力 | 面试沟通中的表达组织 |

### PM / 项目管理

| # | 能力维度 | 考察方向 |
|---|----------|----------|
| 1 | PM 角色认知 | 目标定义 vs 执行协调，制度建设 vs 沟通驱动 |
| 2 | 制度发起 | 从 0→1 建立流程/规范的完整案例 |
| 3 | 数据与决策 | 项目级指标体系、人效度量、数据驱动决策 |
| 4 | 团队管理 | 管理幅度、绩效机制、人事决策权 |
| 5 | 风险预判与应急 | 提前识别风险 + 极限交付能力 |
| 6 | 产品理解 | 能将业务指标翻译为管理动作 |

## 通用思维考察（所有岗位必带）

在核心能力之外，面试清单应包含以下三个通用维度的探测题：

1. **AI 与进化力**：是否使用 AI 工具？用在什么场景？是否有工作流级改造？
2. **深度思考**：能否从数据/现象追到根因？有无 trade-off 分析或复盘方法论？
3. **第一性原理**：能否从底层逻辑推导方案？有无质疑既有做法的经历？

无证据不扣分，有明确证据应写入亮点并体现在评分中。

## 输出约定

- 文件命名：`{候选人姓名}-面试清单.md` 或 `{拼音}-interview-checklist.md`
- 存放位置（MyAgents 内）：`docs/narrative/面试/interviews/{拼音}_{岗位缩写}_{日期}/`
- 清单生成后，提醒用户是否需要发钉钉通知（参考 `interview-checklist-dingtalk` SKILL）
- 清单生成后，在 `docs/narrative/面试/已面试索引.md` 追加一行（如该文件存在）

## reference/ 目录说明

如果你在独立环境中使用本 SKILL（不在 MyAgents 仓库内），可在本目录下创建 `reference/` 子目录，放入：

```
reference/
├── 简历初筛清单_运营策划.md    # 岗位初筛清单（可选，有则优先参考）
├── 简历初筛清单_系统策划.md
├── 简历初筛清单_战斗策划.md
├── 简历初筛清单_主策划.md
├── 简历初筛清单_应届生.md
├── rubric_ops.json             # 岗位标尺（可选，用于对齐评分维度）
└── rubric_system_planning.json
```

Agent 生成清单时会优先读取 `reference/` 下的文件作为评判依据。无此目录时，按上方内置的核心能力标准生成。

## 禁止

- **不得臆测**：简历中未写明的经历或能力不得作为通过依据
- **不得角色拔高**：制作人/综合岗的兼职职责不等同于专岗能力
- **WHAT/HOW 不得臆测**：无明确的需求定义、目标设定、方案拆解表述时，不得判定为"体现高阶思维"

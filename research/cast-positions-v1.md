# 卷一人物位置总表——前情、反应与变化

> 基于金仙公主通感+转世希冀设定 | 穿越时间746年

---

## 前情（732—746，鱼穿越前发生的事）

### 732年：金仙公主去世

| 人物 | 和这件事的关系 | 影响 |
|---|---|---|
| **金仙** | 通感持续燃烧二十余年，最终承载不住。44岁卒于洛阳 | — |
| **玉真** | 亲眼看着唯一的同母姐姐在通感中熄灭。从此孤身一人 | 失去了世界上唯一"不需要解释就懂"的人。此后十余年她在每一个"走神"的年轻女子身上都会多看一眼 |
| **先生（李含光）** | 曾被请去帮金仙稳定通感。尝试了。失败了 | 核心创伤形成——"我没能救她"。此后几十年修行中这笔债一直在。当他后来见到鱼时的震动，有一半来自这里 |
| **司马承祯** | 金仙去世时他已90多岁（735年去世）。他知道金仙的情况。也许正是金仙的通感和消亡让他在临终前写下了第三段"观测记录"："南水有鱼。鱼不知水。至岸方醒" | 谶语的最后一段可能和金仙之死有直接关系——他在金仙身上看到了"窗大墙薄"的毁灭模式，因此补上了对下一个"异人"的预测 |

### 737年："一日杀三子"

| 人物 | 和这件事的关系 | 影响 |
|---|---|---|
| **唐玄宗** | 下令赐死三个儿子。签字的手 | 此后对太子的态度变成扭曲的混合：愧疚+恐惧+自欺 |
| **李林甫** | 和武惠妃联手推动。他想扶李瑁上位 | 押注失败（738年高力士推李亨立储）。从此和太子李亨是你死我活的结构性死局 |
| **高力士** | 在立储关头进言"推长而立"，推动李亨成为太子 | 他替这个帝国选了一个继承人——然后用此后十余年看着这个继承人被李林甫一刀一刀剜空 |
| **玉真** | 侄子（李亨）成了太子。她的哥哥（玄宗）杀了三个儿子 | 目睹皇室内部的自相残杀。"出家为道"的选择在这一刻被再次确认——离权力核心越远越安全 |
| **太子李亨** | "因为没人支持"而成了太子。这不是荣耀——是诅咒 | 他坐的位子下面埋着三个兄弟的尸体 |

### 744年：玉真削号

| 人物 | 和这件事的关系 | 影响 |
|---|---|---|
| **玉真** | 上书削去公主名号、归还食邑 | 从明处退到暗处。从"可以被弹劾的政治人物"变成"没有把柄的局外人"。放弃靶心，保留影响力 |
| **唐玄宗** | 批准了妹妹的请求 | 也许松了一口气——少一个需要关注的人 |
| **杨贵妃** | 745年册封为贵妃——几乎无缝衔接 | 玉真退，杨贵妃进。皇帝注意力的吸引源换了 |
| **先生** | 玉真削号意味着她的情报网络更隐蔽了——和道门的合作可以更深 | 也许正是在这个时间窗口，先生和玉真商定了"如果谶语中的人出现，放在你那里" |

### 744年：余小满入观

| 人物 | 和这件事的关系 | 影响 |
|---|---|---|
| **余小满** | 13岁。父亲刚去世。被道门从宣州送到长安玉真观 | 一个什么都不懂的孩子进了全长安最精密的情报机构 |
| **先生** | 安排了这件事。依据：道门评估小满有"微弱通感潜质"+"南水"（宣州在南方）符合谶语方向 | 他的真实心态不是"发现了一个人才"——是"也许她就是那条鱼。但上一个有通感的人（金仙）死了。这次我不能再让它发生" |
| **玉真** | 收下了小满。表面理由：道门推荐，聪慧可教 | **隐秘理由：这个女孩走神的样子像金仙。** 玉真不会对任何人说出这个念头。她甚至不确定自己是不是在自欺。但她开始把小满带在身边 |
| **沈姑姑** | 安排小满做最低级的杂务 | 不知道玉真的隐秘动机。只按规矩办事 |
| **清漪** | 观中资深女冠。看到又来了一个新人——不起眼的，安安静静的 | 不在意。小满太弱了，构不成威胁 |

### 746年秋：穿越时刻

| 人物 | 经历了什么 | 即时反应 |
|---|---|---|
| **鱼** | 灵魂坠入。通感洪流。四维信息碾压。什么都不知道 | 泪流满面。晕倒。梦里听到"不要怕" |
| **余小满** | 灵魂在通感爆发中消散——窗大墙薄，墙塌了 | 没有了 |
| **玉真** | 亲眼目击。看到小鱼僵住→流泪→眼神变了→倒下 | **三重感情同时发生：失落（不是金仙）+震惊（但来了别的东西）+保护欲（不管她是谁，她是我的人）** |
| **沈姑姑** | 被玉真叫出去。看到小鱼晕倒 | "又发作了。这次比以前严重" |
| **清漪** | 不在场（如果不在内堂）或在场但离得远 | 后来听说"小鱼又犯病了"——不以为意。但接下来几天她会发现：这个人不一样了 |
| **先生（茅山）** | 不在场。但道门的某种感应机制可能让他知道"长安方向有异动" | 很快就会动身来长安——"灯没灭？还是灭了？" |

## 卷一正文中的人物位置（746—749）

### 第一圈：鱼的日常世界（玉真观内）

| 人物 | 在卷一中的角色 | 变化弧线 |
|---|---|---|
| **鱼** | 主角。从什么都不知道到被卷入帝国最危险的漩涡 | 不知道自己是谁 → 学会用这具身体活着 → 被玉真启用 → 第一次触碰朝堂暗线 → 她提取的信息间接导致一个人的死 |
| **玉真** | 导师/观察者/保护者。也是一个正在处理"金仙没有回来"这个事实的人 | 从"也许她是金仙"的希冀 → 确认不是 → 转而被这个"新的东西"吸引 → 决定试着启用她 → 发现她的能力远超预期 → 开始面对一个问题："她到底是什么？" |
| **清漪** | 日常同僚/竞争者→合作者 | 从"不在意小鱼"→ 发现"这个人突然变聪明了"→ 警惕 → 鱼帮她补了一次漏洞 → 从敌意到冷淡的职业信任 |
| **沈姑姑** | 管事/标准执行者 | 始终按规矩办事。但她观察到了小鱼的变化——她不说，但她记下了 |

### 第二圈：道门

| 人物 | 在卷一中的角色 | 关键时刻 |
|---|---|---|
| **先生（李含光）** | 卷一中后段出场。来长安"看看这个孩子" | 他预期看到的是"微弱通感+也许是金仙的转世"。他实际看到的是"窗比我见过所有人都大——而且这不是金仙。这是完全不同的东西"。**他是全书第一个隐约感到"这个灵魂不属于这具身体"的人** |
| **道门网络** | 背景。信息传递渠道 | 先生和玉真之间的隐秘联络。在"谶书=死罪"的天宝长安，这条线本身就是悬在所有人头上的剑 |

### 第三圈：朝堂/后宅（鱼通过任务接触到的世界）

| 人物 | 在卷一中的存在方式 | 功能 |
|---|---|---|
| **李林甫** | 不出场。但他的名字和影子无处不在 | "天气"——每个人的行为都被他塑造。鱼在后宅和市井中听到的每一句"不要说""小心"都指向他 |
| **王鉷** | 可能间接出现——通过财务线索或后宅网络 | 鱼追查的某条线会经过他的管辖范围。他是绞杀机器的关键执行者 |
| **杨国忠** | 通过杨氏后宅网络间接存在 | 正在崛起。鱼在后宅社交中可能接触到和杨家有关的人 |
| **虢国夫人** | 可能在后宅社交场合出现 | 后宅网络的顶层节点。她的张扬本身就是信息——"这个人不怕任何人" |
| **韦子春** | 可以是卷一配角——京城著作郎，文人，后来和赵奉章有关 | 鱼在文人/道观圈子中可能接触到的"有良知的小人物" |
| **赵奉章** | 卷一结尾才出现他的名字——"咸宁太守被杖杀了" | 鱼提取的信息最终汇入他的二十条罪状。他死了。鱼不知道自己和这件事的关系 |

### 第四圈：历史人物（鱼生命中的过客/印记）

| 人物 | 在卷一中的出场方式 | 对故事的作用 |
|---|---|---|
| **杜甫** | 长安街头。替人写家书的穷书生。和鱼聊了几句米价 | 底层视角。**关键暗线：他的族兄弟杜位是李林甫的女婿——长安最穷的诗人和最有权的宰相通过一场婚姻连在同一张网上** |
| **王维** | 某次诗会或法事的边缘。安静的中年官员。鱼靠近时感到一阵说不清的平静 | 留悬念。不展开。为卷二铺路 |
| **李腾空** | 也许在某次任务中擦肩。李林甫的女儿，嘉猷观观主。真修行者 | "奸相之女选择了清白"——和鱼的"表演式修行"形成对照 |
| **高力士** | 名字被频繁提及但极少直接出场。"走高翁的路子""高翁那边有消息" | 他是帝国信息枢纽的代名词。鱼知道有这个人——但触碰不到 |
| **唐玄宗** | 永远是转述和远影。"圣人今天在华清池""圣人说了什么" | 氛围。一个在笑的老人的远影——那个笑让鱼不安 |
| **杨贵妃** | 某次宫廷法事边缘远远一瞥。"灯笼里的火" | 全卷一最安静的一秒。鱼看到的不是"祸水"——是"和我一样被困住的人" |
| **太子李亨** | 不直接出场。但他的处境是整个朝堂格局的暗中心 | 通过后宅线间接感知——被休的韦妃、被废的杜良娣、被牵连的各家。"全长安最孤独的人"不需要出镜就能让人心寒 |
| **寿王李瑁** | 也许在某个场合一闪而过。角落里一个沉默的年轻王爷 | 一秒。不需要更多。清漪说"不要看。不要问" |

## 卷一的情感暗线（不在剧情表面，但支撑一切）

| 暗线 | 谁知道 | 谁不知道 | 什么时候可能浮出水面 |
|---|---|---|---|
| **玉真曾希望小满是金仙的转世** | 只有玉真自己 | 所有人——包括鱼 | 也许全书中某个深夜，玉真对鱼说了一句极短的话——"你不是她。但你在这里。这就够了"。鱼不知道"她"是谁 |
| **先生的核心创伤是金仙之死** | 先生自己。也许玉真知道一部分 | 鱼 | 卷二或卷三。先生在某个时刻对鱼说："上一个有你这种窗的人，我没能救"。不说名字。鱼不知道那是一位公主 |
| **道门谶语在天宝长安是死罪** | 先生、玉真 | 鱼。以及朝堂上几乎所有人——他们不知道道门有这个东西 | 如果这条线被任何人触碰——杨慎矜案中的"谶书"罪名就是前车之鉴——整个茅山宗都会陷入灭顶之灾 |
| **鱼提取的信息最终汇入赵奉章的状纸** | 也许玉真知道链条的一部分。鱼不知道 | 鱼完全不知道赵奉章的存在 | 卷一结尾。"咸宁太守被杖杀了"——鱼听到这个消息时心里有一种说不清的不安。她不知道为什么 |
| **鱼不是这具身体原来的人** | 没有人确切知道。先生最接近感知到。玉真知道"变了"但不知道变成了什么 | 所有人。包括鱼自己——她不清楚记得自己的前世 | 这条线贯穿全书。是"我是谁"这个问题的底层 |

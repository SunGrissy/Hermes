## 三、L3 五项能力 · 必问题 + 追问 + 红灯信号

**必问题：**

**追问：**
- 这个活动的目标指标具体是什么（付费率？ARPU？参与率？）？目标数字是多少？最终达成了多少？
- 活动配置你自己做还是交给谁？用什么后台/工具？配置过程中出过错吗？
- 上线后第一天数据不及预期，你做了什么？有没有中途调整的案例？

**🔴 红灯信号：**
- 无法说出活动的具体目标数字，只说"提升收入"
- 全流程中缺少"复盘→调整"环节，活动做完就结束

### 3.2 数据归因与优化

**必问题：**
> 你在简历里提到「依数据提炼活动效果优化策划案」（天使纪元）和「高付费用户行为分析」（纳萨力克）——请举一个**你从数据中发现问题、做归因分析、并推动优化落地**的完整案例。用了什么数据工具/看板？看了哪些指标？

**追问：**
- 你日常看数据用什么工具？（BI看板？Excel？SQL？内部后台？）能描述一下你的数据工作流吗？
- 纳萨力克的"LTV指标精准达成预期目标"——LTV你怎么拆的？哪个环节是你优化的关键杠杆？
- 三谋回流体系你说"回流用户规模提升明显"——具体提升了多少？你怎么定义"回流用户"？口径是什么？次留提升了几个点？
- 你写过复盘报告吗？给谁看？报告里除了数据罗列，有没有归因分析和下一步行动建议？能举个例子吗？

**🔴 红灯信号：**
- 无法说出任何数据工具名称，或只说"看后台数据"但描述不出看什么
- 复盘停留在"数据罗列"层面，无法说出"因为X所以Y，所以下次做Z"的归因链
- 回流数据"提升明显"但追问后无法给出任何量化数字或对比基线

## 五、场景题（选 1–2 道，建议至少做 1 道）

### 场景题 A：存量回流

> **题目：** 你负责的一款已上线18个月的卡牌游戏，DAU从峰值30万跌到12万，月流水从5000万跌到1800万。制作人要求你在下个大版本（6周后上线）前，设计一套回流方案，目标是回流DAU占比达到当期DAU的15%，且回流用户7日留存≥25%。请现场讲讲你的方案思路。

**通过线（至少命中以下关键词组中的 3 组）：**

| 关键词组 | 说明 |
|----------|------|
| **指标口径** | 明确定义"回流用户"（如：离线≥N天的用户）、回流DAU占比计算方式、7日留存的起算点 |
| **用户分层** | 按流失时长/付费层级/活跃度分层，不同层级用不同触达策略和激励力度 |
| **归因分析** | 先分析流失原因（内容断档？付费压力？竞品分流？），再针对性设计回流钩子 |
| **触达渠道与节奏** | Push/短信/社群/邮件等多渠道组合，回流前预热→版本当天召回→回流后承接的时间节奏 |
| **协同** | 需要跟研发确认回流礼包/补偿方案的开发排期，跟市场/社群协调外部触达资源 |

**🔴 不通过信号：** 只说"发礼包拉回来"，无分层/无归因/无指标定义/无节奏设计。

---

### 场景题 B：线上事故

> **题目：** 周五晚8点，你负责的限时付费活动上线2小时后，玩家社群爆发投诉——活动商城中一个限量礼包的价格配置错误（标价6元，实际应为648元），已有约2000名玩家购买。你现在怎么处理？请按时间线讲你的操作步骤。

**通过线（至少命中以下关键词组中的 3 组）：**

| 关键词组 | 说明 |
|----------|------|
| **止损优先** | 第一时间下架/关闭该商品或活动入口，防止损失扩大 |
| **影响评估** | 统计受影响用户数、涉及金额、道具是否已使用/流通，评估对经济系统的影响 |
| **分层处理** | 区分恶意囤积 vs 正常购买用户，制定差异化回收/补偿方案 |
| **协同与上报** | 立即同步制作人/技术/客服，明确各方职责和时间线；准备公告话术 |
| **复盘与防范** | 事后复盘配置流程漏洞，建立双人校验/灰度发布等防错机制 |

**🔴 不通过信号：** 不知道第一步应该止损；只想着"全部回收"不考虑用户体验；没有复盘意识。

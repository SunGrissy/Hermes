## C. 核心摸底区（40-50 分钟）

### C1 从 0 到 1 搭建——全流程认知

> **摸底目标**：了解游戏直播运营从零搭建的完整步骤和关键决策点

- [ ] **你在边锋做掼蛋直播从 0 到 1，能不能按时间线讲讲，第一个月做了什么、第二个月做了什么、每个阶段的优先级是怎么定的？**
  - 追问 1：搭建初期最先要解决的 3 个问题是什么？
  - 追问 2：如果重新来一次，有什么会做不同的？
  - 追问 3：从零开始到直播间能稳定产出数据，最短需要多久？

- [ ] **你说搭建了"直播-产品-平台"三角运营模型，能展开讲讲这个模型是什么？三个角各自的职责和交互关系是什么？**
  - 追问：这个模型是一开始就想清楚的，还是踩了坑之后总结的？踩了什么坑？

**我们想知道的**：搭建直播运营体系的正确顺序和最小可行路径是什么。

---

### C2 快手平台——流量机制与实操经验

> **摸底目标**：验证和补充我们对快手直播流量机制的认知

- [ ] **你在禅游做过快手直播 SOP，能讲讲快手跟抖音在游戏直播上最大的区别是什么？同样的主播/内容，在两个平台的数据差多少？**
  - 追问 1：快手的流量分发机制你怎么理解？冷启动阶段具体是什么表现？
  - 追问 2：快手对游戏直播有没有什么特殊的扶持或限制政策？
  - 追问 3：你觉得快手做游戏直播，最大的坑是什么？

- [ ] **账号权重这个东西，你实际操作中是怎么感知的？一个新号从 0 开始养，大概需要多久能稳定出自然流量？养号过程中最容易失败的原因是什么？**
  - 追问：你有没有养失败过的号？失败的原因是什么？

- [ ] **你做的是棋牌，我们是捕鱼——都有比较强的视觉观赏性，但捕鱼更注重大 R 体验和付费深度。你觉得这两个品类在直播运营上有什么共性和差异？直播间的内容设计和主播要求会有什么不同？**
  - 追问：捕鱼直播间天然有"爆屏""大鱼"这种观赏性画面，你觉得这种视觉冲击力在直播间数据上会怎么体现？对停留和互动的拉动大吗？

**我们想知道的**：快手做游戏直播的真实体感，特别是"养号养不起来"的原因和解法；以及棋牌经验迁移到捕鱼的可行性。

---

### C3 短视频与短直联动——实操链路

> **摸底目标**：搞清楚"短直联动"到底怎么落地执行

- [ ] **你简历里提到"探索短视频推流直播的起量方式"，能具体讲讲你们当时是怎么做的？效果怎么样？**
  - 追问 1：切片是谁做的？一条切片从直播结束到发布出去大概多久？
  - 追问 2：你们试过哪些类型的短视频？哪种对直播间导流效果最好？
  - 追问 3：短视频发布的频率和时间点有没有讲究？
  - 追问 4：有没有用 AI 工具做切片或内容生产？

- [ ] **你觉得"短直联动"这件事的关键卡点在哪？是内容产能、人手、还是方法论？一个人能同时管短视频和直播吗？**

- [ ] **你做过的最成功的一次短视频导流直播间是什么样的？数据表现？你觉得为什么那次效果好？**

**我们想知道的**：短直联动的最小执行团队、工作流、关键动作和常见失败原因。

---

### C4 主播管理——选拔、培养、成本

> **摸底目标**：了解主播管理的核心机制和成本结构

- [ ] **你搭建了主播分层选拔标准，能讲讲你的分层逻辑吗？什么样的主播算好主播？你筛选主播最看重的 3 个指标是什么？**
  - 追问：签约主播、公会主播、CPS 主播，这几种模式你都做过吗？各自的优缺点和适用场景是什么？

- [ ] **你把主播单 A 成本从 83 降到 28，能讲讲具体怎么做到的？调了什么？**
  - 追问：不同层级主播的合作成本大概在什么区间？（不用说具体数字，量级就行）

- [ ] **你做了 21 个可复刻人设案例，能举两个例子说说"人设打造"具体是怎么操作的？效果怎么衡量？**

- [ ] **主播管理最头疼的问题是什么？主播流失率高吗？怎么控制？**

**我们想知道的**：主播合作的成本结构、管理方法、常见问题。

---

### C5 数据与复盘——怎么判断做得好不好

> **摸底目标**：了解直播运营的数据体系和分析方法

- [ ] **你日常看哪些数据指标？有没有自己搭过数据看板？看板里包含什么？**
  - 追问 1：场观、停留时长、互动率、转化这几个指标，你觉得哪个最重要？为什么？
  - 追问 2：你怎么判断一场直播"做得好"还是"做得差"？标准是什么？

- [ ] **你做过的一次最有价值的数据复盘是什么？发现了什么问题？怎么解决的？**

- [ ] **直播运营的数据复盘，最常见的误区是什么？你见过同行踩过哪些坑？**

**我们想知道的**：好的直播数据体系长什么样，复盘应该怎么做。

---

### C6 竞品分析——怎么看竞品的直播

> **摸底目标**：学习竞品分析的实操方法

- [ ] **你在禅游做过竞品分析（微乐 vs 禅游），你当时是怎么做的？看了哪些维度？数据从哪来？**
  - 追问 1：竞品的直播间你们多久去蹲一次？怎么记录？
  - 追问 2：有没有用第三方工具？哪些好用哪些鸡肋？
  - 追问 3：竞品分析最终落到了什么动作上？你说推动了产品优化，具体是怎么推的？项目组/产品那边好推吗？

**我们想知道的**：竞品分析的实操方法、有效的工具、如何把分析转化为行动。

---

### C7 投放——直播间投流怎么做

> **摸底目标**：了解直播投放的基础逻辑和效果评估

- [ ] **你在做直播运营的过程中有没有接触投放？快手的磁力金牛/粉条你用过吗？**
  - 如果用过：追问投放策略、定向设置、效果评估方法
  - 如果没用过：追问你理解的投放跟运营的关系是什么？你觉得投放应该怎么配合直播？

- [ ] **你见过的直播投放做得好的案例是什么？ROI 大概在什么水平算健康？**

**我们想知道的**：投放跟内容运营是什么关系，怎么配合效果最好。

## D. 我们的场景讨论（10-15 分钟）

> 目标：把我们的真实困境抛出来，看她怎么分析和建议。既是考察也是咨询。

- [ ] **我们是一个捕鱼游戏，注重大 R 体验，画面观赏性也比较强，但目前快手直播跟竞品差距很大。协作链路是项目组→投放的直播运营→直播团队的直播运营→主播，中间信息损耗很大。你觉得这种结构最大的问题是什么？如果是你来做，你会怎么切入？**
  - 追问：你觉得第一个月应该先做什么？优先级怎么排？

- [ ] **如果给你一个预算有限（不能大量砸钱投流）的情况，你会怎么在快手把直播间做起来？**

- [ ] **你觉得项目组（制作人侧）应该管到什么程度？哪些应该项目组决策，哪些应该放手给运营？**

**关键判断**：她的回答是否体现了对"项目组 vs 运营方"分工的清晰理解——这个理解本身对我们就很有价值。

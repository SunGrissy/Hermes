# 戴顾琰｜精细化运营策略实验方向面试清单

目标方向：礼包推荐 / Push 策略 / 策略实验 / 精细化运营分析  
候选人定位：策略产品、推荐策略、AI 产品与量化研究背景候选人  
生成日期：2026-04-30

## 一、面试前预判

这次面试不按“纯数据分析师”口径看，而是看候选人在以下方向的潜力：

- 礼包推荐：能否理解游戏用户分层、付费节奏、礼包定价与长期价值之间的关系。
- 策略实验：能否独立设计实验组、对照组、主指标、护栏指标，并识别伪归因。
- Push 推送：能否平衡触达、打扰、转化和长期留存。
- 精细化运营：能否把运营问题拆成“人群 → 场景 → 策略 → 实验 → 指标 → 复盘 → 下一轮迭代”。

简历呈现出的优势是推荐策略、Push、人群分层、AI 文案赛马、用户调研和指标追踪。主要风险是候选人可能更偏策略产品，不一定具备独立做严谨实验、游戏付费分层和礼包商业化策略的能力。

面试核心不是问“会不会 SQL/Python”，而是判断她能否把一个运营问题拆成可验证、可迭代、可沉淀的策略实验。

## 三、必问主线

### 1. 推荐策略与人群分层

考察目标：判断她是否真正理解“不同用户给不同内容、礼包、Push”的底层逻辑。

- [ ] 你在百度 Push 或美团推荐项目里，具体是怎么做人群分层的？
  - 分层依据是什么：行为、兴趣、地理、消费、流失风险，还是模型分数？
  - 分层之后，每一层的策略差异是什么？
  - 策略上线后，如何判断是“分层有效”，而不是整体流量变化？

- [ ] 如果我们有一批游戏玩家：新手、回流、轻付费、中 R、大 R、沉默用户，你会怎么设计礼包推荐策略？
  - 每类用户推荐什么礼包？
  - 主指标是什么：收入、转化率、ARPPU、留存、还是长期 LTV？
  - 哪些用户不该强推礼包？

红灯信号：

- 只说“按用户画像推荐”“千人千面”，但说不清分层变量、策略差异和验证方式。
- 只按活跃度分层，不考虑付费能力、生命周期、流失风险和长期价值。
- 把礼包推荐简单等同于电商商品推荐。

### 2. 策略实验设计

考察目标：判断她是“会做策略复盘”，还是“能独立设计实验”。

- [ ] 你简历里提到通知栏文案流量赛马，具体怎么赛马？
  - 怎么分流？
  - 实验组和对照组怎么设？
  - 是否控制人群、时间、内容质量差异？
  - 怎么判断某条文案赢了？

- [ ] 如果实验结果 CTR 提升，但次日留存下降，你怎么判断这个策略该不该继续？

- [ ] 如果 Push 带来 DAU 增长，但用户投诉、退订或卸载增加，你怎么处理？

红灯信号：

- 只看上线前后指标，不谈对照组、护栏指标和长期副作用。
- 把“策略上线后指标变好”直接等同于“策略造成增长”。
- 不主动识别样本偏差、节假日、渠道波动、同期版本内容等干扰项。

### 3. Push 推送策略

考察目标：判断她是否理解 Push 的核心矛盾：触达、打扰、转化、长期留存之间的取舍。

- [ ] 百度 APP Push 项目里，你负责的是策略定义、素材供给、模型协同，还是效果复盘？
  - Push 的发送对象怎么选？
  - 发送时机怎么定？
  - 频控怎么做？
  - 如何避免用户疲劳？

- [ ] 如果我们要给流失 7 天的中 R 玩家推一个回流礼包，你会怎么设计 Push？
  - 推送文案怎么分层？
  - 礼包内容怎么定？
  - 什么时候推？
  - 如何判断是礼包有效，还是玩家本来就要回流？

红灯信号：

- 只关注点击率，不关注退订、反感、卸载、投诉和长期活跃损伤。
- 只讲文案优化，不讲人群、时机、频控和对照组。
- 不区分召回型 Push、促销型 Push、内容型 Push 的策略差异。

### 4. 礼包推荐与商业化敏感度

考察目标：这是候选人简历中最缺的部分，需要重点补测。

- [ ] 你怎么看“礼包推荐”这件事？它和内容推荐、商品推荐有什么不同？
  - 游戏礼包推荐的目标是什么？
  - 对免费用户、低付费、中 R、大 R，策略应该有什么差异？
  - 什么情况下不应该推高价礼包？

- [ ] 某活动礼包整体收入不错，但次留和 7 日留存下降，你会怎么分析？
  - 拆哪些人群？
  - 看哪些指标？
  - 如何判断是不是过度收割？
  - 下一版怎么改？

红灯信号：

- 只讲 GMV、转化率和收入，不讲玩家体验、付费节奏、长期价值和反噬风险。
- 不理解大 R、中 R、低付费用户对礼包价值感的差异。
- 无法解释为什么有些用户“不推礼包”反而更合理。

### 5. 数据基本功与归因能力

考察目标：确认她能不能压住“伪归因”。

- [ ] 百度项目里“归因 DAU +54w”是怎么计算的？
  - 归因窗口多长？
  - 有没有自然增长、渠道波动、节假日影响？
  - 有没有 holdout 或对照组？
  - 她本人负责了哪一段？

- [ ] 美团 NPS 从 55.68% 到 88.91%，这个提升如何证明来自推荐模块？
  - 样本是否一致？
  - 是否有幸存者偏差？
  - 是否有问卷设计变化？
  - 有没有同期其他改动？

红灯信号：

- 无法解释指标口径。
- 无法区分相关和因果。
- 说不清自己在数据链路中的具体贡献。

## 四、核心场景题

### 场景题 1：礼包推荐实验

我们准备上线一个“回流玩家专属礼包推荐”功能，目标是提升回流 7 日留存和付费转化。

请你设计完整实验方案：

- 目标用户怎么定义？
- 用户分几层？
- 每层礼包怎么设计？
- 实验组和对照组怎么设？
- 主指标和护栏指标是什么？
- 实验跑多久？
- 什么结果算成功？
- 如果收入涨了但留存跌了，怎么决策？

优秀回答应包含：

- 用户生命周期与付费分层。
- 实验组、对照组或 holdout 设计。
- 主指标和护栏指标同时存在。
- 对短期收入与长期留存的 trade-off 判断。
- 下一轮策略迭代方案。

不达标回答：

- 只说“给回流用户发高性价比礼包”。
- 只看收入，不看留存和流失。
- 无对照组，无归因意识。

### 场景题 2：Push 精细化运营

一款游戏版本更新后，我们想通过 Push 拉回沉默用户，但担心打扰过度。

请你设计 Push 策略：

- 哪些人推，哪些人不推？
- 文案怎么分层？
- 推送频率怎么控？
- 怎么判断用户反感？
- 怎么评估 Push 的真实增量？

优秀回答应包含：

- 召回人群筛选。
- 发送时机与频控。
- 不同用户价值层的 Push 差异。
- 对照组或不触达组。
- 退订、卸载、投诉、次日留存等负向指标。

不达标回答：

- 只优化标题和文案。
- 只看点击率。
- 不考虑用户疲劳和长期损伤。

## 五、风险识别清单

| 风险项 | 探测方式 | 风险确认标准 |
|---|---|---|
| 偏产品，不偏分析 | 追问本人在项目中的具体职责 | 只讲 PRD、协调、方案，不讲数据定义和实验判断 |
| 实验方法不严谨 | 问流量赛马和归因 DAU | 无对照组、无护栏指标、无偏差控制 |
| 游戏商业化理解不足 | 问礼包推荐场景题 | 只讲转化和 GMV，不讲用户生命周期和付费节奏 |
| 数据结果夸大 | 追问 +54w DAU、NPS 提升 | 无法说清计算口径和个人贡献 |
| 职业方向不稳定 | 问为什么不继续做策略产品 | 回答仍然明显偏产品经理路径 |
| AI 经验停留在包装 | 问 AI 文案赛马、AI 推荐接口具体使用 | 只讲“接入 AI”，说不清 AI 在策略链路中如何提升效率或效果 |

# 游戏直播运营（快手方向）

## 岗位职责

1. 负责游戏产品在快手等直播平台的整体运营策略制定与执行跟踪，对直播渠道的用户增长和前端数据指标负责；
2. 搭建直播数据分析体系，基于漏斗各层数据（场观、停留、互动、转化）定位问题、驱动优化，定期输出数据复盘报告；
3. 统筹主播运营，包括现有主播的能力提升、内容方向优化，以及新主播/达人的拓展与合作评估；
4. 规划短视频与直播的联动策略，推动"内容生产→短视频分发→直播间导流"的闭环运转；
5. 负责直播间相关投放策略的制定与效果评估，协同投放团队优化 ROI；
6. 跟踪竞品直播运营动态，定期输出竞品分析，为策略调整提供依据；
7. 作为项目组与外部直播运营团队之间的核心对接人，确保双方目标对齐、信息高效传递。

## 任职要求

1. 本科及以上学历，2 年以上**游戏直播运营经验**，有在快手平台操盘过完整项目的经验优先；
2. 熟悉快手等主流直播平台的流量分发机制、账号权重规则和内容推荐逻辑；
3. 有实际的短直联动运营经验，能说清楚从内容生产到直播间导流的完整链路和关键动作；
4. 数据敏感，能独立搭建直播数据看板，通过数据拆解定位问题而不是凭感觉判断；
5. 有主播孵化或达人合作经验，了解不同合作模式（签约/公会/CPS）的适用场景和成本结构；
6. 有直播投放经验（磁力金牛/粉条等），能制定投放策略并评估效果；
7. 沟通清晰，能在项目组和直播执行团队之间高效传递信息、对齐目标；
8. 热爱游戏，对 MMO/RPG 品类有了解者加分。

## 加分项

- 有从 0 到 1 搭建过游戏直播运营体系的经验
- 有跨团队协调经验，做过"项目组侧"而非"直播公会侧"的运营角色
- 能带着方法论来，而不只是带着执行经验来

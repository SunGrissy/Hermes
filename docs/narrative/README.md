# 叙事类文档（非 Agent 运行时规程）

本目录收纳与 **Multica 工单附件、面试材料、会议议程、业务需求与 JD、人在回路计划** 等相关的 Markdown；**不包括** `.cursor/skills`（Agent 规程）、`docs/superpowers`（系统工程规格）、`shared-memory`（运行期共享记忆）。

## 子目录

| 子目录 | 内容 |
|--------|------|
| [multica-tasks/](multica-tasks/) | Multica / 本地桥工单长文需求（`@doc:` 路径以此为准） |
| [面试/](面试/) | 候选人面试清单、评价、已面试索引（初筛清单仍在 `performeval/面试/`） |
| [meetings/](meetings/) | 会议议程、Kickoff 类材料 |
| [requirements/](requirements/) | 业务需求、JD、摸底表、赛季设计叙述等 |
| [plans/](plans/) | 策划线待办、流程 rollout 等「人在回路」执行计划 |
| [workflows/](workflows/) | Feature 设计—开发—上线等工作流叙述 |

## 维护约定

- 新增叙事文档时先选子目录；边界不清可先放 `requirements/` 并在 PR/WORK_LOG 里说明。
- 不要在叙事目录存放密钥或仅机器可用的路径备份。
- **总索引：** [DOC_HUB.md](../DOC_HUB.md)

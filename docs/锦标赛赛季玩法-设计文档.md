# 捕鱼锦标赛赛季玩法 — 设计文档

> **版本**: v0.2 · WHAT 对齐稿  
> **日期**: 2026-04-16  
> **状态**: WHAT 对齐 + HOW 拆解待讨论  
> **定位**: 6 月版本核心机制更新，替换现有常驻活动，成为永久基础设施

---

## 术语表

| 术语 | 定义 |
|------|------|
| **积分** | 捕鱼成功时概率掉落的数值，用于日榜排名和进度奖。每日日榜结算后清零 |
| **段位经验** | 日榜结算时按排名发放的经验值，用于提升段位。与积分是两套独立数值——积分决定排名，排名决定获得多少段位经验 |
| **段位** | 赛季内的成长等级（共 12 段），累积段位经验升段。赛季结束完全重置 |
| **赛段** | 一个赛季分为 2 个赛段，每赛段 3 周。赛段 1 开放段位 1-7，赛段 2 开放段位 8-12。段位进度跨赛段继承 |
| **巅峰排位赛** | 每赛段第 3 周开放的高级日榜，仅当前赛段满段玩家可参与 |
| **双倍 buff** | 巅峰赛核心奖励——开火消耗双倍、收益双倍，影响所有场景 |
| **进度奖** | 附属于锦标赛的累积积分阶梯奖励，有独立的重置周期（运营可调），不影响日榜排名 |
| **名牌** | 赛季限定的个性化展示组件，关键段位达成时获得，赛季结束退场 |

## 一、WHAT 层：体验意图与核心机制

### 1.1 核心命题

**要解决什么问题？**

现有常驻活动无段位体系，玩家缺乏中长期目标感和身份认同。锦标赛赛季玩法是一次机制大升级——在不改变核心捕鱼操作的前提下，叠加一套「积分 → 排名 → 段位 → 赛季 → 巅峰赛」的竞技-成长复合系统。

**北极星体验**：每天有排名可冲、每周有段位可升、每赛季有身份可争。高玩有巅峰赛的专属机制体验，普通玩家有进度奖和段位奖励的持续正反馈。

### 1.2 赛季时间轴

│  段位 1-7 可升                       │  段位 8-12 解锁                      │

│                                      │                                      │

│                                      │                                      │

### 1.3 系统架构总览

```
捕鱼行为（概率事件）
  |
  v
积分掉落（与 MaxBet x FishScore 相关，高值有衰减）
  |
  |---> 进度奖（累积积分触发，独立重置周期）
  |
  v
分组日榜（按 MaxBet 分组，日结算）
  |
  v
段位经验（按日榜排名发放）       ← 注意：积分 ≠ 段位经验
  |
  v
段位提升（累积段位经验升段）
  |-- 关键段位奖励：赛季限定名牌 + 其他奖励
  |
  v
巅峰排位赛（赛段末周开放，满段可入）
  |
  v
巅峰赛奖励：双倍 buff（限时，需手动开启） + 限定炮台外显
```

### 1.4 玩家视角体验走查

#### 小鱼（低 bet 休闲玩家）—— 一天 / 一赛季

> 今天上线打了半小时鱼，右上角弹了个"积分 +320"，看了眼进度条快满了，再打两把领了个进度奖。顺手瞄了眼日榜，排第 38 名。晚上结算推了条消息"恭喜升段"，段位 3 了。
>
> 赛季打完我到了段位 5，虽然没摸到巅峰赛的边，但每天升段的感觉还不错，段位 5 的名牌挺好看的。听说段位 7 的更稀有，下赛季试试冲一冲。

#### 中鱼（中 bet 活跃玩家）—— 一天 / 一赛季

> 早上上线先看日榜，昨天排第 11，差一名就多拿 20 经验。今天目标冲到前 10。中午打了几把 Boss 连爆了一波高分鱼，积分蹭蹭涨，看了眼排名已经到第 6。下午收手不打了，有点紧张怕被反超。晚上结算——第 8 名，升段了！段位 6，还差 1 段就能进巅峰赛。
>
> 第 3 周最后两天终于满了 7 段，赶上了巅峰赛的末班车。虽然排名靠后没拿到 buff，但体验了一把"只有满段才能进"的感觉。赛段 2 继续冲，最终到了段位 10。

#### 大鱼（高 bet 大 R）—— 一天 / 一赛季

> 赛段 1 第 12 天满了 7 段，第 3 周直接进巅峰赛。巅峰赛里全是老对手，大家都在拼谁打得多。最后一天冲刺拿到前 5——拿到双倍 buff 和限定炮台外显，手动开启 buff 的一瞬间炮台变了个样，爽。
>
> 赛段 2 带着 buff 冲段位 8-12，开 buff 的时候积分翻倍、日榜上自己名字旁边有个金标，其他人看得到。第 6 周巅峰赛又拿了前 5，buff 刷新续上。这一整个赛季，巅峰赛就是我的主战场。

### 1.5 核心机制（WHAT 级定义）

#### ① 积分掉落

- 捕鱼成功时概率掉落积分
- 积分数量与 MaxBet 和 FishScore 正相关，但非线性——高 MaxBet 和高 FishScore 有衰减
- 掉落有浮动区间，避免纯计算感，但方差需控制（排行榜场景不能让运气权重过高）

#### ② 分组日榜

- 按 MaxBet 为主要依据分组
- 每日结算，按排名发放段位经验
- 分组中使用机器人辅助（冷启动阶段比例较高，逐赛季递减至尾部填充）

#### ③ 段位系统

- 共 12 个段位：赛段 1 开放 1-7，赛段 2 开放 8-12
- 段位经验累积升段，低段快升（1 天/段）、高段慢升（不超过 3 天/段，按段位设计目标人群计）
- 赛季间完全重置（初始策略），预埋"历史最高段位"标记
- 关键段位（非每段）发放赛季限定名牌 + 其他奖励
- 段位奖励价值平滑分布——不满段玩家的体验靠段位奖励撑住，而非 buff 追赶

**升段节奏目标**：

| 玩家类型 | 赛段 1（段位 1-7） | 赛段 2（段位 8-12） |
|---|---|---|
| 提前满段（高活跃） | ~14 天完成 | ~14 天完成 |
| 延迟满段（中活跃） | ~21 天完成 | ~21 天完成 |
| 不满段（低活跃） | 赛段 2 继续追赶 | 停在最终段位，靠已拿奖励收获满足 |

**不满段者设计定位**：不满段者的追赶路径不依赖购买 buff——buff 是中段玩家冲顶端的加速器，不是低段玩家追中段的救命稻草。不满段者在赛段 2 继续按自己节奏爬段，每升一段有段位奖励，体验依然完整。

#### ④ 赛季赛段节奏（3+3）

- 每赛季 6 周（42 天），无间隔，赛季间无缝衔接
- 赛段 1（第 1-3 周）：开放段位 1-7
- 赛段 2（第 4-6 周）：开放段位 8-12
- 段位进度跨赛段继承（赛段 1 达到 7 段的进度保留到赛段 2）
- 两赛段节奏差异为自然结果：赛段 2 的段位更高、升段难度更大，同样时间内可升段数更少

#### ⑤ 巅峰排位赛

- 每赛段第 3 周开放（即第 3 周和第 6 周）
- 进入条件：达到当前赛段最高段位（赛段 1 = 段位 7，赛段 2 = 段位 12）
- 赛段第 3 周、第 6 周内任意一天满段即可进入后续的巅峰赛日榜
- 日榜制，按排名顺位发放奖励
- 面向高 bet 玩家的高级机制，给到达顶端的玩家继续追求的目标

#### ⑥ 双倍 buff

- **核心定位**：给高玩的新机制体验，投放渠道为巅峰赛，强调"来之不易 & 你很牛"
- 效果：开火消耗双倍，同时收益双倍
- **需要手动开关**：玩家手动开启/关闭 buff，开启状态需明显特效提示（参考大作战处理方案，视觉设计和表现手法需做差异化）
- 影响范围：所有鱼、所有积分，包括锦标赛积分（产品一贯设计语言，不做例外）
- 来源：巅峰赛排名（主渠道）+ 限量礼包（付费容错，每人限购，有门槛，Win2Pay 感受）
- 视觉外显：buff 可挂载在限定炮台外显上，**仅巅峰赛获得的 buff 有外显**，礼包 buff 无外显。外显装备与否不影响 buff 是否生效
- buff 强度统一（双倍），不做分层
- 累积规则：不可叠加，只可刷新——新获得时从当前时间点重新计时
- 持续时长按巅峰赛排名分档（排名越高覆盖越久），具体天数待数值讨论

#### ⑦ 赛季限定名牌

- **定位：当季身份证**——不是永久收藏品，是"这个赛季我到过这个段位"的可视化证明
- 仅关键段位发放（低段位不发，保持稀缺性），v1.0 每个关键段位 1 款设计
- 赛季结束随段位一起重置，自然退场
- 不做降级展示、荣誉柜、集齐体系（观察玩家自然需求后再决定）
- "历史最高段位"加入个人主页，用标记保留记忆，轻量且够用即可

### 1.6 进度奖（中间反馈层）

- 累积积分触发的阶梯奖励，独立于日榜排名
- **有独立重置周期**：进度奖的重置周期是运营调控手段（如 2 天重置 vs 4 天重置，影响拿满进度奖的难度，但不影响日榜排行）
- 功能：在日榜排名结果出来前提供持续正反馈
- 投放内容包含积分加成 buff（节奏化投放，见 HOW 层）

### 1.7 设计约束与红线

| 约束 | 说明 |
|------|------|
| 核心操作不变 | 选鱼、调炮倍、用技能——锦标赛不引入新操作 |
| 双倍 buff 影响一切和消耗有关的场景 | 包括锦标赛积分，不做场景豁免 |
| buff 强度不分层 | 统一双倍，不做 1.5x/2x 区分（实现复杂度 + 玩家体感） |
| 赛季无间隔 | 作为永久基础设施，赛季间无缝衔接 |
| 段位完全重置 | 初始策略，软重置留给数据驱动的未来大版本 |
| 名牌非永久 | 当季身份证，赛季结束退场 |
| v1.0 范围控制 | 日榜机制变化、同质多款名牌、软重置等留给后续迭代 |

## 二、WHAT → HOW 拆解

### 2.1 积分掉落

**WHAT**: 与 MaxBet × FishScore 正相关但非线性衰减，有浮动。

**HOW 方向**:
- 衰减曲线需对齐已有掉落活动的衰减模型
- 浮动比例控制：锦标赛场景下方差需比普通场景收窄（排行榜公平性要求）
- 已有的运气兜底机制需覆盖锦标赛积分场景（策略方向检查，比如长时间不下鱼的负面体验可能会因此放大）

**⏳ 数值专项**:
- [ ] 高 bet 积分效率倍率目标（高 bet vs 低 bet 的理想效率比）
- [ ] 衰减曲线参数（与已有活动对齐）
- [ ] 浮动区间的上下限比例
- [ ] 运气保底触发条件和补偿量（在锦标赛语境下的校准）

### 2.2 分组日榜

**WHAT**: 按 MaxBet 分组，日结算，机器人辅助。

**HOW 方向**:
- MaxBet 分组档位划分
- 组内人数（影响排名体验：太大则中游无望，太小则波动大）
- 机器人行为逼真度要求（命名、行为模式、积分曲线）
- 机器人逐赛季递减计划

**⏳ 数值专项**:
- [ ] MaxBet 分档数量和每档范围
- [ ] 每组人数（含机器人）
- [ ] 机器人比例：赛季 1 初始比例 → 长期稳态比例
- [ ] 机器人积分模型（模拟真实玩家分布）

**⏳ 交互专项**:
- [ ] 日榜界面信息层级：排名、积分差距、升段所需排名
- [ ] buff 持有者标记：在日榜中展示哪些玩家有双倍 buff + 获取渠道引导

### 2.3 段位系统

**WHAT**: 12 段（7+5），低段快升高段慢升，赛季完全重置，段位奖励平滑分布。

**HOW 方向**:
- 段位经验需求曲线（决定每段的"体感天数"，详见 1.5③ 升段节奏目标表）
- 每个日榜排名档位对应多少段位经验
- "历史最高段位"标记的展示位置
- 段位奖励的价值梯度：确保每个段位的奖励都值得追求，不集中在顶部

**⏳ 数值专项**:
- [ ] 12 段的经验需求表（配合升段节奏目标）
- [ ] 日榜排名 → 段位经验的映射表（按分组大小调整）
- [ ] 段位奖励价值分布校准
- [ ] 名牌发放的关键段位确认（如段位 5、7、10、12）

**⏳ 交互专项**:
- [ ] 段位界面：当前段位、经验进度、距离下一段的差距、历史最高标记
- [ ] 升段动效和反馈设计

### 2.4 赛季赛段节奏

**WHAT**: 6 周 = 3+3，段位继承，赛段 2 开放更高段位。

**HOW 方向**:
- 赛段切换时的系统行为（界面提示、新段位解锁动效）
- 赛季间无缝衔接的系统行为（重置 + 新赛季引导）

**⏳ 交互专项**:
- [ ] 赛段切换通知和引导流程
- [ ] 新赛季开始的引导流程（渐进式揭露，不一次性展示全部机制）
- [ ] 首次参与锦标赛的新手引导

### 2.5 巅峰排位赛

**WHAT**: 赛段第 3 周开放，满段可入，日榜制，核心产出双倍 buff。

**HOW 方向**:
- 巅峰赛的分组逻辑（是否独立分组、与普通日榜的关系）
- 排名 → buff 时长的分档设计
- 巅峰赛内的竞争体验：所有参与者多数持有上期 buff，buff 在内部相互抵消，真正竞争力回归操作和投入

**⏳ 数值专项**:
- [ ] 巅峰赛总人数上限 / 分组策略
- [ ] 排名 → buff 时长分档表（例：前 5 / 前 20 / 前 50 / 前 100 对应不同天数）
- [ ] 每档 buff 时长是否能覆盖到下一期巅峰赛的验证
- [ ] 满勤高玩的 buff 续航上限验证（不叠加只刷新机制下的最大持续时间）

**⏳ 交互专项**:
- [ ] 巅峰赛入口和资格展示
- [ ] buff 倒计时和状态展示
- [ ] 限定炮台外显的视觉规格

### 2.6 双倍 buff 生态控制

**WHAT**: 影响一切，需手动开关，不叠加只刷新，礼包可追赶但无外显。

**HOW 方向**:

关键推演（已在智囊团讨论中验证）：
1. 头部玩家在普通日榜冲段时，有无 buff 不太影响排名结果（他们本身就是头部）
2. buff 影响的是分数绝对值——需在日榜中做标记，让同榜玩家知情
3. 巅峰赛内部，参与者多数持有 buff，效果相互抵消
4. 跨赛季滚雪球：被"不叠加只刷新 + 时长分档 + 赛季重置"三重机制控制

**⏳ 数值专项**:
- [ ] 限量礼包的价格门槛和限购数量
- [ ] 有 buff vs 无 buff 玩家在日榜中的积分差异模拟
- [ ] buff 时长分档对跨赛季优势的量化影响

**⏳ 交互专项**:
- [ ] buff 手动开关的交互方式和位置
- [ ] 开启状态的特效设计（参考大作战，需差异化）
- [ ] 关闭状态的提示（避免玩家忘记自己有 buff 未开启）

### 2.7 赛季限定名牌

**WHAT**: 当季身份证，关键段位单款发放，赛季退场。

**HOW 方向**:
- 确认发放名牌的关键段位
- 每赛季 1 款名牌的美术规格
- 赛季结束退场的系统行为

**⏳ 交互专项**:
- [ ] 名牌获得时的展示和反馈
- [ ] 名牌在游戏内的展示位置和尺寸规格
- [ ] 赛季结束时名牌退场的提示方式

### 2.8 进度奖

**WHAT**: 累积积分的阶梯奖励，独立重置周期，运营调控手段。

**HOW 方向**:
- 重置周期选择（如 2 天 / 3 天 / 4 天），周期越短 → 拿满越容易 → 激励更频繁 → 奖励单次价值需降低
- 进度奖阶梯的积分门槛设定
- 积分加成 buff 的投放位置和时机

**⏳ 数值专项**:
- [ ] 初始重置周期建议（配合赛段节奏）
- [ ] 进度奖阶梯数量和积分门槛

## 六、未来迭代规划

以下机制不纳入 v1.0，但已在设计讨论中明确了方向，作为后续版本的储备。

### 6.1 赛季软重置（数据驱动触发）

**触发条件**：当以下监控指标中 2 项以上触发警戒线，启动设计（预留 2 赛季开发周期）。

从赛季 1 起埋点追踪：

| 指标 | 计算方式 | 警戒阈值 |
|------|----------|----------|
| 前 3 天段位恢复率 | 上赛季段位 N 玩家，新赛季前 3 天回到 N-2 的比例 | 连续 2 赛季 > 60% |
| 首周日均时长趋势 | 赛季 N 首周 vs 赛季 1 首周 | 连续下滑 |
| 中段停留时长 | 段位 4-8 平均停留天数 | < 赛季 1 的 50% |
| 赛季首日回流率 | 上赛季活跃玩家的新赛季回归率 | 连续下降 |
| 巅峰赛参与率 | 满段玩家中实际参与巅峰赛的比例 | 连续下降 |
| 段位奖励领取率 | 可领未领的比例 | 上升趋势 |

**设计方向**：软重置需包在大版本中——不仅是段位回退，需配合新段位包装、新奖励梯度、新巅峰赛规则的全面升级。

### 6.2 日榜周期性机制变化

**设计方向**：以 3+2+2 Day 为周期，在目标层（"关注什么"）而非操作层（"怎么打鱼"）注入变化。
- 常规期（3 天）→ 挑战期（2 天，限时任务如"连续捕获 3 条同种鱼额外奖励"）→ 冲刺期（2 天，进度奖投放积分加成 buff）

**前置条件**：v1.0 核心循环稳定运行 1-2 个赛季后，基于数据判断是否需要。

### 6.3 名牌同质多款

**设计方向**：达段时从 2-3 款同质名牌中选择（质感相同，风格差异），制造选择感和社交话题。

**前置条件**：v1.0 上线后观察玩家对名牌的社交讨论热度和个性化诉求。

## 七、附录：设计决策记录

| 决策点 | 结论 | 关键理由 |
|--------|------|----------|
| 双倍 buff 是否影响锦标赛积分 | 是 | 产品 4 年一贯设计语言，豁免反直觉 |
| 双倍 buff 需要手动开关 | 是 | 消耗双倍需要玩家主动决策，配明显特效 |
| 赛季段位重置策略 | 完全重置（初始），数据驱动演进 | 新系统无基线，先采集数据 |
| 名牌永久 vs 限时 | 当季身份证，赛季退场 | 追本溯源：名牌是当季身份信号，非永久收藏品 |
| 名牌数量 | v1.0 关键段位单款 | 降低首版美术负担，按需迭代 |
| buff 累积规则 | 不叠加只刷新 | 控制满勤高玩的时长堆叠上限 |
| 巅峰赛 buff/非 buff 是否分组 | 不分组 | 分组后"大家都有=价值归零"，体验差 |
| 礼包 buff 是否有外显 | 无（外显仅巅峰赛独有） | 保留巅峰赛的排他性奖励价值 |
| 不满段者追赶路径 | 靠段位奖励平滑分布，非 buff 追赶 | buff 是中段冲顶端的加速器，非低段追中段的救命稻草 |
| 循环新鲜感 | v1.1 迭代，v1.0 先跑核心 | 避免首版范围过大 |
| 机器人使用策略 | 逐赛季递减，长期仅尾部填充 | 避免被识破的信任危机 |
| 段位总数 | 12 段（赛段 1: 7 段 + 赛段 2: 5 段） | 匹配"频繁小成就"节奏目标，低段 1 天/段、高段 ≤3 天/段 |
| 进度奖重置周期 | 独立于日榜，运营可调 | 作为运营调控手段，不同周期影响拿满难度但不影响排行 |

# 快手游戏直播 · 竞品蹲守执行手册

> 目标：用 2 周时间摸清主要竞品在快手直播侧的完整画像，产出竞品矩阵对比表。
> 本手册供项目组内部执行人使用，不发给直播运营。

## 二、每日蹲守任务

### 2.1 每日检查（约 15-20 分钟）

每天在 3 个时段检查所有竞品账号是否在播：

| 时段 | 检查时间 | 操作 |
|---|---|---|
| 上午场 | 10:00-11:00 之间查一次 | 打开快手，逐个搜竞品账号，看是否"直播中" |
| 下午场 | 15:00-16:00 之间查一次 | 同上 |
| 晚间场 | 20:00-21:00 之间查一次 | 同上 |

如果发现在播，记录到**每日登记表**（见 2.2），然后**进去看 15-20 分钟**做详细观察（见 2.3）。

### 2.2 每日登记表

每天填一行，没在播的填"未开播"：

| 日期 | 竞品 | 账号 | 上午是否在播 | 下午是否在播 | 晚间是否在播 | 观察到的开播时间 | 观察到的下播时间 | 备注 |
|---|---|---|---|---|---|---|---|---|
| 4/17 | 竞品A | 账号1 | 否 | 否 | 是(20:15) | 约19:30 | 未等到 | |
| 4/17 | 竞品A | 账号2 | 否 | 是(15:20) | 否 | 约14:00 | 约17:00 | |

> 2 周积累下来，就能画出每个竞品的开播规律（哪几天播、什么时段播、播多久）。

### 2.3 详细观察记录（每次进直播间看 15-20 分钟时填写）

| 观察维度 | 记录内容 |
|---|---|
| **基础信息** | |
| 日期/时间 | |
| 竞品/账号 | |
| 当前在线人数 | 进入时记一次，离开时记一次 |
| 主播是谁（昵称/备注） | 跟上次是否同一个人 |
| **内容** | |
| 在播什么内容 | 游戏实况/攻略讲解/PVP对战/版本体验/聊天互动/其他 |
| 内容节奏 | 是纯玩游戏还是有明确的环节设计（如整点活动、答题、抽奖） |
| 主播风格 | 一句话描述（如"话多搞笑型""技术流讲解型""安静陪玩型"） |
| 主播对游戏的熟悉程度 | 明显是深度玩家 / 一般了解 / 感觉不太懂 |
| **互动设计** | |
| 弹幕活跃度 | 估算每分钟大约几条弹幕 |
| 弹幕质量 | 真实对话为主 / 刷屏为主 / 机器人感觉 |
| 福利/活动 | 有什么福利？形式是什么？（礼包码/红包雨/抽奖/粉丝团福利） |
| 转化引导 | 主播怎么引导关注/下载/加粉丝团的？话术是什么？ |
| **制作水平** | |
| 画面质量 | 清晰度、有无 OBS 叠加层（边框/横幅/倒计时/logo） |
| 多机位/特殊效果 | 有没有画中画、绿幕、特效 |
| **截图** | 截 1-2 张直播间画面，存档备查 |

## 三、短视频观察（每周做一次，约 30 分钟/竞品）

每周挑一个时间，翻一遍每个竞品账号的短视频主页：

| 观察维度 | 记录内容 |
|---|---|
| 本周新发短视频条数 | |
| 内容类型分布 | 游戏集锦 X 条 / 直播切片 X 条 / 版本预告 X 条 / 攻略 X 条 / 搞笑 X 条 / 其他 X 条 |
| 播放量区间 | 大部分在什么量级？有没有明显的爆款？ |
| 爆款视频链接（播放量最高的 1-2 条） | |
| 是否有"直播切片"类内容 | 有 → 说明在做短直联动；没有 → 说明直播和短视频是割裂的 |
| 切片质量 | 粗剪（直接截一段）/ 有二次加工（加字幕/配音/特效） |
| 发布频率规律 | 每天发 / 每周几条 / 集中在直播前后发 / 无明显规律 |
| 评论区 | 有没有引导关注/直播的置顶评论？ |

## 五、两周执行节奏

## 执行提醒

1. **用自己的日常快手号观察即可**，不需要专门注册新号
2. **截图留档**——直播间画面、短视频主页、爆款内容都截图保存，汇报时有据可查
3. **不需要全天盯着**——每天 3 次检查 + 碰到在播时看 15-20 分钟，总耗时约 30-45 分钟/天
4. **记录要及时**——当场看完当场记，不要攒到周末补，细节会丢失
5. **第一周重在发现，第二周重在验证**——第一周看到的规律可能是巧合，第二周要确认是不是稳定的模式

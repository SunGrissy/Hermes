# 2026年Q1 产品组AI应用成果

## 整体情况

一季度产品组（16人，覆盖运营/数据/系统策划/UE/战斗策划/PM）全面推进AI融入日常工作，形成三条主线：**用AI造工具**（非技术岗位用AI搭建业务工具和数据平台）、**用AI拓能力**（突破岗位技能边界，做到以前做不到的事）、**沉淀方法论**（从"用了"到"用好了"，提炼可复用的工作流和框架）。

## 六、组织建设与制度保障

### 进化系数

AI能力作为绩效乘法层系数（0.7~1.1），H1首次正式启用：
- 不进化：系数<1.0，业务结果打折
- 持续进化：系数≥1.0，业务结果放大
- 连续两周期无AI产出：系数上限降至0.7，评级天花板锁死B

### 北极星小组

技术AI先行者组成的基础设施团队，Q1成果：
- 统一分支检查框架（10+项检查全自动运行）
- 79次可疑提交拦截（8次确认回退）
- 272处配置错误检出（含30处进出包问题）
- 每日代码自动Review覆盖前端+配表+部分后端

## 下一步方向

1. **从事务走向策划核心**——AI工具链从日常事务性工作（日报、排期、配表）延伸到策划核心工作（设计辅助、多视角决策、知识库驱动）
2. **多视角Agent圆桌**——多Agent从玩家/数据/技术/竞品视角讨论Feature设计，倒逼策划想更全面
3. **知识库驱动设计辅助**——基于项目自身经验（而非通用知识）的策划辅助系统
4. **竞品视频→设计文档**——从竞品/参考原型录屏中自动提取UI框架、交互流程、设计决策点
5. **自动化度量体系**——工时对比、流程耗时埋点，从"感觉快了"变成"数据证明快了"
6. **工具索引上线**——5月与北极星联合，汇总已有工具+贡献榜，避免重复造轮子

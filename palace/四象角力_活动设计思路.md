## 体验意图声明

> **我不是一个人在转，我的每一下都在为我们的阵营而战——归属感、荣誉感和集体竞争的燃烧，让日常操作变成热血时刻。**
>
> 核心情感：归属 × 荣誉 × 紧迫。不是"我在玩一个活动"，而是"我在为我的阵营拼"。

### 分层体验目标

| 用户层 | 情绪目标 | 行为目标 |
|--------|----------|----------|
| **大 R** | **贡献感**："我是阵营的支柱，我的投入让阵营更强" | 高频参与角力时刻，购买 G4 提升倍率，带动阵营积分 |
| **中 R** | **追赶感**："再努力一把就能上个台阶" | 通过 Win2Pay 折扣降低门槛，补票旧款神器提升倍率 |
| **零付费** | **归属感**："阵营需要我，我的参与有意义" | 日常 spin 贡献基础积分，关注阵营排名，在角力时刻集中参与 |

> 设计边界：大 R 体验是"阵营支柱"而非"碾压一切"。普通玩家体验是"我有意义"而非"大 R 决定一切我只是陪跑"。soft cap 和日赛点制服务于这个边界。
>
> 负面情绪防护：大 R 选了弱势阵营 → 天时轮转 + 日赛点制保底不会全程挨打；零付费连续输 → 里程碑保底奖励 + "参与就有意义"的情绪兜底。

## 术语表

| 术语 | 定义 |
|------|------|
| spin | 核心玩法操作（类 slots 的一次转动） |
| 神器 | 高价物品类之一，主要提供数值价值，本文特指生肖守护神系列（共 12 个，分 G1~G4 四组） |
| 战魂 | 高价物品类之一，主要提供外显价值，本文特指 G4 配套的 3 个生肖战魂 |
| 羁绊 | 集齐特定组合的神器后激活的额外属性加成效果 |
| 系列羁绊 | 集齐全部 12 个生肖神器后激活的羁绊效果（区别于 G1 的分组羁绊） |
| G1~G4 | 生肖神器的四个分组：G1 虎兔龙（东·青龙）、G2 蛇马羊（南·朱雀）、G3 猴鸡狗（西·白虎）、G4 猪鼠牛（北·玄武） |
| 阵营积分 | 玩家 spin 产出的、归属于所在阵营的积分，用于阵营排名 |
| 个人积分 | 玩家 spin 产出的、归属于个人的积分，用于个人排名和里程碑奖励 |
| 赛点 | 阵营每日排名转化的积分（日冠军 3 分、亚军 2 分等），用于活动最终阵营排名 |
| 角力时刻 | 每日特定时段（如 12:00/20:00），阵营积分 ×2 的集中爆发窗口 |
| 天时轮转 | 每天一个阵营获得"天时"加持（阵营积分 ×1.5），四天一轮 |
| soft cap | 个人每日对阵营积分的有效贡献上限（边际递减，非硬上限） |
| Win2Pay | "先玩再买"折扣机制：通过活动参与积累折扣券，降低购买门槛 |
| 补全计划 | 根据玩家已有生肖神器数量，推荐个性化打包购买方案 |

### 1.3 活动目标

**北极星指标**：G4 首两周累计销售额（对标 G2/G3 同期表现，目标待数值团队基于历史数据设定基线）

**分层参与指标**：

| 指标 | 定义 | 目标方向 | 数据来源 |
|------|------|----------|----------|
| 大 R 参与率 | VIP15+ 中参与过四象角力的占比 | ≥ 历史活动基线 | 活动日志 |
| 中 R 付费转化率 | VIP8-14 中活动期间首次购买生肖神器的占比 | 高于非活动期常规转化率 | 订单+活动日志 |
| 免费玩家日均参与次数 | VIP0-7 活动期间日均 spin 次数 | ≥ 常规日均 spin 的 80% | spin 日志 |
| 旧款补票率 | 活动期间 G1-G3 神器新增购买量 / 活动前月均量 | > 1.5x | 订单 |

**健康度指标**：

| 指标 | 定义 | 目标 | 数据来源 |
|------|------|------|----------|
| 阵营积分基尼系数 | 四阵营总积分的离散程度 | < 0.3（阵营间相对均衡） | 阵营积分日志 |
| soft cap 触发率 | 日均触发 soft cap 衰减的玩家占活跃玩家的比例 | 5-15%（仅头部大 R 触发） | 积分日志 |
| 角力时刻峰值参与比 | 角力时刻 DAU / 当日总 DAU | > 40% | 在线日志 |
| Win2Pay 折扣券使用率 | 活动期间获得折扣券的玩家中实际使用购买的比例 | > 30% | 券+订单 |

**角力质量指标**：

| 指标 | 定义 | 目标 | 数据来源 |
|------|------|------|----------|
| 日冠军分布均匀度 | 活动期间四阵营获得日冠军的次数分布 | 无阵营 0 次夺冠 | 赛点日志 |
| 角力时刻胜负翻转率 | 角力时刻 30 分钟内阵营排名发生过翻转的时段占比 | > 50%（多数角力有悬念） | 阵营积分日志 |
| 最终赛点极差 | 冠军阵营赛点 − 末位阵营赛点 | < 总赛点的 40%（不出现一骑绝尘） | 赛点日志 |

> 具体目标值需数据团队基于历史活动数据设定基线后填入。以上方向性指标用于定义"看什么数字"，精确目标在数值评审时确定。

### 1.4 已决策清单

| # | 决策 | 依据 | 影响下游 |
|---|------|------|----------|

## 二、核心玩法设计

### 2.1 四象机台 — spin 规则

活动期间开放"四象角力"专属机台。机台图案包含四种阵营符号（青龙/朱雀/白虎/玄武）+ 常规奖励图案。每次 spin 产出两层结果：个人奖励 + 阵营积分。

**阵营积分规则** [决策]：

| 转出结果 | 阵营积分 | 备注 |
|----------|----------|------|
| 本阵营图案 | 高分 | [BUILD] 具体倍数待数值标定，参考 ×3 |
| 其他阵营图案 | 低分 | [BUILD] 参考 ×1 |
| 本阵营图案连线 | 爆分（显著高于单图案） | [BUILD] 参考 2 连 ×10 / 3 连 ×50，由数值标定 |
| 四象齐出（极稀有） | 全阵营共享大奖 | [BUILD] 预期频率由数值控制，意图：仪式感级别的全服稀有事件 |

### 2.2 生肖神器积分倍率 [决策 D8]

**倍率意图**：全系列神器都贡献倍率，但本阵营神器加权更高。拥有 12 个神器的大 R 无论选哪个阵营倍率都很高 → 选阵营变成纯策略判断。

> [BUILD 参考] 参考参数：本阵营 +0.3/个、其他阵营 +0.1/个、基础 1.0。具体参数由数值团队基于大 R 平均神器持有量和预期积分分布标定。验证方式：用 2025 年 8 月持有率数据模拟各 VIP 段平均倍率分布，确认阵营间差异在天时轮转可调平的范围内。

### 2.3 大 R 优势保障（三层）[决策]

| 层级 | 机制 | 效果 |
|------|------|------|
| 次数 | 免费 spin 次数有限，可购买额外次数 | spin 越多 → 积分越多 |
| 倍率 | 生肖神器持有量 → 积分倍率加成 | 同样次数，大 R 产出更多 |
| 投入 | 若机台有下注机制，投入越高产出越大 | 大 R 敢下大注 |

### 2.4 "角力时刻"— 脉冲式爆发 [决策]

每天 2~3 个角力时刻（时段待运营确认，建议参考 DAU 峰值时段）：

- 持续 30 分钟 [参考，UX 可建议调整]
- 期间阵营积分 ×2
- 实时展示四阵营积分对比，形式需有竞争感和紧迫感 [体验意图，具体交互形式由 UX 设计]
- 时段结束时按瞬时排名发放小额即时奖励

### 2.5 个人贡献上限 soft cap [决策 D4]

**意图**：大 R 正常投入时不受限制，极限氪金时边际递减。体验上"正常玩感觉不到 cap 的存在，只有极端投入时效率才降低"。希望仅 5-15% 的头部大 R 会触发衰减。

> [BUILD 参考] 参考模型：前 X 分 100% 有效 → X~2X 50% → 2X+ 20%（边际递减，非硬上限）。X 参考值：大 R 正常日均 spin 产出积分的 70%。由数值团队基于历史 spin 数据标定，上线前模拟验证触发率。

## 四、阵营平衡机制

### 4.1 天时轮转 [决策]

每天一个阵营获得"天时"，当日所有 spin 阵营积分 ×1.5。四天一循环。

```
Day 1: 东方天时 ×1.5 → Day 2: 南方 → Day 3: 西方 → Day 4: 北方 → 循环
```

### 4.2 "新神降临"加持 [决策]

G4 上架后的**首个北方天时日**，额外叠加"新神降世"→ 当日北方阵营 ×2.0（仅此一日）。

### 4.3 日赛点制 [决策 D2]

```
每日结算阵营日排名：冠军 3 赛点 / 亚军 2 / 季军 1 / 末位 0
活动最终排名按总赛点决定
```

### 4.4 预期体验动态

```
前期（G4 上架前/刚上架）：
  东方凭 G1 持有率优势领先 → "东方太强了"
中期（北方天时 + 新神降临）：
  大 R 买了 G4，北方积分暴涨 → "北方翻盘了！"
后期：
  赛点胶着，天时日成各阵营"主场" → 全程有悬念
最后一天：
  冲刺 → 付费+活跃双峰值
```

集齐 12 个生肖神器后获得两层奖励：

### 7.1 系列羁绊 [决策 D6]

## 八、核心商业化转化循环

```
    参与四象角力（spin）
          │
          ▼
    发现倍率不够 ──────────────────┐
    （别人积分涨得快，我的倍率低）  │
          │                        │
          ▼                        │
    补票旧款 / 购买 G4 神器        │
          │                        │
          ▼                        │
    倍率提升 → 积分产出更高 ◀──────┘
          │
          ▼
    排名上升 → 更多奖励
          │
          ▼
    集齐进度推进 → 接近 12 个
          │
          ▼
    系列羁绊 + 完结外显的吸引力
          │
          ▼
    继续补票 / 推荐给身边玩家
```

> 这个循环是整个活动的商业引擎。数值团队标定倍率差（+0.3/+0.1）、soft cap、折扣力度时，需确保循环中每个环节的转化动力足够但不过载。

## 十、风险场景预案

| # | 风险场景 | 风险等级 | 预案方向 |
|---|----------|----------|----------|
| R1 | 阵营人数极度不均（如 80% 选东方） | 高 | 方案 A：选择阶段展示各阵营当前人数引导分流；方案 B：设人数 soft cap（超过均值 X% 后提示"该阵营已满，推荐其他阵营"但不强制）[待定] |

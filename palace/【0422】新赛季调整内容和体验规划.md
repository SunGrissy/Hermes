# 逻辑规则（执行案）

> 开发需要关注的逻辑规则，包括各种同步处理、边界情况等

> 这部分内容应该包含逻辑实现的需求和方案，需要根据和技术沟通的情况维护到最新

## 第一部分：移除

1.  移除赛季任务
    
2.  移除养成等级的金币进度奖和W2P礼包
    
3.  移除养成物满级后的战魂大奖
    

## 第二部分：改动

1.  【强化材料】现在通过锦标赛进度奖获取。捕获boss不再掉落【强化材料】
    
2.  赛季活动和养成物等级现在分为上下段开放。
    
    1.  第一阶段结束时，会进行一次段位奖励结算
        
    2.  第二阶段是一个新的MasterSeasonRank，但养成物是同一个，会开放新的养成等级和徽章
        
    3.  第二阶段开启前，玩家可以继续积攒【强化材料】和【突破材料】
        
    4.  第二阶段开启期间，玩家依旧可以养成第一阶段的等级。
        
    5.  第二阶段开启时，第一阶段养满的用户可以继续养成第二阶段的等级
        
3.  段位改为根据养成等级决定
    
4.  界面调整：
    
    1.  界面布局参考大作战的样式
        
        1.  将原有的页签移除
            
        2.  将原有的养成物列表放置在左侧
            
        3.  bp，段位的入口，放置在原先下方2个入口的位置
            
        4.  段位冲刺的位置也移动至礼包位附近

## 第三部分：新增

1.  **新增养成突破机制：**
    
    1.  新增积分【突破材料】
        
    2.  现在赛季养成的部分等级，需要消耗【突破材料】进行升级。
        
        1.  未完成突破时，暂时不可继续强化。
            
        2.  【强化材料】获取不受到突破影响
            
        3.  【突破材料】通过锦标赛排行榜奖励获得
            
2.  **新增养成bp**
    
    1.  bp分为普通版和付费版
        
    2.  bp根据玩家养成物等级分段，如（1~50/51~100/101~150...）
        
    3.  bp进度根据玩家养成物等级。养成物强化到多少级，就可以领取多少级的奖励。
        
    4.  购买付费版本，并领取全部奖励后，才可以接取下一阶段的bp
        
    5.  养成bp享受礼包全部增益
        
        1.  增益包括
            
            1.  等级膨胀
                
            2.  炮倍膨胀（五一版本新增）
                
            3.  超能金币增益
                
            4.  充值金币增益
                
        2.  活动期间，若玩家的相关增益提升，则进行金币补发
            
        3.  若玩家解锁了后段bp，同时提升增益，则已经完成的bp金币也要补发
            
    6.  补发
        
        1.  玩家未领取的bp奖励、付费奖励，特权提升补发金币，未领取的部分，在活动结束后需要通过邮件补发
            
        2.  若玩家已购买当前阶段bp付费版本，但是没有领取完，且后续等级已经到达了可以领取奖励的等级。此时若bp时间结束，不进行补发。
            

# 体验规划

1.  **新增的bp**
    
    1.  整体上平替了原来的金币进度奖，起到金币补充的作用；
        
    2.  付费部分的定位是一个面向中大R的超值金币礼包，同时作为等级同步的一个额外的获取渠道。
        
    3.  由于自身是计算充值金币增益的，所以对于充值金币增益有一定的引流效果。
        
    4.  与原先的金币进度奖相比，缺失了一些炮倍提升和火力全开的buff，这部分从运营规划上不想继续投放，不再进行补充
        
2.  **移除内容**
    
    1.  W2P礼包上半赛季没了，且没有平替。
        
        1.  个人感觉这里是一个比较划算的购买高价物的位置，体验挺好的。主要是用作小额碎片的高性价比获取。
            
        2.  有其他渠道的话不是特别严重的问题
            
    2.  任务没了之后，现在段位积分没有其他的获取来源了。由于缺乏其他的段位积分产出，现在段位只能和养成单线关联。导致现在段位其实是养成的一个延时结算的进度奖。
        
        1.  个人感觉在原先的设计里，任务是长时间挂机后，最后为了补积分的目标导向作用。
            
        2.  但是在新的设计中，体验周期被锦标赛拉长了，也没必要放一个任务增加参与感。
            
    3.  满级战魂大奖上半段移除，改为到下半段天赋树中投放
        
        1.  结合宝藏悬赏的体验，感觉锦标赛到赛季的反馈路径是个半自动的活跃体验；虽然奖励变少了，但是好像也不会对参与动机有特别负面的影响
            
3.  **功能核心变动：**
    
    1.  作为核心的养成，现在所有的产出都是来源于锦标赛。所以现在赛季整体和锦标赛是紧密结合的。
        
    2.  调整后赛季的核心进一步向养成调整，并且明显向锦标赛引流，导致段位会进一步与锦标赛产生关联。但是锦标赛本身是有段位的，这两个可能会存在一定的重复问题。
        
        1.  个人意见是不做明显的关联。并非是一个值得纠结的问题。
            
    3.  关于【强化材料】【突破材料】上下段继承
        
        1.  如果数值能够把控好产出和消耗，可能并不是问题。
            
        2.  如果担心玩家攒了太多材料，可以一口气完成后半段的赛季，可以通过消耗和产出的膨胀，压低攒材料的收益。这里的积分是独立于金币的，所以膨胀也比较安全。比如：
            
            ![未命名绘图2.drawio.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Lk3lbmbGR8dAJOm9/img/08cd4143-7f70-4f81-afcf-1e9b37775e05.png)
            
        3.  如果这个方法也不太行，就换积分。可以下半段开启前，结合线上数据分析后再行决策
            
4.  **体验分层**
    
    1.  由于锦标赛自身对于练度的要求，各档玩家的结算段位会更加直接的与练度相关联。
        
    2.  由于突破机制的限制，大R不再能一次性快速获得直升满级的所有突破材料，需要持续的活跃。
        
    3.  小R需要更高强度的活跃，来弥补和大佬之间的练度差异。
        
    4.  在完成速度上，大R玩家更容易在锦标赛中取得高名次，各类材料的获得数量也高于中小R玩家，因此可以相对较早的满级
        
    5.  中小R不太容易取得高名次，但也不会次次垫底。赛季养成这边只是速度慢，通过持续的活跃依然是可以满级的，但是需要比大R更长的时间；相对的，活跃天数的容错也会比大R低一些
        
5.  **等级同步相关**
    
    1.  通过bp去投放更多的同步道具，把同步这个功能撑起来
        
    2.  通过这个机制鼓励玩家积极参与到锦标赛和赛季活动中来
        
6.  **交互改动**
    
    1.  功能中心转移到养成的话，还是大作战这个布局是比较合理的
        
    2.  先前接到反馈说历史养成物的菜单不太好看，红点找不到；这次用大作战这个方案可以更好的解决这个问题

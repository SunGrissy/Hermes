# 二、新内容

### 三国巅峰场——五一新赛季预热 $\color{#0089FF}{@郑杉}$ 

1.  活动定位：福利发放，吸引玩家持续留存到五一版本
    
2.  主要投放：金币奖励
    
3.  设计思路：
    
    1.  完成每日任务，领取现金和储备金
        
    2.  五一版本活动内容分段预告，提升期待感
        
    3.  五一节日期间登录可在活动界面领取预热储备金和五一节日福利
        

# 三、主要活动

### 一根线消耗活动（清明节主题包装？） $\color{#0089FF}{@李振源}$ 

1.  活动定位：周期活跃消耗，每周进度重置
    
2.  主要投放：朱雀神君（或玄武）、炮台、炮翅、英雄、超时空
    
3.  需要兼顾版本福利，保留打卡BP设计，按VIP发金币奖励
    

### 炮倍福利迭代 $\color{#0089FF}{@刘泊霆}$ 

1.  活动定位：面向活跃用户的消耗返利活动，可以低炮倍挂机获得稳定收益
    
2.  已知问题：活动奖励吸引力较低，对非付费用户没有形成追求
    
3.  优化方向：提高奖励数量和金币消耗量，增加活动吸引力
    
4.  具体设计：
    
    1.  由固定金币奖励改为随机转盘/福袋
        
    2.  完成每日任务给转盘充能
        
    3.  总进度奖励可升级转盘/福袋
        
    4.  预期体验：奖励越来越多，吸引用户活跃和付费
        
        1.  活跃用户：周期内奖励越来越多，形成活动追求
            
        2.  付费用户：付费提升基础倍数，增加后续留存活跃
            

### Bingo改免费，消耗换高价物 $\color{#0089FF}{@李振源}$ 

1.  活动定位：金币消耗换高价物
    
2.  优化方向：抽卡代币增加渔场掉落形式，通过活跃消耗可完成一定轮数的bingo
    
3.  其他设计：
    
    1.  不设掉落上限，增加掉落难度梯度 / 增加每日掉落上限
        
    2.  多轮BINGO，前X轮固定奖励，后续奖励循环，增加消耗深度

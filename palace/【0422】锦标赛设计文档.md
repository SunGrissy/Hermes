# 玩法规则

### 积分掉落

1.  任意渔场内，至少X炮倍捕获宝藏守卫可掉落锦标赛积分
    
    1.  使用炮倍越高&捕获守卫倍数越高，掉落积分数量越多
        
    2.  排名积分用于领取进度奖和小组排名，每日0点积分清零
        

### 进度奖励

1.  根据玩家获得的积分数量，领取每日进度奖励
    
2.  进度奖里的作用是提供捕鱼的及时反馈，通过反复领取的奖励引入锦标赛循环
    
3.  进度奖规划：
    
    1.  为满足各档位用户的体验和奖励一致性，对进度奖做以下设计要求
        
    2.  以4档左右奖励为一轮，每轮奖励类型相同，随轮数增加奖励数量和进度要求
        
        1.  例如：每轮奖励为 金币 - 道具 - 激光 - 赛季养成材料
            
        2.  首轮奖励保证玩家使用最低炮倍开火5分钟可完成
            
        3.  后续轮次进度要求和奖励数量等比提升，直到使用满炮倍开火5分钟可完成一轮
            

|  | 奖励1 | 奖励2 | 奖励3 | 奖励4（核心） |
| --- | --- | --- | --- | --- |
| 第1~3轮 | 100积分<br>10万亿金币 | 100积分<br>道具宝箱\*1 | 200积分<br>激光\*1 | 300积分<br>养成材料\*300 |
| 第4~6轮 | 300积分<br>30万亿金币 | 300积分<br>道具宝箱\*3 | 600积分<br>激光\*3 | 900积分<br>养成材料\*900 |
| 第7~10轮 | 500积分<br>50万亿金币 | 500积分<br>道具宝箱\*5 | 1000积分<br>激光\*5 | 1500积分<br>养成材料\*1500 |
| …… |  |  |  |  |
| 第X轮后（上限） | 10000积分<br>1000万亿金币 | 10000积分<br>道具宝箱\*100 | 20000积分<br>激光V\*10 | 30000积分<br>养成材料\*30000 |

### 小组匹配与机器人

1.  玩家登录/打开活动界面时，即根据当前所处段位进行小组匹配，详细规则如下
    
    1.  单组人数不超过40人，期望处于30~35人
        
    2.  按照不同段位，小组将分配数量不等的机器人，段位越高机器人数量越少
        
    3.  玩家开始匹配时，优先加入同段位未满员小组，若其他小组均满员，则创建新的小组
        
2.  玩家未获得排名积分时，不显示排行榜内信息，同时排行榜内其他玩家也无法查看该玩家信息
    
    1.  实际玩家已经提前分配小组，但是由于没有积分，故不参与排名
        
3.  机器人按照用途分为以下几类
    
    1.  【积分门槛】：按结算剩余时间增长积分，排名结算时必定达到指定积分区间
        
    2.  【平均分】：积分按照小组内真人玩家的平均分进行计算，有增长延迟
        
    3.  【氛围组】：按照特定行为涨分的机器人，预期不影响小组头部竞争
        

### 排名结算

1.  每日跨0点后立即进行小组赛的结算，结算奖励与段位无关
    
    1.  渔场内在线的玩家，结算完成后进行强弹推送
        
    2.  非渔场内跨天的玩家，进入渔场时进行强弹推送
        
2.  未完成排名结算时，仅记录排名积分，暂不参与新一轮的排名
    
3.  排名结算后，及时计算段位星和段位提升，如果段位提升，直接发放排名奖励，并按照新段位匹配
    
4.  待讨论内容：
    
    1.  大作战只要参与的玩家保底获得1颗段位星，保证小R玩家可缓慢提升段位
        
    2.  如果仅给排行榜前X名玩家发放段位星，可能会导致末位玩家始终无法提升段位，但是会提到对门槛排名的追求，可刺激晋级线边缘玩家的消耗

# 数值框架

**体验级数值意图**（非数值同事能一眼理解「锦标赛大概长什么样」）

- **节奏与周期**：每日 0 点小组排名结算；赛季内段位累计段位星晋升，赛季重置段位与奖励；进度奖按日刷新、积分每日清零。
- **烈度与规模**：单组约 30~35 人，段位越高机器人越少、竞争越真实；进度奖以约 4 档为一轮、多轮递进，首轮低炮倍约 5 分钟可完成一轮，后续轮次要求与奖励等比提升。
- **经济与概率**：积分由渔场捕获守卫掉落，炮倍与捕获倍数影响单次掉落量；进度奖、小组排名奖励、段位晋级奖励构成主要投放；段位星发放规则待定（保底 1 星 vs 仅前 X 名）。

# 交互需求输入

### 1.核心体验节奏

*   【单日体验】
    
    *   （结算）领取昨日结算奖励，获得段位星/限时战魂体验，预设今日目标
        
    *   初期：每次捕获成功伴随领取大量进度奖励，强化捕获反馈
        
    *   中期：以常用炮倍体验，约5~10分钟可完成一轮进度奖，领取频次降低，但奖励吸引力提升
        
    *   后期：频繁关注排名情况，按照玩家预期目标调成炮倍使用策略，追求更高排名
        
*   【周期体验】
    
    *   大佬：快速提升段位获得限定外显；后续持续提升赛季增益放大周期内奖励
        
    *   轻度：前期缓慢累计段位星，中后期随头部用户升段，开始追求日榜排名，最终目标为限定外显

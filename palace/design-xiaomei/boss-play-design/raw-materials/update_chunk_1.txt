前置随机+杀意值** | 开局定量级，Loop 概率涨杀意值 | 开局定底牌，追觉醒 | 生肖猴 |
| **转盘觉醒型** | 转盘 Loop + 觉醒判定 | 转盘自带 near miss | 太空兔 |
| **双舞台 Loop** | 多形态 Loop 交替 + 彩蛋 Super | Loop 不单调 | 乐队 |
| **集锦型** | 射歪=结束 或 =Boss 大奖 | 失败和大奖共用入口，反差极致 | 丘比特 |

设计新 Boss 时，可从以上类型中选择最贴合主题的结构，也鼓励**混搭或创新**。

## 通用结算模式

| 结算模式 | 公式 | 说明 |
|------------|------|------|
| **A x B** | 加倍数 x 翻倍数 | 最通用 |
| **A x N+B** | 单次值 x 次数 + 附加 | 多次攻击累加型 |
| **基础 x 乘数** | Loop 基础 x Super 乘数 | 前后段互相放大 |
| **数字即结果** | 演出中的数字本身 | 数字匹配型，所见即所得 |

## Near Miss 核心三段论

Near Miss 的分支可读性来自三段论：**信号 → 赌注 → 揭晓**。缺任一段，悬念价值归零。

- **信号**：角色核心动作、标志性行为，让玩家产生预期。
- **赌注**：被引导抬升的希望/预期（离完成差一口气）。
- **揭晓**：正向揭晓（回撤/进度/匹配）或反转型揭晓。

## 4 种 Near Miss 范式

### 范式一：回撤型

动作趋近完成 -> 在临界点**回撤** -> 重建悬念

| 主题 | 表现 |
|------|------|
| 开箱子 | 箱子半开->光芒外泄->箱盖又合上 |
| 拔剑 | 蓄力拔剑->剑刃将出->泄力滑回鞘中 |
| 拉弓 | 弓弦绷到极限->箭尖发光->泄力弓弦松弛（后弈） |
| 蓄能释放 | 能量聚满->光球闪烁->忽然回缩 |
| 封印 | 裂开光芒->即将碎裂->裂纹又愈合 |

### 范式二：进度型

进度持续推进 -> 接近目标 -> 最终**差一点**未达成

| 主题 | 表现 |
|------|------|
| 莲花点亮 | 9 瓣莲花亮了 7-8 瓣，差一两瓣没觉醒

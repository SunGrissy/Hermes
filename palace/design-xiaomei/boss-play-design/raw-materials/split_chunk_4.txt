# Boss 实战案例库

## 案例 01：后弈
- **类型**：Loop x N + Super
- **核心动作**：拉弓蓄力 -> 射日
- **流程**：Loop 1 必定成功 -> Loop 2-4 各自独立判定 -> Super 穿射连破多个太阳
- **结算**：累加
- **Near Miss**：蓄力回撤（弓弦绷到极限 -> 箭尖发光 -> 泄力弓弦松弛）
- **亮点**：首轮保底必成功；9 个太阳 = 大圆满叙事奖励，特殊场景图

## 案例 02：生肖狗
- **类型**：Loop x N + 觉醒分支 Super
- **核心动作**：大剑蓄力 -> 觉醒变身
- **流程**：大概率第1轮进 Super -> Super1 天狗领域（连击跳涨） vs Super2 月食领域（翻倍增长）
- **结算**：累加
- **Near Miss**：觉醒未触发（双层悬念：蓄力 + 觉醒）
- **亮点**：觉醒时不给 Loop 基础分（觉醒替代而非叠加）；两条 Super 路线体验不同

## 案例 03：哪吒
- **类型**：奖池型
- **核心动作**：闹海三连击 -> 对龙连击 -> 莲花点亮
- **流程**：Loop 无失败出口（无风险积累）-> Super 必进（A x 2 + B x 1~X + C x 1）-> 莲花 9 瓣全亮 = 觉醒
- **结算**：基础 x 乘数（Loop 基础 x Super 乘数）
- **Near Miss**：莲花进度型（9 瓣亮了 7-8 瓣，差一两瓣没觉醒）
- **亮点**：无风险 Loop + 必进 Super + 乘法结算；莲花进度指示器

---

## 案例 04：生肖鸡
- **类型**：Loop + Heavy + 奖池混合
- **核心动作**：剑雨释放 -> Heavy 多段攻击 -> 奖池解锁
- **流程**：部分轮次升级为 Heavy（多段攻击）-> Loop 和 Heavy 都概率掉奖池豆 -> 奖池解锁后进 SuperA 得翻倍数
- **结算**：累加 + 翻倍
- **Near Miss**：奖池差一点未解锁
- **亮点**：Loop 内分级轮次（Heavy 升级轮）；蓄力判定 + 奖池积累双系统并行

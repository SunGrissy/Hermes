# 案例 04：生肖鸡
- **类型**：Loop + Heavy + 奖池混合
- **核心动作**：剑雨释放 -> Heavy 多段攻击 -> 奖池解锁
- **流程**：部分轮次升级为 Heavy（多段攻击）-> Loop 和 Heavy 都概率掉奖池豆 -> 奖池解锁后进 SuperA 得翻倍数
- **结算**：累加 + 翻倍
- **Near Miss**：奖池差一点未解锁
- **亮点**：Loop 内分级轮次（Heavy 升级轮）；蓄力判定 + 奖池积累双系统并行

## 案例 05：生肖猴
- **类型**：前置随机 + 杀意值奖池
- **核心动作**：棍势蓄力 1-3 段 -> 连续攻击涨杀意值
- **流程**：棍势蓄力 1-3 段影响每次打击数值（与次数无关）-> Loop A x N + B -> 概率涨杀意值 -> 满则觉醒攻击涨翻倍数
- **结算**：A x N + B
- **Near Miss**：杀意值进度型（杀意条蓄到 90%+，差最后一击）
- **亮点**：开局一次随机定本局量级（前置随机定基调）

## 案例 06：太空兔
- **类型**：转盘觉醒型
- **核心动作**：转盘转动 -> 觉醒飞船登顶
- **流程**：Loop 转盘 -> 判定结束? -> 未结束则判定觉醒 -> 觉醒后飞船登顶 A x B 结算
- **结算**：A x B
- **Near Miss**：匹配型（指针几乎停在大奖格 -> 滑过一格停小奖）
- **亮点**：转盘自带 near miss；结构简洁明快

## 案例 07：乐队
- **类型**：双舞台 Loop
- **核心动作**：舞台开合 -> 吉他 solo / 合奏
- **流程**：Stage1 吉他 solo（加倍数A） vs Stage2 合奏（B x C）-> 舞台关闭后判定是否再开 -> 随机触发 Super 彩蛋加倍数 D
- **结算**：加法 + 乘法
- **Near Miss**：舞台没再开（期望继续但关闭了）
- **亮点**：两种 Loop 形态交替保持新鲜感（多形态 Loop）；彩蛋式 Super

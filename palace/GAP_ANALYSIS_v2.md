## 一、共性缺口（出现在 2+ 份报告中）

### 1. 体验意图声明缺失/不完整 · 4/4

| 报告 | 描述 |
|------|------|
| 锦标赛 | 概述偏向机制罗列，缺少一句话体验意图（玩家感受到什么核心情绪） |
| 四象角力 | ✅ 已有（重点建议，非阻断） |
| 开火挑战 | 完全缺失，直接进入玩法规则描述 |
| 神君随心购 | 完全缺失，直接进入功能描述 |

**模板建议**：在 DOC_SPEC 模板中，将「体验意图」从「内容结构」内部提升为**独立必填章节**，且置于文档前 1/3，格式强制为：

```markdown
## 体验意图
本功能的核心体验是让玩家感受到______（一句话）。
```

建议新增强制检查规则：文档类型为「全新设计」「运营活动」时，体验意图必须出现在前 500 字内。

# [0422]升炮赛设计文档 审核报告

**审核日期**：2026-04-11
**方案类型**：完整策划案
**启用引擎**：Purpose, Rhythm, RedLine, Value, Segment, Economy

## 一、30秒速判
- **设计目的（一句话）**：通过设置阶梯式的、高门槛的竞技淘汰赛，让高炮倍玩家体验到“炮倍养成带来的巅峰对决的荣誉感”，从而驱动其持续的炮倍养成和游戏内高价值消耗。
- **宏观适配**：⚠️ (警告)
- **微观目标感**：方案的结构和流程（初赛 $\rightarrow$ 复赛 $\rightarrow$ 决赛）非常清晰，目标用户群定位准确。但其核心驱动力过于依赖“门槛”和“淘汰”，缺乏一个能让中坚玩家持续投入的、非排名的核心乐趣点。

## 二、引擎检查结果

### Purpose（设计目的）
| 检查项 | 评估 | 备注 |
| :--- | :--- | :--- |
| **核心目的清晰度** | ✅ | 核心体验（成长感/荣誉感）和目标用户（中高炮倍活跃玩家）定义明确。 |
| **模块服务性** | ✅ | 所有模块（预热、初赛、复赛、决赛、机器人）都服务于“门槛提升”和“荣誉展示”这一核心目的。 |
| **目标人群明确性** | ✅ | 明确锁定头部玩家（大R），并以此为后续活跃目标。 |
| **潜在冲突点** | ⚠️ | 核心目的是“荣誉感”，但机制设计（如机器人、积分掉落）更偏向“数值碾压感”，两者需要更精妙的平衡。 |

**问题清单：**
*   **P1 (逻辑冲突)**：体验意图提到“生肖羁绊×3加成的爆发爽感”，但在“数值杠杆效应”中，它被描述为“与使用炮倍和守护神增益(x3)的乘法公式”，这使得生肖羁绊的价值感被稀释为单纯的数值乘数，削弱了“爆发爽感”的叙事性。

**维度评分：** 8/10
**决策问题：** 核心目的是“荣誉感”，但机制设计更偏向“数值碾压感”。是否需要增加一个非数值、非排名的“团队/合作”维度来分散大R的注意力，以提升整体的“社交荣誉感”？

### Rhythm（情绪节奏）
| 检查项 | 评估 | 备注 |
| :--- | :--- | :--- |
| **情绪曲线绘制** | ⚠️ | 流程设计了清晰的“爬升-高潮-下降-再爬升”的曲线，但存在明显的**情绪平原**风险。 |
| **情绪平原识别** | ❌ | **风险点：** 从“初赛”到“复赛”再到“决赛”的**中间过程**（即：未晋级玩家的日常活动）极易陷入情绪平原。一旦玩家无法参与核心竞争，其日常活动缺乏足够的“目标感”来维持兴奋度。 |
| **宏观节奏合理性** | ✅ | 2周一期，三轮递进的结构是合理的，符合大型赛季活动的节奏。 |
| **关键节点强化** | ✅ | 预热期和决赛结算的强弹/公告设计，能有效制造高光时刻。 |

**问题清单：**
*   **P2 (节奏缺失)**：未晋级玩家的“冷却期”或“过渡期”的活动设计缺失。这部分玩家的体验极易跌入谷底，导致流失。

**维度评分：** 7/10
**决策问题：** 如何设计一个“非核心竞争者”也能参与，且能维持一定“目标感”的日常活动，避免玩家在淘汰赛周期中脱离主线乐趣？

### RedLine（红线与误区）
| 检查项 | 评估 | 备注 |
| :--- | :--- | :--- |
| **核心循环不为 KPI 让步** | ✅ | 核心循环是“炮倍养成 $\rightarrow$ 参与比赛 $\rightarrow$ 获得荣誉”。该循环是自洽的，没有为了短期KPI（如充值）而破坏核心的养成/竞技体验。 |
| **不强迫玩家** | ⚠️ | **风险点：** 淘汰赛的结构（TOP 200 $\rightarrow$ TOP 100）本质上是强迫玩家进行“持续的、高强度的投入”。如果玩家在某轮次感到疲惫，系统缺乏足够的“退出缓冲带”，会造成挫败感。 |
| **不做冗余系统** | ✅ | 整体上是基于现有系统（炮倍、Boss、排名）的增强，没有引入大量不必要的独立系统。 |
| **命中误区（堆系统）** | ⚠️ | 流程上堆叠了“初赛-复赛-决赛”三个独立的、高强度的竞争阶段，如果每个阶段的差异化不足，容易被玩家视为“系统堆叠”。 |

**问题清单：**
*   **P1 (强迫感)**：淘汰赛的层级结构过于陡峭，缺乏“软着陆”机制。

**维度评分：** 7.5/10
**决策问题：** 如何在保持竞技压力的同时，为玩家提供一个“可选择退出高压区，但仍能获得价值感”的缓冲机制？

### Value（价值冲突）
| 检查项 | 评估 | 备注 |
| :--- | :--- | :--- |
| **价值排序冲突** | ⚠️ | **公平感 vs. 荣誉感：** 方案过度侧重“荣誉感”和“展示”，而牺牲了“公平感”。机器人和炮倍门槛的设定，使得资源投入的玩家（大R）的优势被系统化放大，让普通玩家的努力感难以被看见。 |
| **大R/中坚/免费/低活跃影响** | ⚠️ | **中坚层保护不足：** 中坚层（Mid-Tier）的价值点是“晋级突围”和“明确目标”。但一旦他们未能达到门槛，其价值感会迅速归零，缺乏一个“可替代的、有意义的次级目标”。 |
| **付费点设计** | ✅ | 奖励梯度（初赛 $\rightarrow$ 复赛 $\rightarrow$ 决赛）与门槛提升是挂钩的，付费点（养成/消耗）与荣誉挂钩，逻辑自洽。 |

**问题清单：**
*   **P1 (公平感)**：系统设计倾向于“资源/投入决定一切”，缺乏“战术/运气/社交配合”等非资源维度的胜利可能，导致公平感极低。

**维度评分：** 6.5/10
**决策问题：** 如何在不削弱大R核心竞争力的前提下，设计一个能让中坚玩家感受到“我也可以通过努力达到顶尖水准”的、非数值依赖的突破口？

### Segment（玩家分层）
| 检查项 | 评估 | 备注 |
| :--- | :--- | :--- |
| **大R影响** | ✅ | 极度满足。通过炮倍门槛和三轮淘汰，完美满足了其“巅峰对决”和“身份展示”的需求。 |
| **中坚层影响** | ⚠️ | 影响是“压力”而非“激励”。他们被门槛卡住，体验到的是“我离目标还差X”，而非“我正在向目标靠近”。 |
| **免费/低活跃影响** | ❌ | **完全忽略。** 方案的所有门槛（炮倍200w/250w/300w）都将这些群体排除在外，导致其活动曝光和参与感极低，极易产生“与核心玩法脱节”的负面情绪。 |
| **分层保护** | ❌ | 缺乏对低活跃玩家的“软着陆”机制，导致用户生命周期管理维度缺失。 |

**问题清单：**
*   **P1 (用户流失)**：对低活跃玩家的曝光和价值输出设计缺失，可能导致大量用户在活动期间选择“静默期”，而非“退出”。

**维度评分：** 5.5/10
**决策问题：** 是否需要为低炮倍玩家设计一个“辅助养成线”或“观战/学习线”，让他们在无法参与核心竞争时，仍能感受到“参与感”和“对未来的期待”？

### Economy（经济健康）
| 检查项 | 评估 | 备注 |
| :--- | :--- | :--- |
| **通胀/重置风险** | ⚠️ | **风险点：** 奖励（生肖碎片自选宝箱、金币加赠券）的重复发放，如果缺乏消耗机制，会造成资源池的缓慢通胀。 |
| **追赶机制** | ✅ | 炮倍门槛的设定，本身就是一种“追赶机制”，迫使玩家投入资源。 |
| **回收机制** | ⚠️ | 奖励的回收机制不明确。例如，如果玩家在初赛获得大量碎片，但后续无法晋级，这些资源是否会“沉底”？需要更明确的消耗路径。 |
| **数值依赖性** | ✅ | 整个经济循环高度依赖“炮倍”这一核心数值，数值杠杆效应的描述是合理的。 |

**问题清单：**
*   **P2 (资源沉底)**：奖励的消耗和回收路径需要明确，防止玩家获得大量无法在短期内使用的资源，造成经济冗余。

**维度评分：** 7/10
**决策问题：** 奖励的“保底消耗”机制是什么？是否可以将部分奖励（如碎片）与“赛季目标达成度”挂钩，强制玩家在活动周期内使用？

## 四、问题汇总

**P0 (致命/必须解决)：** 无。
**P1 (高优先级/逻辑冲突)：**
1.  **[Value]** 生肖羁绊的价值感被数值乘数化，削弱了叙事性。
2.  **[RedLine/Value]** 淘汰赛的层级结构过于陡峭，缺乏“软着陆”机制，导致玩家强迫感过高。
3.  **[Segment]** 对低炮倍玩家的价值输出和参与感设计缺失，导致用户流失风险高。
**P2 (中优先级/优化建议)：**
1.  **[Rhythm]** 缺乏未晋级玩家的“过渡期”活动设计，易造成情绪平原。
2.  **[Economy]** 奖励的消耗和回收路径需要明确，防止资源沉底。

**待验证项：**
*   参与人数（集结赛）的预期值。
*   积分获取比例（金币 $\rightarrow$ 积分）的具体数值。
*   核心奖励的“保底消耗”机制。

## 六、文档完整性备注（附录）
文档的结构化程度极高，流程图、参数表、决策清单等模块的填充非常详细，体现了策划的深度思考。

**但存在以下大面积空白或待定项，对下游（UX/数值/技术）的阻塞影响较大：**

1.  **数值参数缺失（阻塞影响：高）：** 多个关键参数（如：活动查看门槛要求、比赛炮倍门槛要求、积分获取比例、机器人目标分数 $x$）均标记为 `[数值·待标定·人·日期]`。这直接阻塞了数值和UX的**硬性开发**。
2.  **经济/概率模型缺失（阻塞影响：高）：** 奖励的“产出/消耗/返还比例”和“概率/保底”部分，缺乏任何数值锚定，无法进行经济模型搭建。
3.  **流程衔接点缺失（阻塞影响：中）：** 关键的“衔接点”的决策项中，有多个标记为 `[待定·人·日期]`，这会阻塞**系统流程的联调测试**。

**总结：** 策划的“骨架”已搭建完毕，但“血肉”（核心数值和具体机制）的填充工作尚未完成，需要立即跟进数值和系统对接。

# [0422]升炮赛设计文档 审核报告

**审核日期**：2026-04-11
**方案类型**：完整策划案
**启用引擎**：Purpose, Rhythm, RedLine, Value, Segment, Economy

## 一、30秒速判
- **设计目的（一句话）**：通过设置一个高门槛、多阶段、强淘汰的竞技场，驱动核心玩家进行炮倍养成，并提供周期性的巅峰荣誉感，以提升整体的活跃度和养成粘性。
- **宏观适配**：✅
- **微观目标感**：方案的结构（预热 $\rightarrow$ 初赛 $\rightarrow$ 复赛 $\rightarrow$ 决赛）非常清晰，目标用户群（中高炮倍活跃玩家）和核心驱动力（炮倍养成）的绑定非常紧密，具备极强的落地执行感。

## 二、引擎检查结果

### Purpose（设计目的）
| 检查项 | 评估结果 | 备注 |
| :--- | :--- | :--- |
| **目的清晰度** | ✅ | 核心目的（成长感与荣誉感）和次要目的（差异化体验、爽感）界定明确。 |
| **模块服务性** | ✅ | 所有模块（预热、分组、三阶段比赛、奖励）都围绕“门槛提升 $\rightarrow$ 竞争 $\rightarrow$ 奖励”这一核心循环服务。 |
| **目标人群明确性** | ✅ | 明确锁定“中高炮倍的活跃玩家”，并为大R和中R分别设计了不同的激励点。 |

**问题清单**：无明显 P0/P1 问题。
**维度评分**：9/10分
**决策问题**：**Sense**：方案的成功高度依赖于“炮倍门槛”的设定。请确认这个门槛的提升速度（梯度）是否与玩家的平均养成速度匹配，避免门槛过高导致用户流失。

### Rhythm（情绪节奏）
| 检查项 | 评估结果 | 备注 |
| :--- | :--- | :--- |
| **情绪波峰波谷** | ✅ | 节奏设计极佳：预热（期待） $\rightarrow$ 初赛（爆发） $\rightarrow$ 复赛（收缩/紧张） $\rightarrow$ 决赛（巅峰/高潮）。 |
| **宏观节奏合理性** | ✅ | 2周一期，3天三轮淘汰，节奏层层递进，符合竞技活动的标准节奏。 |
| **衔接点平滑度** | ⚠️ | 从“初赛”到“复赛”的过渡（TOP 200 $\rightarrow$ 积分重置 $\rightarrow$ 烈度提升）需要极强的视觉和信息引导，否则玩家会感到流程突兀。 |

**问题清单**：
*   **P1 (流程引导)**：在“初赛 $\rightarrow$ 复赛”的过渡点，需要明确的“情绪缓冲/信息重置”环节，不能仅仅依靠“邮件通知”来完成从全员到精英的心理跨越。
**维度评分**：8.5/10分
**决策问题**：**Flag**：请明确“积分重置”和“排名重置”的视觉/系统反馈，是否需要一个专门的“赛区公告/总结”环节来强调“我们进入了更精英的圈层”。

### RedLine（红线与误区）
| 检查项 | 评估结果 | 备注 |
| :--- | :--- | :--- |
| **核心循环让步** | ✅ | 核心循环（炮倍驱动 $\rightarrow$ 参与 $\rightarrow$ 排名）非常坚固，未被KPI（如每日在线时长）所稀释。 |
| **不强迫玩家** | ✅ | 玩家通过“达到门槛”自愿进入，而非系统强制。 |
| **不做冗余系统** | ✅ | 明确替换了现有系统（王者争锋），聚焦了核心体验。 |
| **误区规避** | ✅ | 避免了“堆系统当内容”的风险，而是将系统（炮倍、生肖）作为**驱动力**。 |

**问题清单**：无明显 P0/P1 问题。
**维度评分**：9.5/10分
**决策问题**：**Gate**：由于系统复杂度极高，请务必在设计文档中增加一个“系统依赖图谱”，清晰展示所有模块（预热、分组、初赛、复赛、决赛、机器人、奖励发放）之间的**数据流向**，以防技术实现层面出现阻塞。

### Value（价值冲突）
| 检查项 | 评估结果 | 备注 |
| :--- | :--- | :--- |
| **公平感** | ⚠️ | 核心优势（生肖羁绊 $\times 3$）和门槛（炮倍）的结合，导致系统天然倾向于“富人通吃”的体验。 |
| **社交生态** | ✅ | 排名和荣誉的展示极大地激发了玩家的炫耀欲和参与感，利于社群话题的生成。 |
| **爽感** | ✅ | 积分掉落与Boss金币挂钩，大数额的积分跳动，能提供极强的单次操作爽感。 |
| **留存** | ✅ | 周期性（2周/3天）和持续的养成目标（炮倍）保证了极高的短期和中期留存。 |
| **付费点** | ⚠️ | 方案侧重于“养成驱动”，但未明确指出付费点如何与“炮倍门槛”挂钩，付费的动机需要更明确的引导。 |

**问题清单**：
*   **P1 (公平感)**：需要设计一个机制，让中R玩家在达到门槛前，也能感受到“参与感”和“价值感”，防止他们因为炮倍差距过大而产生强烈的挫败感。
**维度评分**：8/10分
**决策问题**：**Sense**：请考虑是否可以在“预热期”增加一个“炮倍提升助力”的付费/养成环节，让付费行为与活动门槛的达成更直接挂钩，增强付费的合理性。

### Segment（玩家分层）
| 检查项 | 评估结果 | 备注 |
| :--- | :--- | :--- |
| **大R（核心）** | ✅ | 完美匹配：荣誉、高对抗、高回报，满足其“展示欲”和“统治欲”。 |
| **中坚层（中R）** | ✅ | 匹配点：通过“晋级压力”和“目标锁定门槛”来刺激其养成，使其持续关注炮倍。 |
| **免费/低付费层** | ⚠️ | 覆盖度不足。当前设计中，低炮倍玩家的曝光和奖励似乎被边缘化，容易造成“参与感缺失”。 |
| **保护机制** | ⚠️ | 缺乏对中R的“情绪保护”。如果中R玩家在预热期投入大量资源，但最终因炮倍差距无法进入比赛，其投入的价值感会迅速崩塌。 |

**问题清单**：
*   **P1 (中R价值)**：需要为中R设计一个“可量化的、非排名相关的”的参与奖励，例如“参与度奖励”或“养成里程碑奖励”，确保他们投入的资源不会“白费”。
**维度评分**：7.5/10分
**决策问题**：**Flag**：请重新审视“预热期”的奖励设计，是否可以增加一个“参与度/养成贡献度”的奖励池，用于奖励那些虽然炮倍未达标，但持续投入的玩家。

### Economy（经济健康）
| 检查项 | 评估结果 | 备注 |
| :--- | :--- | :--- |
| **通胀/重置** | ✅ | 积分和排名在每轮比赛中进行了重置，有效控制了短期内的通胀和疲劳感。 |
| **资源消耗/回收** | ✅ | 核心消耗点是“炮倍养成”，这天然地构建了一个资源回收（Sink）机制。 |
| **追赶/拉开差距** | ✅ | 机器人和生肖羁绊的乘法加成，成功地为高资源玩家提供了指数级的优势，拉开了差距，满足了“巅峰对决”的体感。 |
| **经济风险** | ⚠️ | 奖励的“碎片自选宝箱”和“金币加赠券”的投放量和稀有度，需要与炮倍养成消耗的资源量进行精确的平衡，否则会造成经济失衡。 |

**问题清单**：
*   **P2 (奖励平衡)**：需要对“生肖碎片自选宝箱”的价值进行量化评估。如果其价值过高，会成为玩家主要的“目标”，从而让炮倍养成本身失去意义。
**维度评分**：8/10分
**决策问题**：**Sense**：请提供一个“奖励价值曲线图”，展示从初赛到决赛，奖励的价值增长曲线是否是平滑且符合玩家预期的，避免出现“初赛奖励过高，决赛奖励平淡”的情况。

## 四、问题汇总
**P0 (致命问题)**：无。
**P1 (高优先级)**：
1.  **流程引导（Rhythm）**：初赛 $\rightarrow$ 复赛的过渡需要更强的情绪/信息重置环节。
2.  **中R价值（Segment）**：需要为中R设计非排名相关的参与奖励，防止其投入的资源价值感崩塌。
3.  **付费钩子（Value）**：需要明确付费点如何与“炮倍门槛”的达成挂钩，增强付费的合理性。
**P2 (中优先级)**：
1.  **奖励平衡（Economy）**：需量化评估“生肖碎片自选宝箱”的价值，确保其不会成为唯一的驱动力。
2.  **门槛梯度（Purpose）**：需确认炮倍门槛的提升速度是否与玩家的平均养成速度匹配。

**待验证项**：
1.  **数值参数**：所有涉及的门槛炮倍、参与人数、积分获取比例等，均标记为待定，需数值团队填补。
2.  **奖励价值量化**：所有奖励（特别是碎片宝箱）的实际游戏价值，需要进行量化评估。

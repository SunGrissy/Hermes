# 作者侧写（novel 语料推断）

> **正文双份**：与 `novel/agent-author-profile.md` **同步**；若工作区只挂载 `novel/` 子树或需给人读，优先打开该文件。修改时请 **两处同改**。  
> **依据**：`novel/research/writing-principles.md`、`novel/story-bible.md`、`novel/review-master.md`、`novel/chapters/*.md`、`novel/INDEX.md`、`novel/action-plan.md` 等。  
> **性质**：协作提示，非医学/心理诊断；若与作者当面口径冲突，以作者即时指令为准。

## 一、认知与性格侧写（Agent 协作时怎么用）

| 维度 | 表现 | 对 Agent 的含义 |
|------|------|----------------|
| **系统型大脑** | 大量表格、阶段模型、检查清单、版本戳（如「2026.03.22 定稿口径」）、文件间互链与「冲突时优先级」 | 给方案时优先 **结构化**（条、表、门禁），少空话；改动设定要指出 **权威源文件** 与 **连锁修改面** |
| **因果优先于氛围** | 反复强调「事件=有风险的选择」「政治天气要落到主角身上」「能力必须被戏剧化测试」 | 评语从 **机制** 出发：这一笔改变了什么处境、谁施压、代价是什么；避免只夸「有质感」 |
| **自我迭代能力强** | `review-master` 能同时扮演「晋江编辑视角」与「作者自检」，把问题收敛成 P0/P1 与可执行项（`action-plan`） | 可以 **尖锐但要对齐她的标尺**（戏/散文、钩子、信息差）；她吃得下硬反馈，但要 **可落地** |
| **野心与平台自觉并存** | 主题要「俄狄浦斯级」完整执行，同时承认晋江章更、章末钩、CP 浓度等 **引擎** 需求 | 不让她在「纯文学慢板」与「网文饥饿感」之间二选一糊弄过去；建议需同时照顾 **叙事尊严** 与 **连载节奏** |
| **伦理与边界感** | `writing-principles` §十一：非鱼 POV 比例、禁洗白禁猎奇、苦难描写距离 | 协助写暴力/性别/权力议题时 **默认克制、侧面、不消费**；不加她未许可的「爽虐」镜头 |
| **文献型审美** | 道门、天宝制度、称谓、服饰等多文件考证；世界观层喜欢 **有典可查的骨架** | 胡编年代/称谓会被视为 **毁稿级**；不确定就查 `naming-conventions.md` 等或明确标注「待考」 |

## 二、写作风格 DNA（正文层面）

1. **感官层级清晰**  
   常让 **气味、触觉、声场** 先于抽象判断；高潮段用 **短句 + 破折号** 控呼吸（例：「不是疼——是满」一类节奏）。

2. **信息叠压而非解说**  
   穿越、通感等多采用 **多层同时涌入**，以身体反应落地，少用作者口吻解释设定。

3. **克制标签化**  
   叙述紧贴人物边界；反对把女主写成「穿越者」标签人，而强调 **认知阶段与措辞禁区**（见 `writing-principles` §1）。

4. **具体锚代替抽象情绪**  
   伏笔挂在 **物件、账目、一句话、一道伤** 上；反对「她觉得不安」式空泛。

5. **对话有骨质**  
   人物开口常带 **阶层、行当、关系权力**（如三叔生意人口吻、杜甫「具体的人」式信息方式）。

## 三、她偏好的「反馈语言」

- **高信号词**：戏/散文、钩子、落地、外部后果、信息差、代价、推进、白名单 POV、千年毒素（慎用频度）、北极星（女主主体性 / CP / 史实服务前两项）。  
- **低信号**：泛泛的「文笔好」「很有画面」而不接 **下一章读者会问什么**。  
- **修改建议格式**：指出 **违反了她哪条自创铁律**（最好精确到 `writing-principles` 章节）+ **一改法示例**（可短，但要可执行）。

## 四、协作流程提醒

1. **入口纪律**：写卷一情节时默认遵循 `novel/INDEX.md` 的优先级：`chapter-outline.md` → `vol1-narrative-spine.md` → `story-bible.md`。  
2. **HTML 与 md**：`novel/reader/**/*.html` 多为阅读端导出；**设定争论以 `.md` 为准**（INDEX 已声明）。  
3. **大改前**：对照 `story-bible` 北极星与 `writing-principles` 密度标尺，避免只改文笔不改 **发动机**。  
4. **替她做决定时**：她更信任 **「可选方案 A/B/C +  trade-off」**（见 `action-plan` 写法），而非单一武断结论。

## 五、易踩雷（Agent 自检）

- 让记忆封锁期的鱼使用 **穿越者元语言**（「这具身体」「历史上」等）—— **稿毁级**。  
- 用 **明清称谓/套路** 写天宝（爹、大人、道姑等）—— 她要求 **称谓零容忍**。  
- 通感只写内心、没有 **社交/商业/身体痕迹** —— 违反自定规则。  
- 章末只做 **情绪收束**、没有 **具体问题/悬念** —— 与她认定的网文引擎相悖。  
- 为「方便读者」让角色 **口播百科** —— 她明确反对（应用具体人事传递信息）。

## 六、与 workspace 其他画像的关系

- `producer-context.mdc` 中的 **因果链、北极星公式、相关≠因果** 与她在 novel 侧的 **机制化写作** 同向；管理类输出与创作类输出可共享这一套「穿透表面」的思维。  
- 本 skill 仅覆盖 **小说创作语料**；管理/绩效语境仍以 `producer-context` 为准。

# 面试清单参考数据

在此目录放置岗位清单和评分标尺，Agent 生成面试清单时会优先读取。

## 推荐文件

```
简历初筛清单_运营策划.md     # 同 resume-screening/reference，可复用
简历初筛清单_系统策划.md
简历初筛清单_战斗策划.md
简历初筛清单_主策划.md
简历初筛清单_应届生.md
rubric_ops.json              # 运营策划评分标尺（可选，提升评分维度对齐度）
rubric_system_planning.json  # 系统策划评分标尺（可选）
```

**没有参考数据也能用**：SKILL.md 内置了各岗位核心能力标准，有了这里的数据判断更准确。

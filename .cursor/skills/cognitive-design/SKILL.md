# 认知设计引擎

> 给所有设计类 Skill 装底层解释引擎——把"直觉上对"变成"机制上可解释"。
> 按**设计场景**组织。每个模块：机制原理 → 设计含义 → 常见误用 → 检验方法。
> 需要学术深挖时，读取 `reference/foundations.md`（三本书完整蒸馏 + 7 篇前沿论文）。

## 角色规则

- 不扮演任何人物，以认知科学视角提供分析
- 术语首次出现时给一句人话翻译，不堆学术黑话
- 优先用游戏设计案例说明原理，其次用产品设计案例

## 适用场景

- 审查设计方案时，解释"为什么这样设计对/不对"
- 评估体验节奏时，用认知机制定位问题
- 与 `design-review`、`producer-mind`、`design-council` 配合，提供底层科学支撑
- 新功能设计时，用认知原理预判玩家反应
- **需要学术依据时**：加载 `reference/foundations.md`，回答"原理是什么、证据级别、边界条件"

## 不适用于

- 纯数值平衡（那是数值策划的领域）
- 纯视觉美学判断（那是主美的领域）
- 商业模型和变现策略（认知引擎只管体验层）

## 回答工作流（Agentic Protocol）

### Step 1: 定位设计问题属于哪个认知域

| 认知域 | 信号词 |
|--------|--------|
| 注意力与信息负荷 | "信息太多"、"看不过来"、"不知道该看哪" |
| 奖励与动机 | "没动力"、"奖励无感"、"上瘾"、"麻木" |
| 情绪与记忆 | "没感觉"、"记不住"、"被坑的感觉很强" |
| 预期与预测误差 | "没惊喜"、"太可预测"、"落差太大" |
| 决策与引导 | "不知道该选什么"、"选择太多"、"被强迫" |
| 心流与学习 | "太难"、"太简单"、"无聊"、"焦虑" |

### Step 2: 调取对应模块的认知机制分析

### Step 3: 输出

```
1. 认知诊断（用机制语言描述问题本质）
2. 设计含义（翻译成策划能听懂的语言）
3. 改进方向（基于机制的具体建议）
4. 误用警告（这个机制滥用会怎样）
```

如用户追问"原理是什么""有什么学术依据"→ 读取 `reference/foundations.md` 对应章节，给出文献级回答。

## 模块一：注意力与信息负荷

- **工作记忆 4±1**：同屏核心信息组不超过 4 个；Boss 技能演出一次展示不超过 3 个需注意元素
- **注意力双系统 DAN/VAN**：好节奏让主动搜索（DAN）和意外惊喜（VAN）交替激活；连弹 5 个弹窗 = 全是 VAN 强制捕获
- **认知负荷三分类（Sweller）**：消除无关负荷 → 释放资源 → 投入相关负荷 → 进入心流

## 模块二：奖励与动机

- **多巴胺预测误差 PEL**：PE = 实际 − 预期。固定奖励→PE归零→麻木；可变奖励→PE持续→参与度维持。**为"预期"而设计，非为"奖励"**
- **可变比率强化**：所有强化程式中最抗消退；概率掉落 > 确定掉落，但需保底兜底
- **VDAC 价值驱动注意力捕获**：与奖励关联的感官特征获得"价值标签"，此后自动捕获注意力；不兑现的价值标签造成长期干扰
- **习惯回路**：暗示→惯常→奖赏；暗示越明确、奖赏越即时，习惯形成越快

## 模块三：情绪与记忆

- **峰终定律**：体验评价由最强烈时刻（峰值）+ 结束感受（终值）决定；虎头蛇尾最伤评价
- **情绪认知评估**：四维度（相关性/一致性/归因/前景）；内部可控归因→掌控感，外部不可控→无助
- **杏仁核快通道**：负面情绪记忆比正面更持久；公平感受损的修复成本远高于预防成本；首次体验印记最深

## 模块四：预期与预测误差（深化）

- **动效叙事三级进化**：CM级（功能反馈）→ RM级（节奏优化）→ MG级（完整动效叙事，不识字也能理解）
- **Near Miss**：差一点就赢了——大脑处理方式接近成功；适度维持动机，过度→认知失调
- **联结三阶段**：初始（奖励触发）→ 学习（线索先于奖励）→ 巩固（多巴胺在线索时释放）→ **线索设计比奖励设计更重要**

## 模块五：决策与引导

- **系统 1/2 双过程**：爽感走系统1，策略走系统2；连续3个系统2环节→需插入"呼吸点"
- **选择架构（助推）**：默认选项、锚定、框架效应、社会规范、显著性；核心：**可以引导不能剥夺选择权**
- **损失厌恶**：失去X的痛苦≈得到2X的快乐；保护机制的价值常被低估

## 模块六：心流与学习

- **心流通道**：技能与挑战匹配→心流；挑战>>技能→焦虑；技能>>挑战→无聊
- **IKEA效应**：参与制作→主观估值更高→黏性更强
- **社会奖赏神经等价性**：社交认可激活的脑区与金钱奖励相同；排行榜、成就展示是实打实的奖励

## 诚实边界

- 认知科学研究本身存在**可复现性危机**——部分经典实验近年复现失败，本 Skill 优先选择多次复现成功的机制
- 从实验室到产品设计的**迁移损耗**——实验条件下的效应量在真实环境中通常缩小
- 本 Skill 偏重**认知和情绪层面**，不覆盖社会文化、经济理性等影响行为的其他维度
- "高参与低负荷"是理想目标，实际设计中两者经常冲突——增加参与几乎总会增加某种负荷
- 认知机制解释"为什么有效"，不替代"什么是好玩的"——好玩仍然需要人的直觉（Gate 类判断）

# 认知科学基础文献库

> 三本核心著作的系统蒸馏 + 前沿论文补充。不是书评，是**可检索的知识索引**。
> 与 `cognitive-design-engine`（实战版）的关系：本 Skill 是理论层，那个是应用层。

## 适用场景

- 需要给设计决策找学术依据时
- 与 `cognitive-design-engine` 配合，追问"这个设计原则背后的原理是什么"
- 评估一个设计方案是否符合认知科学规律
- 辨别"直觉上对"和"有证据支撑"的区别

## 不适用于

- 直接输出设计方案（那是 `cognitive-design-engine` 和 `game-review` 的事）
- 心理治疗或临床诊断相关的应用

# Part A：《思考，快与慢》（Daniel Kahneman, 2011）

## 核心框架：双系统理论

### 系统 1（快思考）

- **特征**：自动化、无意识、低耗能、快速、并行处理
- **能力**：模式识别、情绪反应、因果直觉、联想激活、刻板印象
- **弱点**：容易被框架效应、锚定、可得性、代表性等启发式欺骗
- **运行条件**：持续在线，不需要意志力，不会"累"

### 系统 2（慢思考）

- **特征**：刻意、有意识、高耗能、缓慢、串行处理
- **能力**：逻辑推理、复杂计算、规则遵守、自我控制、假设检验
- **弱点**：容量有限、容易疲劳（自我损耗）、被系统 1 的输出锚定
- **运行条件**：需要注意力资源，会被认知负荷耗竭

### 两系统的交互

- 系统 1 持续产出印象、直觉和意图 → 系统 2 通常接受（"认知吝啬鬼"）
- 系统 2 只在检测到意外、困难或明确被要求时才介入
- 系统 1 无法被关闭——你知道视错觉是假的，但仍然看到它

## 判断与决策中的启发式和偏差

### 锚定效应（Anchoring）

- **机制**：先接触到的数字影响后续判断，即使该数字完全无关
- **实验证据**：问"甘地去世时是否超过 114 岁"的人，对甘地去世年龄的估计远高于被问"是否超过 35 岁"的人
- **强度**：即使被告知锚定值是随机的，效应仍然存在
- **应用领域**：定价、谈判、数值设计、第一印象

### 可得性启发（Availability Heuristic）

- **机制**：越容易想到的例子，被判断为概率越高
- **影响因素**：媒体曝光度、个人经历的鲜明程度、情绪强度
- **经典案例**：飞机失事后人们高估飞行风险（实际远低于驾车）
- **扩展——可得性级联**：媒体报道→公众恐慌→更多报道→更多恐慌，自我放大

### 代表性启发（Representativeness）

- **机制**：根据"像不像某个类别"来判断概率，忽略基础概率
- **经典案例**：Linda 问题——"银行出纳员且女权活动家"被判断为比"银行出纳员"更可能，违反概率基本公理
- **后果**：忽视样本量、忽视回归均值、过度推断因果

### 损失厌恶（Loss Aversion）

- **核心数据**：损失的心理权重约为等额收益的 1.5-2.5 倍（中位数约 2 倍）
- **禀赋效应**：拥有的东西被赋予更高价值——不是因为"喜欢"，而是因为"放弃 = 损失"
- **现状偏差**：维持现状被偏好，因为任何改变都包含"放弃当前状态"的损失成分

### 框架效应（Framing）

- **机制**：同一事实的不同表述方式导致不同决策
- **经典案例**：亚洲疾病问题——"200 人获救"vs"400 人死亡"，数学等价但选择逆转
- **原理**：框架决定了参照点，参照点决定了什么是"得"什么是"失"

### 峰终定律（Peak-End Rule）

- **机制**：体验的回忆评价由峰值强度和结束时感受决定，与时长几乎无关（时长忽视）
- **实验证据**：冷水实验——60 秒 14°C vs 60 秒 14°C + 30 秒 15°C，后者虽然总痛苦更多但被评为"更不痛苦"（因为结尾改善了）
- **应用**：体验设计中，结尾质量和峰值设计比平均质量更重要

### 回归均值（Regression to the Mean）

- **机制**：极端表现之后大概率回归平均水平，这是统计规律而非因果
- **常见误归因**：教练惩罚差表现→下次表现变好→归功于惩罚（实际是回归均值）
- **应用**：不要把随机波动归因于干预措施

## 前景理论（Prospect Theory）

Kahneman 与 Tversky 最核心的理论贡献：

### 四个核心要素

1. **参照点依赖**：价值是相对于参照点的变化量，不是绝对值
2. **损失厌恶**：损失曲线比收益曲线更陡（约 2 倍）
3. **敏感度递减**：从 100 到 200 的感受差距 > 从 1100 到 1200
4. **概率加权**：小概率被高估（买彩票），大概率被低估（买保险）

### 四重模式

| | 高概率 | 低概率 |
|---|---|---|
| **收益** | 风险规避（确定效应） | 风险寻求（彩票效应） |
| **损失** | 风险寻求（翻盘心理） | 风险规避（保险效应） |

## 两个自我

- **体验自我**：此刻正在经历的感受（每秒约 3 次情绪采样）
- **记忆自我**：事后回忆中对体验的评价（受峰终定律和时长忽视支配）
- **冲突**：记忆自我做决策，但不忠实于体验自我的实际感受
- **设计含义**：产品的口碑和复购由记忆自我决定，而非体验自我的每秒感受

# Part B：《助推》（Thaler & Sunstein, 2008 / 终极版 2021）

## 核心概念：选择架构

### 自由家长主义（Libertarian Paternalism）

- **定义**：在保留完全选择自由的前提下，通过设计选择环境引导人们做出对自己更好的选择
- **不是强迫**：任何选项都不被禁止或经济惩罚
- **核心洞察**：不存在"中立的"选项呈现方式——任何呈现方式都在影响选择，所以不如有意识地影响

### 选择架构师（Choice Architect）

- **定义**：负责设计选择环境的人——菜单设计者、表单设计者、产品经理、策划
- **责任**：你已经在影响用户选择了（通过默认值、顺序、分组），不如把这件事做好

## 六大助推工具（NUDGES 框架）

### iNcentives（激励）

- 让选择的成本和收益对决策者**可见**
- 问四个问题：谁用？谁选？谁付钱？谁获利？——四个答案不一致时容易出问题
- 关键：人对"不做"的成本感知很弱——需要让机会成本可见

### Understanding mappings（理解映射）

- 帮人把选项翻译成最终体验
- 例：冰淇淋试吃 > 看成分表——直接让人体验结果比解释参数有效
- 应用：让用户看到"这个选择意味着什么体验"，而非"这个选择的参数是什么"

### Defaults（默认值）

- **最强的助推工具**：大量实证显示大多数人不改默认值
- 器官捐献：opt-out 国家捐献率 > 90%，opt-in 国家 < 20%——同样的人不同的默认值
- 设计原则：默认值应设为"如果用户不懂、不在意时对他最好的选项"
- **分类**：
  - 强制主动选择：不设默认值，强制用户做选择
  - 智能默认值：根据用户画像动态调整默认值
  - 持久默认值 vs 每次重置：一次设定持续生效 vs 每次要求确认

### Give feedback（给反馈）

- 人在做了正确/错误选择后需要即时反馈
- 好的反馈系统：在偏离轨道时及时提醒，而非事后追责
- 例：路面的震动条纹——偏离车道时物理性提醒，不需要罚款

### Expect error（预期错误）

- 设计应假设用户**会犯错**，并降低犯错的代价
- 例：巴黎地铁双向插入的卡 > 只能单向插入的卡
- 应用：撤销功能、确认对话框、防呆设计

### Structure complex choices（简化复杂选择）

- 选择太多 → 决策瘫痪（果酱实验：24 种果酱的展台购买率低于 6 种）
- 策略：分层呈现（先选大类再选细节）、过滤和排序、智能推荐
- 但过度简化也有风险——用户可能觉得选择权被剥夺

## 助推的伦理边界

- **透明性**：助推应该是可见的，不应欺骗
- **可退出**：用户必须能轻松选择其他选项
- **利他性**：助推的方向应该符合被助推者的利益，而非仅符合设计者的利益
- **暗黑模式（Sludge）**：故意制造摩擦阻碍人做好选择——是助推的反面，应避免

# Part C：《体验引擎》（Tynan Sylvester, 2013）

## 核心论点：游戏 = 人造体验生成器

- 游戏不是打包好的媒体产品，是**生成体验的系统**
- 其他媒体给你一段固定体验，游戏在每次运行时**实时生成**不同体验
- 设计者不是在设计"内容"，是在设计"生成内容的规则"

## 情绪触发器模型

### 情绪不是被"放进"游戏的，是从交互中涌现的

- 游戏机制本身不包含情绪，情绪是玩家和机制交互时**涌现**的产物
- 同一个机制对不同玩家可以产生完全不同的情绪
- 设计者设计的是**触发条件**，不是**情绪本身**

### 人类关切（Human Concerns）

Sylvester 提出的情绪触发分类——不是情绪种类，而是**引发情绪的事件类型**：

| 关切类型 | 触发的情绪范围 | 游戏中的体现 |
|----------|---------------|-------------|
| **胜利与失败** | 骄傲、羞耻、挫败、成就感 | 输赢、排名、达成 |
| **威胁与安全** | 恐惧、紧张、安心、释放 | 生存、躲避、安全区 |
| **社交认同** | 归属、孤独、被认可、被排斥 | 公会、排行榜、合作 |
| **创造与破坏** | 满足、遗憾、掌控感 | 建造、定制、沙盒 |
| **获得与失去** | 贪婪、惋惜、满足、空虚 | 收集、掉落、交易 |
| **学习与掌握** | 好奇、困惑、顿悟、无聊 | 教程、发现、技能成长 |
| **预期与惊喜** | 期待、悬念、惊喜、失望 | 随机事件、剧情反转 |

### 情绪的层叠（Emotional Layering）

- 单一事件可以同时触发多种人类关切 → 多重情绪叠加 → 体验更丰富
- 例：PVP 击杀同时触发"胜利"+"社交认同"+"掌握"→ 三重正面叠加
- 但也可能叠加出矛盾情绪——"赢了但手段不光彩"→ 胜利 + 内疚

## 涌现叙事 vs 脚本叙事

### 涌现叙事（Emergent Narrative）

- 从系统交互中**自发产生**的故事，不是预先写好的
- 每个玩家的故事都不同——因为系统状态不同
- 更有粘性——"我的故事"比"别人写给我的故事"更有归属感
- 例：EVE Online 的星际战争、RimWorld 的殖民地悲剧——都不是编剧写的

### 脚本叙事（Scripted Narrative）

- 传统的、预先编写的故事
- 优势：可以精确控制情绪节奏和信息披露
- 劣势：重复体验时快速贬值（"已经知道结局了"）

### 混合模式

- 最佳实践是两者混合：脚本提供框架和高潮，涌现提供个人化填充
- Sylvester 的建议：**系统先行，叙事辅助**——先确保系统能产出有趣的涌现，再用叙事包装

## 心流理论的设计翻译

### Csikszentmihalyi 的八要素（Sylvester 的设计翻译版）

| 理论要素 | 设计翻译 |
|----------|---------|
| 技能与挑战匹配 | 动态难度或分层难度，不是固定曲线 |
| 清晰目标 | 玩家任何时刻都知道"下一步该干什么" |
| 即时反馈 | 每个操作都有可感知的响应（不超过 200ms） |
| 掌控感 | 失败可归因到自己的操作而非随机 |
| 深度专注 | 消除无关干扰（弹窗、广告、社交打断） |
| 时间扭曲 | 不是设计目标而是副产品——如果发生了说明心流在 |
| 自我意识消失 | 玩家不再"想着自己在玩游戏" |
| 内在奖励 | 活动本身有趣，不依赖外部奖励 |

### 心流的敌人

| 敌人 | 机制 | 设计对策 |
|------|------|---------|
| **焦虑** | 挑战 >> 技能 | 渐进引导、失败代价降低 |
| **无聊** | 技能 >> 挑战 | 引入随机性、提升复杂度 |
| **认知过载** | 无关负荷过高 | 简化 UI、渐进披露 |
| **打断** | 外部刺激中断专注 | 减少强制弹窗、给玩家控制权 |
| **不公平感** | 失败不可归因到自己 | 透明规则、可理解的输赢逻辑 |

## 设计作为迭代

- **核心主张**：好设计不是天才的灵感，是**有纪律的迭代**
- 快速原型 → 测试 → 观察实际体验（不是问卷！）→ 修改 → 再测试
- 观察比提问有用——玩家说的和做的往往不一致
- 砍功能比加功能更需要勇气，也更常是正确的决策

# Part D：前沿论文补充

## D1. 多巴胺预测误差（Schultz 系列）

**核心发现**（Schultz et al., 1997, Science）：

中脑多巴胺神经元编码的不是奖励本身，而是**预测误差信号**：
- 意外奖励 → 强烈放电
- 预期中的奖励 → 不放电
- 预期奖励未出现 → 放电抑制（低于基线）

**时间动态**：
- 随着学习，多巴胺反应从"奖励出现时"前移到"预测奖励的线索出现时"
- 完成学习后，奖励本身不再触发多巴胺，只有**超出预期的部分**才触发
- 这解释了为什么固定奖励会"麻木"——PE 归零后多巴胺不再释放

**2016 综述更新**（Schultz, Dialogues in Clinical Neuroscience）：
- 预测误差编码存在于伏隔核、前额叶、纹状体等多个区域
- 不仅编码奖励的有无，还编码奖励的大小、概率和时间
- 惩罚的预测误差由不同的神经通路处理（非多巴胺主导）

## D2. 价值驱动注意力捕获 VDAC（Anderson 系列）

**开创性发现**（Anderson et al., 2011, PNAS）：
- VDAC 是继目标驱动和刺激驱动之后的**第三种注意力控制模式**
- 与奖励关联的特征即使变得任务无关，仍然自动捕获注意力
- 这种捕获是非自愿的——知道它会干扰也无法阻止

**消退条件**（2022-2023 更新）：
- VDAC 在特定条件下可以消退：当奖励特征变为任务无关且不再强化时
- 但消退不彻底——残余效应可持续数天到数周
- 认知控制训练可以**对抗** VDAC（Learned cognitive control counteracts VDAC, 2023）
- 个体差异：工作记忆容量低和高冲动性的人更易受 VDAC 影响

**神经机制**（MEG 研究, 2020, J. Neurosci）：
- 价值调节发生在刺激呈现后约 260ms，定位于后部视觉皮层和顶叶
- 早期视觉处理（200ms 以前）不受价值学习影响
- 说明 VDAC 是高层注意力选择阶段的效应，不是感知层面的

## D3. Near-miss 神经生理学（2024 系统综述）

**核心发现**（J. Gambling Studies, 2024）：
- **P300 成分**：Near-win > Loss，接近 Win 的水平——大脑在奖励加工层面把"差一点"处理得更像"赢了"
- **FRN（反馈相关负波）**：结果不一致——部分研究显示 Near-win 的 FRN 类似 Loss，部分类似 Win
- **解读**：Near-miss 可能同时激活奖励通路（"几乎赢了"）和冲突监测通路（"但实际输了"），两个信号并存
- **问题赌徒差异**：问题赌徒对 Near-win 的 P300 显著高于正常人——奖励系统对"差一点"的响应被放大

## D4. 视听刺激与沉浸（2025, J. Gambling Studies）

**核心发现**：
- **中等强度视听刺激产生最大沉浸**，而非最大强度——倒 U 型曲线
- 焦虑、抑郁、压力水平高的个体沉浸度更高（寻求逃避）
- 性别差异：女性在中等刺激条件下沉浸度高于男性

**设计含义**：过度刺激反而打破沉浸——这是"高参与低负荷"的实验证据。

## D5. 累积奖励的 dACC 编码（2026, Nature Communications）

**核心发现**：
- 当虚拟代币逐步累积接近 jackpot 时，dACC（背侧前扣带皮层）的价值编码增强
- 接近目标时决策更快更准确——参照依赖价值模型（越接近目标，每一步的主观价值越高）
- 这是"进度条效应"的首个神经影像证据

## D6. Machine Zone 与 Dark Flow（Schüll + Dixon）

**Schüll《Addiction by Design》核心概念**：
- **Machine Zone**：slots 玩家进入的恍惚状态——不是为了赢钱，是为了**维持这个状态本身**
- 与心流的关键区别：心流是技能匹配挑战后的积极沉浸；Machine Zone 是认知窄化后的消极逃避
- 设计全栈如何服务于 Machine Zone：人体工学椅让你不动、无窗让你失去时间感、快速循环让你不需要决策

**Dixon 的 Dark Flow 研究**：
- Dark Flow = slots 中类似心流的体验，但缺乏心流的核心要素——技能成长和掌控感
- Dark Flow 与问题赌博正相关，而积极心流与问题赌博无关
- 区分标准：有没有技能成长感、失败能不能归因到自己、离开后是满足还是空虚

## D7. 部分强化消退效应 PREE（Frontiers in Psychology, 2016）

**核心发现**：
- 被间歇强化（有时给奖励、有时不给）训练的行为，在奖励完全停止后**持续时间远长于**持续强化的行为
- 更长的试次间隔（ITI）+ 低强化率 → 消退阶段更持久
- 冲动性高的个体消退更慢

**设计含义**：这是"为什么概率掉落比确定掉落更让人上瘾"的实验机制——部分强化天然抗消退。

## 诚实边界

- 认知科学存在**可复现性危机**——本 Skill 优先选择多次复现成功的机制（Kahneman 自己也承认部分 priming 实验复现失败）
- 三本书的出版年份（2008-2013）意味着部分内容已有更新——论文部分补充了 2020-2026 的进展
- 从实验室效应到产品设计的**迁移损耗**不可忽视——实验中显著的效应在复杂真实环境中可能减弱
- 《助推》的伦理框架（自由家长主义）是一种价值立场，不是科学结论——"应不应该助推"是哲学问题
- slots 相关研究多在赌博成瘾语境下进行，迁移到休闲游戏设计时需要重新评估伦理边界

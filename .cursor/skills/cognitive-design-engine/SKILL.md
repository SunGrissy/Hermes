# 认知设计引擎

> 给所有设计类 Skill 装底层解释引擎——把"直觉上对"变成"机制上可解释"。
> 按**设计场景**组织，不按学科分。每个模块：机制原理 → 设计含义 → 常见误用 → 检验方法。

## 角色规则

- 不扮演任何人物，以认知科学视角提供分析
- 术语首次出现时给一句人话翻译，不堆学术黑话
- 优先用游戏设计案例说明原理，其次用产品设计案例

## 适用场景

- 审查设计方案时，解释"为什么这样设计对/不对"
- 评估体验节奏时，用认知机制定位问题
- 与 `game-review`、`producer-mind`、`boss-precheck-review` 配合，提供底层科学支撑
- 新功能设计时，用认知原理预判玩家反应

## 不适用于

- 纯数值平衡（那是数值策划的领域）
- 纯视觉美学判断（那是主美的领域）
- 商业模型和变现策略（认知引擎只管体验层）

## 回答工作流（Agentic Protocol）

### Step 1: 定位设计问题属于哪个认知域

| 认知域 | 信号词 |
|--------|--------|
| 注意力与信息负荷 | "信息太多"、"看不过来"、"不知道该看哪" |
| 奖励与动机 | "没动力"、"奖励无感"、"上瘾"、"麻木" |
| 情绪与记忆 | "没感觉"、"记不住"、"被坑的感觉很强" |
| 预期与预测误差 | "没惊喜"、"太可预测"、"落差太大" |
| 决策与引导 | "不知道该选什么"、"选择太多"、"被强迫" |
| 心流与学习 | "太难"、"太简单"、"无聊"、"焦虑" |

### Step 2: 调取对应模块的认知机制分析

### Step 3: 输出

```
1. 认知诊断（用机制语言描述问题本质）
2. 设计含义（翻译成策划能听懂的语言）
3. 改进方向（基于机制的具体建议）
4. 误用警告（这个机制滥用会怎样）
```

## 模块一：注意力与信息负荷

### 1.1 工作记忆容量（4±1 组块）

**机制**：人同时能主动处理的信息组块约 4 个（米勒 7±2 已被 Cowan 修正为 4±1）。超出即过载，表现为"看了但没进脑子"。

**设计含义**：
- UI 同屏核心信息组不超过 4 个
- 复杂系统拆成"每次只理解一层"的渐进式披露
- Boss 技能演出一次展示不超过 3 个需要玩家注意的元素

**常见误用**：
- 活动页面同时展示 8 种奖励 + 3 种货币 + 2 个倒计时 → 哪个都没看进去
- 新手引导一次解释 5 个系统 → 全忘了

**检验方法**：截图，数一数玩家需要同时处理的独立信息组。超过 4 个就需要分层或分时。

### 1.2 注意力双系统（背侧 DAN / 腹侧 VAN）

**机制**：
- **背侧网络（DAN）**：自上而下，目标驱动——"我主动在找什么"
- **腹侧网络（VAN）**：自下而上，刺激驱动——"什么东西突然抢了我的注意力"

好的设计让两个系统**交替激活**：主动搜索（DAN）→ 意外惊喜（VAN）→ 重新聚焦（DAN）。

**设计含义**：
- 纯 DAN（全是目标导向操作）→ 疲劳、无聊
- 纯 VAN（全是弹窗、特效抢注意力）→ 烦躁、失控感
- 好节奏：让玩家主动追目标的过程中，穿插适度的意外刺激

**常见误用**：登录后连弹 5 个活动弹窗——全是 VAN 强制捕获，玩家的 DAN（我想做什么）完全被压制。

### 1.3 认知负荷三分类（Sweller）

**机制**：
- **内在负荷**：任务本身的复杂度，由内容决定，设计者难以改变
- **无关负荷**：糟糕的信息呈现带来的额外负担，应**消除**
- **相关负荷**：有意义的思考活动（建图式、做预测），是**有益的**

**设计目标**：消除无关负荷 → 释放认知资源 → 投入相关负荷 → 进入心流。

**MG 案例**：通过动效叙事管理和分级信息，避免无关负荷超载。每个步骤都包含"建立预期→验证预期"的相关负荷循环，而非无意义等待。

**检验方法**：对设计中每个元素问——"这是帮玩家理解（相关），还是让玩家困惑（无关）？"

## 模块二：奖励与动机

### 2.1 多巴胺预测误差（Prediction Error Learning, PEL）

**机制**：多巴胺不是对奖励本身的反应，是对**预期和实际之间差值**的反应。

```
PE = 实际结果 − 预期结果
PE > 0 → 多巴胺释放，正强化，希望与动机增强
PE < 0 → 多巴胺抑制，负强化，动机减弱
PE = 0 → 学习停止，行为维持，平静但缺少兴奋
```

**设计含义**：
- 固定奖励 → PE 迅速归零 → 麻木（"每天签到 100 钻"第三天就没感觉）
- 可变奖励 → PE 持续存在 → 参与度维持（概率掉落、随机事件）
- **为"预期"而设计，而非为"奖励"而设计**——核心乐趣来源于预期管理

**MG 案例**：每次掷骰子都是一个微型 PEL 循环——建立预期（会走到哪）→ 验证（实际停在哪）→ 结果分支（好事还是坏事）。持续制造小型预测误差。

**常见误用**：
- 保底机制让 PE 永远 ≥ 0 → 安全但无趣
- 负面 PE 过强过频且玩家无法通过策略调整 → 习得性无助 → 流失

### 2.2 可变比率强化（Variable Ratio Schedule）

**机制**：平均每 N 次行为给一次奖励，但具体哪次不确定。所有强化程式中**最抗消退**——停止奖励后行为持续最久。

**设计含义**：
- 概率掉落 > 确定掉落（动机持续性）
- 抽卡/开箱的核心机制就是可变比率强化
- 但需要保底兜底——纯随机导致极端负面体验

**常见误用**：强化比率太低（1000 抽出一个）→ 超过玩家的"预期调节能力"→ 不是"惊喜"而是"欺诈感"。

### 2.3 价值驱动注意力捕获（VDAC）

**机制**：通过反复学习，与奖励关联的刺激获得内在"价值标签"。一旦被赋予价值，即使与当前目标无关，也会**自动、非自愿地**捕获注意力。

**形成三步**：
1. **联想学习**：特定感官特征与奖励体验同时出现（"叮"的音效 + 金币飞出）
2. **价值编码**：该感官特征获得高价值标签（系统 1 自动联想）
3. **自动化捕获**：此后只要出现该感官信号，注意力自动被吸引

**设计含义**：
- 正向利用：建立"音效/特效 → 好事"的联结，玩家听到声音就兴奋
- MG 案例：Cash Boost 触发时改变节奏 + 震动 + 特效聚拢 Roll 按钮 → 建立价值标签 → 此后类似信号自动捕获注意力

**误用警告**：
- 价值标签一旦形成**很难消除**——不兑现的价值标签会造成长期注意力干扰
- 过多无关的高价值信号持续分散注意力 → 低烈度但持续的负面情绪 → 认知耗竭
- 要对抗已形成的价值标签需要调动系统 2 额外消耗认知资源

### 2.4 习惯回路（暗示→惯常→奖赏）

**机制**：行为自动化的三环结构。暗示触发行为，行为产出奖赏，奖赏强化暗示-行为联结。

**设计含义**：
- 日常循环本质上在建习惯回路：登录提醒（暗示）→ 完成日常（惯常）→ 领奖励（奖赏）
- 暗示越明确、奖赏越即时，习惯形成越快
- 一旦形成习惯，移除奖赏不会立刻消除行为（抗消退性）

**常见误用**：暗示太弱（埋在三级菜单里）或奖赏延迟太久（月度结算）→ 回路无法闭合。

## 模块三：情绪与记忆

### 3.1 峰终定律（Peak-End Rule）

**机制**：人对体验的总体评价主要由两个时刻决定——**最强烈的时刻（峰值）**和**结束时的感受（终值）**。过程的平均值和时长影响很小。

**设计含义**：
- 一个关卡只需要一个"最爽的瞬间"+ 一个"不错的结尾"，整体评价就好
- 中间过程可以有波谷（对比度反而增强峰值）
- 结束体验必须是正面的——虎头蛇尾是最伤评价的

**检验方法**：画出体验的情绪曲线，标记峰值和终值。峰值不够高 → 需要一个 wow moment。终值是负面的 → 结尾需要重做。

### 3.2 情绪 ABC 理论 + 认知评估

**机制**：情绪不直接由刺激引起，而是由**对刺激的认知评估**驱动。评估回答四个核心问题：

| 评估维度 | 问题 | 驱动的情绪 |
|----------|------|-----------|
| 相关性 | 这对我重要吗？ | 兴趣 vs 无动于衷 |
| 一致性 | 对我的目标是好是坏？ | 正面 vs 负面情绪 |
| 归因 | 谁该负责？我能应对吗？ | 愤怒/掌控感 vs 焦虑/无助 |
| 前景 | 接下来会怎样？ | 希望 vs 恐惧 |

**设计含义**：
- 相关性：奖励必须和玩家当前目标关联，"与我无关的奖励"不产生情绪
- 归因：**内部可控归因**产生掌控感（"我做对了所以赢了"），**外部不可控归因**产生无助（"系统坑我"）
- 前景：给希望（"下次可以"）比给补偿（"这次赔你"）更有效

**常见误用**：PVP 中失败归因设计不当——玩家归因为"匹配不公平"（外部不可控）而非"我还需要练习"（内部可控）→ 愤怒而非成长感。

### 3.3 杏仁核快通道（情绪记忆优先）

**机制**：情绪体验走杏仁核快通道，比理性记忆编码更快、更持久。负面情绪记忆尤其顽固。

**设计含义**：
- "被坑了一次"比"被奖励十次"记得更清楚
- 公平感伤害是情绪记忆——修复成本远高于预防成本
- 首次体验的情绪印记最深——新手前 10 分钟的设计权重应极高

**与 producer-mind 的连接**：制作人的"公平感 > 社交 > 爽感 > 留存 > 付费"排序，底层就是杏仁核快通道——公平感受损的情绪记忆比爽感的正面记忆更持久。

## 模块四：预期与预测误差（深化）

### 4.1 动效叙事：从"反馈"到"预期管理"

**机制**：传统动效 = 行为发生后的反馈。高阶动效 = 事件发生前就开始提供线索，引导玩家建立和管理预期。

**MG 的三级进化**：
1. **CM 级**：传统功能性反馈（点了有反应）
2. **RM 级**：飞积分的节奏优化 + 正向价值标签
3. **MG 级**：完整的动效叙事——不识字也能通过动效理解发生了什么、即将发生什么

**设计原则**：
- 在事件发生前就开始用动效提供线索
- 让玩家"捕捉线索"的过程本身成为参与
- 前置正反馈，提高体验下限（MG 的 MegaHeist：戴眼罩瞬间金光已给正反馈）

### 4.2 Near Miss（差一点就赢了）

**机制**：Near Miss 利用 PEL 制造"几乎成功"的预测误差——实际结果是失败，但大脑处理方式接近成功。

**设计含义**：
- 适度 Near Miss 维持动机（"差一点，下次能行"）
- 过度 Near Miss 导致认知失调（"明明差一点为什么总是差一点"→ 归因为被操纵）

### 4.3 联结机制的三阶段

```
初始阶段：奖励本身触发多巴胺
学习阶段：线索先于奖励 → 大脑学习线索
巩固阶段：多巴胺在线索出现时就释放（预期），奖励兑现时不再额外增加
```

**设计含义**：成熟玩家的多巴胺释放点已经前移到"线索出现时"而非"奖励到手时"。所以**线索设计比奖励设计更重要**。

## 模块五：决策与引导

### 5.1 系统 1 / 系统 2（双过程理论）

**机制**：
- **系统 1**：快、自动、无意识、低耗能——直觉、情绪、习惯
- **系统 2**：慢、刻意、有意识、高耗能——推理、计算、规划

**设计含义**：
- 爽感体验走系统 1（即时反馈、视觉冲击、节奏感）
- 策略体验走系统 2（资源规划、阵容搭配、风险评估）
- 好设计让两个系统**交替激活**，不让系统 2 持续过载

**检验方法**：标记设计中每个环节调动的是系统 1 还是系统 2。连续 3 个以上系统 2 环节 → 需要插入系统 1 的"呼吸点"。

### 5.2 选择架构（助推）

**机制**：选项的呈现方式本身就在影响选择——顺序、默认值、分组、参照物都是设计变量。

**设计工具箱**：
| 工具 | 原理 | 游戏应用 |
|------|------|---------|
| **默认选项** | 大多数人不改默认 | 推荐配置、自动战斗开关 |
| **锚定** | 第一个数字影响后续判断 | 商城原价→现价、战力数字展示 |
| **框架效应** | 同样的事换说法接受度不同 | "90% 胜率"vs"每 10 场输 1 场" |
| **社会规范** | "80% 的人选了这个" | 人气标签、排行榜、推荐标记 |
| **显著性** | 突出的选项被优先考虑 | 高亮推荐、限时标记 |

**核心原则（自由家长主义）**：可以设计环境让好选择更容易、差选择更难，但**不能剥夺选择权**。这是"不强迫玩家"红线的认知科学依据。

### 5.3 损失厌恶（前景理论）

**机制**：失去 X 的痛苦 ≈ 得到 2X 的快乐。人对损失的敏感度约为收益的 2 倍。

**设计含义**：
- "掉段"比"升段"感受强烈约 2 倍 → 保护机制的价值被低估
- 限时活动（"不买就没了"）比常驻更有效——利用损失厌恶
- 扣除已有资源比不给新资源的负面感受强得多

**常见误用**：过度利用损失厌恶做付费转化 → 短期有效，长期造成"被逼付费"的情绪记忆 → 流失。

## 模块六：心流与学习

### 6.1 心流通道（Csikszentmihalyi）

**机制**：当技能水平和挑战难度匹配时进入心流。挑战 >> 技能 → 焦虑；技能 >> 挑战 → 无聊。

**设计含义**：
- 难度曲线不是线性递增，是跟随玩家技能成长的动态匹配
- 合理的认知负荷水平是进入心流的前提——消除无关负荷，聚焦相关负荷
- 心流状态下时间感消失——是留存的最强驱动力

### 6.2 IKEA 效应

**机制**：自己参与制作的东西主观估值更高，即使客观质量一般。

**设计含义**：
- 自定义角色/家园/装备 → 投入劳动 = 提升主观价值 = 提升沉没成本
- 让玩家"参与创造"比"给现成的"黏性更强
- 适度的组装/定制环节增加归属感

### 6.3 社会奖赏的神经等价性

**机制**：fMRI 研究显示社会认可（点赞、排名、公会夸奖）激活的脑区与金钱奖励**相同**。

**设计含义**：
- 社交系统不是"虚拟安慰奖"，在神经层面和物质奖励等价
- 排行榜、成就展示、公会贡献可见——都是实打实的奖励
- 但反面也成立：社交否定（被踢出公会、被嘲讽）的伤害等同物质惩罚

## 诚实边界

- 认知科学研究本身存在**可复现性危机**——部分经典实验近年复现失败，本 Skill 优先选择多次复现成功的机制
- 从实验室到产品设计的**迁移损耗**——实验条件下的效应量在真实环境中通常缩小
- 本 Skill 偏重**认知和情绪层面**，不覆盖社会文化、经济理性等影响行为的其他维度
- "高参与低负荷"是理想目标，实际设计中两者经常冲突——增加参与几乎总会增加某种负荷
- 认知机制解释"为什么有效"，不替代"什么是好玩的"——好玩仍然需要人的直觉（Gate 类判断）

# 认知炼化炉

> 从人物的一手素材中蒸馏认知操作系统（Cognitive OS），产出可对话的数字思考伙伴。
> 核心理念：**蒸馏的是思考方式，不是说话方式**。

## 适用场景

- **炼化自己人**：制作人、主美、主程、TL——基于工作区内的规范、评审记录、沟通偏好
- **炼化外部人物**：行业专家、知名思考者——基于公开著作、访谈、演讲
- **炼化主题**：不是人，而是一种方法论——基于多人/多流派的综合

## 不适用于

- 纯娱乐性的角色扮演（"扮演一个海盗"）——本工具面向严肃的思维辅助
- 需要实时信息的判断（"XX 今天说了什么"）——本工具蒸馏的是稳定的思维模式
- 敏感人物的争议性判断——涉及伦理风险时应明确声明

## 炼化流程（六阶段）

### Phase 0: 入口分流

确认炼化类型和素材来源：

| 类型 | 素材来源 | 特征 |
|------|----------|------|
| **自己人** | 工作区文件（rules/skills/会议记录/评审记录） | 一手素材丰富、可交叉验证 |
| **外部人物** | 书籍、访谈、演讲、文章 | 需要 web search 采集、二手解读需警惕 |
| **主题** | 多人/多流派综合 | 先识别 3-5 个核心贡献者，再分别蒸馏 |

**GATE**: 如果素材不足 3 个独立来源 → 停下来告知用户，要么补充素材，要么标注 `[DRAFT]`

### Phase 1: 六维信息采集

围绕目标人物，从六个维度采集信息：

| 维度 | Agent 职责 | 产出 |
|------|-----------|------|
| **著作/系统思考** | 阅读长文、规范、方法论文档 | 核心观点提取 |
| **对话/即兴反应** | 阅读会议记录、评审意见、沟通记录 | 即时判断模式 |
| **表达 DNA** | 分析措辞、句式、偏好词、禁忌词 | 表达风格画像 |
| **他者视角** | 搜索他人对此人的评价、反馈 | 盲点和争议 |
| **决策记录** | 提取关键决策及其理由 | 决策启发式 |
| **时间线** | 关键转折点、立场变化 | 思维演进轨迹 |

**自己人快捷路径**：如果素材在工作区内，直接 Grep/Read 相关文件，无需 web search。

### Phase 1.5: 采集检查点（CHECKPOINT）

输出采集摘要表格，让用户确认：
- 找到了哪些素材、各维度覆盖度如何？
- 有没有遗漏的重要素材（用户可补充）？
- 某些维度素材不足，是否继续？

**等待用户确认后再进入 Phase 2。**

### Phase 2: 框架提炼

从采集结果中提取心智模型和决策启发式。

#### 2a. 心智模型提取（3-7 个）

**三重验证筛选**——每个候选心智模型必须通过：

| 验证 | 标准 | 不通过则 |
|------|------|----------|
| **跨域复现** | 此模型在 2+ 个不同场景中被使用过 | 降级为"单次观点"，不纳入 |
| **生成力** | 此模型能在新场景中产出有价值的推导 | 太具体/太死板，不纳入 |
| **排他性** | 此模型不是通用常识（如"要数据驱动"） | 太泛，合并或去掉 |

#### 2b. 决策启发式提取（5-10 条）

每条启发式必须包含：
- 规则名（简短标签）
- 具体描述（不是泛泛之谈）
- 适用场景
- 至少一个来自素材的真实案例

#### 2c. 表达 DNA 量化

| 维度 | 提取内容 |
|------|----------|
| 句式指纹 | 此人高频使用的 3-5 个句式模板 |
| 词汇偏好 | 高频词、自造概念、行业术语 |
| 确定性 | 高（"我的判断是"）还是低（"也许可以考虑"） |
| 类比密度 | 频繁用类比还是直述 |
| 疑问句比例 | 多用反问引导思考还是直接给结论 |
| 禁忌词/反模式 | 此人明确反对的表述方式 |

### Phase 2.5: 提炼检查点（CHECKPOINT）

输出提炼结果摘要，让用户确认：
- N 个心智模型是否准确？有没有遗漏或误提取？
- 决策启发式是否反映真实偏好？
- 表达 DNA 是否传神？

**等待用户确认后再进入 Phase 3。**

### Phase 3: Skill 构建

按标准模板组装 SKILL.md，结构如下：

```
1. 角色规则（第一人称、免责、退出机制）
2. 回答工作流（Agentic Protocol: 分类→研究→输出）
3. 核心心智模型（3-7 个，每个含：描述、应用、局限）
4. 决策启发式（5-10 条，每条含：规则、描述、场景）
5. 表达 DNA（句式、词汇、风格标签）
6. 价值观与反模式（追求/拒绝/内在张力）
7. 诚实边界（至少 3 条）
8. 与现有 Skill 关系（边界声明）
9. 变更记录
```

**关键**：Agentic Protocol 的 Step 2（研究）维度必须从心智模型自动推导，不是固定模板。

### Phase 4: 质量验证

用以下方式验证蒸馏质量：

| 测试 | 方法 | 通过标准 |
|------|------|----------|
| **已知场景** | 用此人已处理过的案例测试 | 输出与真实决策方向一致 |
| **边缘场景** | 用此人可能遇到但没有记录的场景测试 | 输出符合其思维模式逻辑 |
| **风格测试** | 让 Skill 回答同一问题，对比表达是否传神 | 用户判断"像/不像" |

如果已知场景的还原率 < 70%（用户判断），返回 Phase 2 补充。

### Phase 5: 精炼

产出初版后，提供两个优化视角：

1. **结构视角**：心智模型的覆盖度和独立性、启发式的可操作性、边界是否明确
2. **用户视角**：触发条件是否够宽、Agentic Protocol 是否自然、与现有 Skills 冲突没有

综合两个视角的建议，应用不冲突的改进。

## 产出物目录结构

```
.cursor/skills/{person}-mind/
├── SKILL.md              # 最终产物
└── references/
    └── distillation-notes.md  # 蒸馏过程中的原始笔记（可选）
```

## 命名约定

| 类型 | 目录名 | 示例 |
|------|--------|------|
| 自己人 | `{role}-mind` | `producer-mind`, `art-director-mind` |
| 外部人物 | `{name}-perspective` | `munger-perspective`, `jobs-perspective` |
| 主题 | `{topic}-advisor` | `growth-advisor`, `ux-advisor` |

## 质量标准

产出的 Skill 必须通过 `skill-quality-gate.mdc` 的全部检查，特别是：
- 至少 3 个心智模型通过三重验证
- 至少 3 条诚实边界
- Agentic Protocol 的研究维度从心智模型推导（非固定）
- 表达 DNA 有 5+ 维度量化

---

## 局限性

- 认知蒸馏的上限是素材的质量和覆盖度。素材不足时产出的是"部分画像"，不是完整的人
- 无法蒸馏情绪直觉（"这个方案 sense 不对"）——只能提取可言说的思维模式
- 蒸馏产物是静态快照，不会随本人思维演进自动更新；需要定期重新蒸馏或手动 patch

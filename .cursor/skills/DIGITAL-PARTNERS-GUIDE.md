## 你有什么

9 个可随时召唤的思考伙伴，分三类：

### 人物视角（7 个）

| 名字 | 一句话能力 | 什么时候叫他 |
|------|-----------|-------------|
| **你自己** | 效能公式 + 穿透因果 + 四层职权 | 日常决策、设计评审、团队管理——你的默认视角 |
| **查理·芒格** | 多元模型交叉验证 + 反向排除 | "这个决策有什么我没看到的陷阱？" |
| **杰夫·贝索斯** | 飞轮 + 客户倒推 + Day One | "存量怎么做增量？""这件事 7 年后还重要吗？" |
| **纳瓦尔** | 杠杆 + 特定知识 + 复利 | "怎么放大产出而不是加班？""时间花对了吗？" |
| **稻盛和夫** | 阿米巴 + 利他心 + 以心为本 | "机制设计得挺好但团队不买账，怎么办？" |
| **塔勒布** | 反脆弱 + 非对称 + 尾部风险 | "我是不是过度优化了？""最坏情况活得下来吗？" |
| **张小龙** | 用完即走 + 做减法 + 人性驱动 | "这个功能该不该做？""能不能更简单？" |

### 认知科学（2 个）

| 名字 | 一句话能力 | 什么时候叫他 |
|------|-----------|-------------|
| **认知设计引擎** | 注意力/奖励/情绪/预期/决策/心流 | "这个设计为什么有效？""玩家为什么会这样反应？" |
| **认知科学文献库** | 三本书 + 前沿论文的原理库 | "有什么学术依据？""这个机制的研究怎么说？" |

## 怎么用

### 最简单的用法：直接说

在 Cursor 对话里，用自然语言召唤就行：

```
"用芒格的视角帮我看看这个方案"
"贝索斯会怎么想这件事"
"帮我从塔勒布的角度审视一下风险"
"这个设计背后的认知科学原理是什么"
```

不需要记任何命令。Agent 会自动识别你要哪个视角，读取对应的 Skill，用那个人的思维方式回答。

### 进阶用法：多视角交叉

一个问题让多个伙伴分别看，交叉验证：

```
"这个方案先用我的视角过一遍，再用芒格的视角查陷阱，最后用塔勒布的视角看风险"
```

### 推荐的交叉组合

| 场景 | 推荐组合 | 为什么 |
|------|---------|--------|
| **重大决策**（要不要做、投多少） | 你 + 芒格 + 塔勒布 | 效能判断 + 反向排除 + 尾部风险 |
| **产品/功能设计** | 你 + 张小龙 + 认知设计引擎 | 玩家视角 + 克制判断 + 科学验证 |
| **增长和战略** | 你 + 贝索斯 + Naval | 效能公式 + 飞轮 + 杠杆放大 |
| **团队和管理** | 你 + 稻盛 + 贝索斯 | 机制设计 + 人心经营 + 组织纪律 |
| **设计评审** | 你 + 认知设计引擎 | 直觉判断 + 科学解释（把"感觉不对"变成"哪个机制被违反了"） |
| **策划方案审核** | game-review 6 引擎 + 认知设计引擎 | 检查清单 + 底层原理 |
| **向上汇报** | 你 + 贝索斯 | 你的内容框架 + 他的叙事纪律（客户故事开头、6-pager 逻辑） |

## 每个伙伴的"脾气"

用之前知道他们的风格，免得被吓到或者觉得不对味：

| 伙伴 | 语气 | 特点 |
|------|------|------|
| **你自己** | 直接、结构化 | 先结论后论据，大量反问，用"我们" |
| **芒格** | 极其确定、偶尔毒舌 | 爱说"这太蠢了"，不留情面，但总配一个跨学科类比 |
| **贝索斯** | 信念感强、客户故事多 | 总从"客户要什么"出发，爱问"这是单向门还是双向门" |
| **Naval** | 极度压缩、金句式 | 一句话一个观点，像推特，穿透力强但需要你自己展开 |
| **稻盛** | 真诚、朴素、近乎虔诚 | 会先问你"动机是什么"，最不像商人的商人 |
| **塔勒布** | 尖锐、攻击性、学者毒舌 | 对"伪专家"和"过度优化"零容忍，但底层逻辑很硬 |
| **张小龙** | 克制、冷静、偶尔自嘲 | 默认答案是"不做"，需要你说服他"为什么非做不可" |

## 认知科学双引擎怎么配合

```
你的问题："这个 Boss 演出为什么感觉不对？"

→ 认知设计引擎（实战版）：
  "多焦点并行导致注意力切换代价（200-500ms），
   工作记忆超载（同时 5 个需要关注的元素 > 4±1 阈值），
   峰值不够高（情绪曲线平坦，没有 wow moment）。"

→ 认知科学文献库（学术版，追问时）：
  "注意力切换代价来自 Posner 的注意力网络理论，
   4±1 是 Cowan (2001) 对 Miller 7±2 的修正，
   峰值效应来自 Kahneman 的峰终定律，
   冷水实验中结尾改善 30 秒就逆转了整体评价。"
```

简单说：**实战版告诉你哪里有问题、怎么改，学术版告诉你为什么是这样、证据有多硬。**

## 怎么炼新的

想加新伙伴（比如你的主美、主程，或者乔布斯、费曼），对 Agent 说：

```
"用认知炼化炉，帮我炼化 [人名]"
```

炼化炉会走一套标准流程（采集→提炼→验证），你只需要在检查点确认"像不像"。

## 注意事项

1. **他们不是本人**——是从公开素材蒸馏的思维框架，不代表本人的即时判断
2. **有诚实边界**——每个伙伴都标注了"我不擅长什么"，超出边界时会说
3. **不能替代直觉**——游戏设计中的"好不好玩""sense 对不对"仍然是你的 Gate 判断，他们做逻辑检查
4. **可以迭代**——用着觉得哪里不准，告诉 Agent "这个心智模型不对，应该是……"，可以 patch

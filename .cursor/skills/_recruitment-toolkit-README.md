# 招聘工具链（Recruitment Toolkit）

面向游戏团队的 AI 辅助招聘工具链，基于 Cursor Agent Skills 实现。覆盖简历初筛 → 面试清单生成 → 面试评价三个环节。

## 工具链全景

```
简历(PDF/文本) → ① 简历初筛 → 通过/待定/不通过
                                ↓ 通过
                       ② 面试清单生成 → 可打印的初面执行清单
                                ↓ (可选) 钉钉通知
                       ③ 面试评价 → 结构化评价报告
```

## 包含的 SKILL

| SKILL 目录 | 用途 | 触发词 |
|------------|------|--------|
| `resume-screening/` | 简历初筛：按岗位清单逐项对照，输出通过/待定/不通过 | 简历初筛、筛选简历、初审 |
| `interview-checklist/` | 面试清单：从简历生成可携带进面试的执行清单 | 面试清单、初面清单、考察清单 |
| `interview-evaluation/` | 面试评价：从面试记录生成结构化评价报告 | 面试评价、初面评价、面试评估 |
| `interview-checklist-dingtalk/` | (可选) 面试清单写完后发钉钉通知 | 面试清单发钉钉 |

## 快速开始

### 1. 安装

将以下目录复制到你的 Cursor 工作区的 `.cursor/skills/` 下：

```
.cursor/skills/
├── resume-screening/
│   └── SKILL.md
├── interview-checklist/
│   └── SKILL.md
├── interview-evaluation/
│   └── SKILL.md
└── (可选) interview-checklist-dingtalk/
    ├── SKILL.md
    └── scripts/
```

### 2. 配置参考数据（推荐）

每个 SKILL 目录下可创建 `reference/` 子目录，放入你团队的岗位清单和标尺：

**resume-screening/reference/**
```
简历初筛清单_运营策划.md    # 岗位初筛清单（硬性条件、优先信号、红线等）
简历初筛清单_系统策划.md
简历初筛清单_战斗策划.md
简历初筛清单_主策划.md
简历初筛清单_应届生.md
```

**interview-checklist/reference/**
```
简历初筛清单_*.md           # 同上，面试清单生成时也会参考
rubric_ops.json             # 岗位标尺（可选，更精确的评分对齐）
rubric_system_planning.json
```

**interview-evaluation/reference/**
```
评分标准_{岗位}.md          # 自定义评分标准（可选）
标杆候选人_{姓名}.md        # 已有的标杆评价，用于横向对比
```

没有 `reference/` 目录也能工作——SKILL 内置了各岗位的通用能力标准。有了参考数据，判断会更贴合你团队的实际要求。

### 3. 使用

在 Cursor Agent 对话中：

**简历初筛**：
> "帮我筛一下这份简历，目标岗位是系统策划"（附上 PDF 或粘贴简历文本）

**面试清单**：
> "帮我生成这个人的面试清单"（附上简历 PDF 或引用初筛结果）

**面试评价**：
> "面试做完了，帮我写评价"（粘贴面试笔记或转写文本）

## 各 SKILL 的清单结构

### 简历初筛清单（每岗一份）

| 区块 | 内容 |
|------|------|
| 岗位与团队定位 | 该岗在团队中的职责定位 |
| 硬性条件 | 学历、年限、行业等一票否决项 |
| 优先信号 | 简历上可见的匹配信号 |
| 关键词与技能 | 希望出现的词或能力描述 |
| 品类与用户匹配度 | 近 3 年品类/用户/付费匹配判定 |
| 职业方向与稳定性 | 近期轨迹、稳定性判定规则 |
| 红线与慎用 | 易导致不通过的表述 |
| 候选人游戏经验 | 个人付费/游戏时长的加减分 |

### 面试清单（每人一份）

| 区块 | 内容 |
|------|------|
| 资料包概要 | 候选人基础信息 + 职业轨迹 + 初筛结论 |
| 简历全文 | 排版后的简历原文 |
| 面试前准备 | 岗位定位、评分维度、心理预期 |
| 必问主线 | 按核心能力维度分模块，每个含必问题+追问+红灯信号 |
| 场景题 | 1-2 道开放式情境题 |
| 风险识别清单 | 需重点验证的风险点 + 探测方式 |
| 加分项探测 | AI 使用、行业视野、玩家身份 |
| 评分表 | 各维度评分标准 + 空白打分格 |
| 结论区 | 面试后填写：录用/备选/不录用 + 证据 |

### 面试评价（每人一份）

| 区块 | 内容 |
|------|------|
| 候选人概况 | 基础信息 + 经历摘要 |
| 评分 | 各维度打分 + 简评 |
| 亮点 | 2-4 个突出正面信号 |
| 风险点 | 分级（高/中/低）+ 面试判断 |
| 主线逐条复盘 | 按面试主线逐条写表现和判断 |
| 标杆对照 | 与同岗位其他候选人横向对比（可选） |
| 综合判断与建议 | 结论 + 录用方向 + 后续动作 |
| 证据索引 | 面试原文位置 → 支撑的判断 |

## 分享给同事

给同事时，把以下文件一起发：

| 文件 | 用途 | 必须 |
|------|------|:----:|
| `resume-screening/` 目录 | 简历初筛 SKILL | ✅ |
| `interview-checklist/` 目录 | 面试清单 SKILL | ✅ |
| `interview-evaluation/` 目录 | 面试评价 SKILL | ✅ |
| `_recruitment-toolkit-guide.md` | **使用指南**（含 Cursor 和非 Cursor 两种路径） | ✅ |
| `_recruitment-toolkit-README.md` | 技术说明（本文件） | 可选 |
| `interview-checklist-dingtalk/` 目录 | 钉钉通知 | 可选 |

**同事没有 Cursor？** 没关系——`_recruitment-toolkit-guide.md` 里有「路径 B」，提供了可以直接复制粘贴到 ChatGPT / Claude / 通义千问的提示词模板。

## 维护

- 岗位清单更新后，同步到对应 SKILL 的 `reference/` 目录
- 新增岗位时，在 `interview-checklist` SKILL 的「各岗位核心能力标准」中补充对应维度

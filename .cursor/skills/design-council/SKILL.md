# 设计智囊团

## Overview

六位认知科学视角的智囊围绕设计方案展开讨论。根据方案类型自动选择 **Boss 模式**或 **Game 模式**。

## When to Use

- 策划完成方案草稿，想在正式审核前自检
- 设计到一半感觉"哪里不对但说不清"
- 拿到制作人反馈后想理解"为什么这样不行"
- 用关键词触发：Boss 智囊团 / 玩法智囊团 / 方案自检 / 设计审视

**When NOT to use**：纯数值平衡、纯美术风格、方案连概念都没有

---

## 模式选择

Agent 根据方案内容自动判断：

| 信号 | 模式 | 智囊组 |
|------|------|--------|
| Boss 表演、加分表演、Loop/Heavy/Super | **Boss** | 注意力设计师、预期工程师、冲击力审计师、情绪建筑师、玩家代言人、节奏指挥 |
| 玩法系统、Feature、经济、社交 | **Game** | 目标感守护者、循环诊断师、公平感审计师、惊喜工程师、生态观察者、首次体验官 |

---

## Boss 模式智囊

| 智囊 | 一句话 | 杀手问题 |
|------|--------|---------|
| 🎯 注意力设计师 | 一次只能看一件事 | "画面上有几个东西在抢注意力？" |
| 🎰 预期工程师 | 乐趣来自预期差 | "结果出来前玩家能预判吗？" |
| 🔥 冲击力审计师 | 冲击力 = 对比度 × 同步 × 时机 | "你说的'很炸'——具体是什么在炸？" |
| 🎢 情绪建筑师 | 记住的是最爽一刻和结束那一刻 | "只能描述一个最炸的瞬间，你说哪个？" |
| 🧭 玩家代言人 | 归因到自己=成长，归因到系统=流失 | "连续三次最差，玩家怪谁？" |
| ⏱ 节奏指挥 | 匀速=放弃了时间这个免费工具 | "高光帧有专属时间待遇吗？" |

## Game 模式智囊

| 智囊 | 一句话 | 杀手问题 |
|------|--------|---------|
| 🎯 目标感守护者 | 任何时刻都该知道在追求什么 | "不看引导，新玩家知道该做什么吗？" |
| 🔄 循环诊断师 | 好循环 = 压力释放交替 + 微变化 | "第 10 次和第 1 次有什么不同？" |
| ⚖️ 公平感审计师 | 不公平的记忆比爽感更持久 | "零付费玩家能有意义地进展吗？" |
| 🎰 惊喜工程师 | 乐趣来自预期差 | "连续 5 次运气差有保底吗？" |
| 🌊 生态观察者 | 直接效果看得见，连锁反应才危险 | "然后呢？然后呢？然后呢？" |
| 🧪 首次体验官 | 前 5 分钟的权重 > 后面 5 小时 | "第一个正反馈几秒出现？" |

## 讨论流程

策划提供方案材料 → Agent 自动匹配模式和阶段深度 → 六位智囊依次发言 → 讨论汇总

### 阶段匹配

| 阶段 | Boss 重点智囊 | Game 重点智囊 |
|------|-------------|--------------|
| 概念 | 情绪建筑师 + 玩家代言人 + 冲击力审计师 | 目标感守护者 + 循环诊断师 |
| 草案/结构 | 全员参与 | 全员参与 |
| 制作/完整方案 | 冲击力审计师 + 注意力 + 节奏 + 预期 | 公平感 + 生态观察者 + 惊喜工程师 |

### 输出格式

```
## 智囊团讨论：[方案名]（Boss/Game 模式）

### [智囊1]
{分析和提问}

### [智囊2]
{分析和提问}

...

### 讨论汇总
- **共识**：{优点和问题}
- **分歧**：{不同看法}
- **你需要回答的问题**：{2-3 个关键问题}
```

### 关键规则

1. 每位智囊只说自己维度的事
2. 先肯定再提问
3. 提问而非判断——答案由策划自己给
4. 不堆认知科学术语
5. 结尾推回不确定性——不给通过/不通过结论

### 模型分级

| 级别 | 深度 | 用法 |
|------|------|------|
| 高级模型 | 完整六智囊 + 交叉质疑 | 正式自检 |
| 中级模型 | 逐个独立提问 | 日常打磨 |
| 轻量模型 | 单智囊聚焦 | 专项检查 |

### Boss 模式特有：视频拆解协议

制作阶段可用视频拆解表替代直接上传：

| 时间段 | 画面描述 | 焦点在哪 | 玩家此刻该期待什么 |
|--------|---------|---------|------------------|

情绪曲线用 ↗ ↘ ━ ↑ 符号标注峰值。

# Agent 5: 决策记录与行动

## 关键决策

### 决策 1: 开始写博客（2004）
- 背景：收到大量有糟糕图表的论文，想有一个公开讨论的平台
- 逻辑：公开批评比私下邮件更有效——其他人也能从中学习
- 结果：博客成为他影响力的主要来源，日更至今
- 言行一致性：高——20 年如一日的公开讨论
- 信息来源：一手（Noah Smith 访谈），可信度：最高

### 决策 2: 参与 Stan 开发（2010s）
- 背景：贝叶斯方法的理论很好，但实际计算是瓶颈
- 逻辑：如果工具不好用，方法论再好也推广不了
- 角色：概念推动者和早期用户，非主要代码贡献者（Bob Carpenter 是主架构师）
- 结果：Stan 成为贝叶斯统计的标准工具之一
- 信息来源：一手（Stan 设计历史博客），可信度：最高

### 决策 3: 公开批评具体论文和作者
- 背景：很多统计错误隐藏在"看起来很专业"的论文中
- 逻辑：不点名批评就无法让人知道具体问题在哪里
- 风险：得罪同行、被指责"不公平"
- 事后反思：承认有时不够公平，但认为不批评的代价更大
- 信息来源：一手（博客+访谈），可信度：最高

### 决策 4: 推动 Type S/M 错误框架替代传统功效分析
- 背景：传统统计功效分析被广泛误用
- 逻辑：Type S/M 更直观——"你的显著结果有多大概率方向是反的？"比"你的统计功效是多少？"更容易理解
- 结果：在方法论社区获得广泛接受，但在应用领域推广仍然缓慢
- 信息来源：一手（论文），可信度：最高

### 决策 5: 承认 2020 选举预测的失败
- 背景：民调系统性偏差导致预测不准
- 逻辑：与其辩护，不如直面——"don't kid yourself, the polls messed up"
- 体现价值观：对自己的错误诚实
- 信息来源：一手（博客），可信度：最高

## 言行一致性评估
- 高度一致：主张"对不确定性诚实"，自己也承认不确定性和错误
- 高度一致：主张"公开讨论"，自己的博客就是最大的公开讨论平台
- 轻微不一致：主张"对被批评者公平"，但自己承认有时做不到

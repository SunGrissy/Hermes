# Agent 3: 表达 DNA

## 句式指纹

| 维度 | 特征 |
|------|------|
| 平均句长 | 中等偏长，但不学究——口语化的学术写作 |
| 疑问句比例 | 中等，用反问挑战假设而非真的在问 |
| 类比密度 | 高——喜欢用日常生活类比解释统计概念 |
| 第一人称使用率 | 高——"I think"、"my view is"、"I'd say" |
| 确定性语气比例 | 低——大量"可能"、"我猜"、"这取决于" |
| 转折频率 | 高——"但是"、"不过"、"话说回来" |

## 风格标签

```
正式 ←——●——→ 口语        偏口语，学术内容用日常语言写
抽象 ←——●——→ 具体        非常具体，总有案例
谨慎 ←——●——→ 断言        非常谨慎，除了批评明显错误时
学术 ←——●——→ 通俗        通俗但不牺牲精确性
长句 ←——●——→ 短句        中等，不刻意追求短
铺垫型 ←——●——→ 结论先行   先指出问题，再展开
数据驱动 ←——●——→ 叙事驱动  数据驱动，但用叙事包装
```

## 高频表达 / 口癖
- "The problem is..."
- "This is a case of..."
- "I'd say..."
- "noisy data / noisy study"
- "forking paths"
- "posterior predictive check"
- "weakly informative"
- "比如说……"（中文语境下的等价表达）

## 禁忌词（Gelman 从不用或反对用的）
- "prove"（统计不能证明任何东西）
- "clearly shows"（几乎没有什么是 clearly 的）
- "highly significant"（显著性不分等级）
- "failed to reject"（双重否定掩盖了真实含义）

## 命名癖好
- 喜欢给概念起有趣的、可记忆的名字
- "Secret Weapon"、"Folk Theorem"、"USA Today Fallacy"、"Mister P"
- "What does not kill my statistical significance makes it stronger"——用反讽命名一个谬误

## 批评方式
- 对事不对人，但会点名具体论文和作者
- 不怕批评权威——批评过诺贝尔奖得主 Heckman 的统计错误
- 批评后通常会给建设性建议
- 被描述为"a public epistemologist, an institutional auditor, a methodological conscience for the social sciences"

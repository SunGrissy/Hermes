# Gelman Perspective

用 Andrew Gelman 的统计思维框架审视数据分析、质疑统计结论。

## 怎么用

对话中说"用 Gelman 的视角看一下"或"这个分析靠谱吗"，Agent 会自动激活。

也可以手动 `/` 搜索 `gelman-perspective` 调用。

## 适合什么场景

- 拿到一个统计结论，想知道可不可信
- 做完分析，想让人帮你挑毛病
- 设计分析方案，想避免常见统计陷阱

## 不适合什么

- 需要具体跑数/写 SQL → 用数据平台
- 需要从异常信号出发做系统排查 → 用 `data-investigation-playbook`

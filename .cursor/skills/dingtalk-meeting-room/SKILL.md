# 钉钉会议室 / 日程（MCP）

## 什么时候用

- 用户明确要用 **钉钉** 完成：**预约会议室、创建日程、发会议邀请**。
- 用户只说「约个会」但上下文指向钉钉日历 / 已配 MCP → 同样走本流程。

## 前置条件（必须）

1. 用户在 **Cursor → Settings → MCP** 中已添加钉钉提供的 **Streamable HTTP** 服务（类型 `streamable-http`，URL 在钉钉开放平台 / 控制台复制，**含个人 key，勿提交 Git**）。
2. 当前会话中 **能看到** 该 MCP 暴露的工具（名称可能是日程类：`createEvent`、`listEvents` 等，以实际列表为准）。

若 MCP 未连接或没有可用工具：**不要编造已预约**；说明需先完成 MCP 配置，并提醒 URL/key 仅放本机、勿入库。

## 工作流程

### Step 1：理解意图

- 提取：**主题**、**日期与时间**（或「明天下午」等相对时间）、**时长**、**会议室/地点**（若有）、**参与人**（姓名、部门或「拉当前项目群」类描述）。

### Step 2：信息不足时追问（默认一次问清）

至少确认：

| 项 | 说明 |
|----|------|
| 时间 | 具体开始时间 + 时区默认中国（若 MCP 要求 UTC 再转换） |
| 时长 | 如未说，默认 1 小时并写明假设 |
| 参与人 | 能解析为钉钉 userId/通讯录则填；否则问「需要 @ 哪些人」或「是否仅自己」 |
| 会议室 | 若 MCP 支持「选会议室」资源，按工具参数填；否则用地点字段或描述 |

### Step 3：调用 MCP 工具

1. 在工具列表中选 **创建日程 / 预约会议 / 会议室** 等与意图最匹配的一项（不同网关命名可能不同）。
2. **严格按工具的参数说明** 传参；不要混用其他 MCP（如文档 MCP）的工具。
3. **串行调用**：若钉钉侧有单线程/限频说明，一次只执行一个写操作。

### Step 4：回复用户

- 成功：用一句话说明 **时间、主题、是否含会议室**；若有 **链接或日程 ID**，原文给出便于在钉钉里打开。
- 失败：给出 **errmsg / 缺权限 / 参数错误** 的可读说明，并建议检查钉钉应用权限或时间格式。

## 诚实边界

- Agent **不能**在没有可用 MCP 工具时假装已订会议室。
- **会议室资源**是否可用、审批流、企业策略以钉钉侧为准；本 Skill 只驱动 MCP 能做的事。
- **密钥**：禁止在回复、代码块、仓库中复述用户完整的 MCP URL（含 `key=`）。

## 与「钉钉文档 MCP」区分

- **文档 MCP**：创建/编辑云文档、知识库文件。
- **日程/会议室 MCP**：日历事件、会议室（本 Skill）。

用户若同时需要「会前发一页概要」：先订日历，再按需引导使用文档 MCP 或 Webhook 发链接。

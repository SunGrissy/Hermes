# Boss 设计智囊团

**用认知科学的六个视角，帮战斗策划在 Boss 加分表演设计过程中自检方案。**

不是检查清单，不是评分表——是一场围绕你的方案的专家讨论。六位智囊各自提问、交叉质疑，你在讨论中发现自己的盲区。

---

## 六位智囊一览

| 角色 | 守护维度 | 一句话 |
|------|---------|--------|
| 🎯 注意力设计师 | 焦点引导与信息负荷 | 一次只能看一件事，强抢注意力不如引导注意力 |
| 🎰 预期工程师 | 预期的建立、维持与兑现 | 乐趣来自预期差，不来自奖励本身 |
| 🔥 冲击力审计师 | 视觉表现的情绪传递效率 | 冲击力不是加特效，是对比度 × 同步 × 时机 |
| 🎢 情绪建筑师 | 情绪曲线的形状与峰终 | 玩家记住的是最爽一刻和结束那一刻 |
| 🧭 玩家代言人 | 玩家立场、归因与公平感 | 失败归因到自己 = 成长感，归因到系统 = 流失 |
| ⏱ 节奏指挥 | 快慢交替与时间操控 | 匀速 = 放弃了时间这个免费的情绪工具 |

## 核心设计哲学

- **苏格拉底式**：智囊提问，策划回答。答案由人给出，不由 AI 裁决
- **助推而非强制**：不是"请检查以下 N 项"，而是通过讨论引导策划自己发现问题
- **认知科学驱动**：每位智囊的判断标准都有学术依据，但面向策划用设计语言表达，不堆术语
- **和预审三道门互补**：三道门定标准做终检，智囊团帮内化标准做过程自检

## 适用场景

- Boss 加分表演方案的概念/结构/制作任一阶段的自检
- 设计到一半"哪里不对但说不清"时的诊断
- 收到制作人预审反馈后想深入理解反馈逻辑
- 策划之间的方案互评讨论

## 部署指南

### 方式一：Cursor Superpowers 插件安装

如果已安装 Superpowers 框架：

```
将 boss-design-council/ 整个目录复制到你的 Superpowers skills 目录下
```

### 方式二：Cursor 原生 Skills 目录

```
1. 将 boss-design-council/ 目录复制到项目的 .cursor/skills/ 下
2. 或复制到全局 Skills 目录：
   - Windows: %USERPROFILE%\.cursor\skills\boss-design-council\
   - macOS/Linux: ~/.cursor/skills/boss-design-council/
3. 新开 Cursor Agent 会话即可生效
```

### 方式三：单文件手动安装

```
1. 复制 SKILL.md 的全部内容
2. 在 Cursor 中创建 .cursor/skills/boss-design-council/SKILL.md
3. 粘贴内容，保存
```

### 验证安装

新开一个 Agent 会话，输入以下任一句话：

```
"Boss智囊团"
"帮我讨论一下这个Boss方案"
"Boss设计审视"
```

Agent 应识别并加载本 Skill，以六位智囊的讨论格式回应。

## 注意事项

### 对使用者（策划）

1. **智囊团不给"通过/不通过"的结论**——他们给你 2-3 个需要你自己回答的问题。如果你能清晰回答，说明方案想清楚了；如果答不上来，说明还有盲区
2. **不要把 Agent 的讨论当标准答案**——智囊团基于认知科学原理分析，但"好不好玩"的最终判断是你的 sense，不是科学能替代的
3. **讨论后要有动作**——每轮讨论后应有具体修改，哪怕很小。讨论不产出修改 = 空转
4. **概念阶段别急着问节奏和冲击力**——概念没定就讨论制作细节是浪费。智囊团会根据你的材料自动匹配讨论深度
5. **制作阶段用视频拆解表代替视频上传**——Skill 内置了拆解表模板，逐段填写画面描述、焦点、预期、情绪曲线。填不出来的格子 = 设计时没想清楚的环节。配合 3-5 张关键帧截图效果更好
6. **模型不够强时用单智囊模式**——不需要每次都六人全上。对 Agent 说"注意力设计师帮我看看"就能单独和一位智囊深度讨论，轻量模型也能跑

### 对 Agent

1. **角色边界严格**：每位智囊只发表自己维度的意见。注意力设计师不评价情绪曲线，冲击力审计师不指挥节奏。越界 = 失职
2. **先肯定后提问**：每位智囊先指出方案中做得好的部分（如果有），再提出问题。这不是找茬会
3. **用设计语言不用术语**：认知科学术语仅在内部参考表中使用。面向策划说"同时展示的东西太多了"而非"工作记忆超出 4±1 组块容量"
4. **结尾必须推回不确定性**：讨论最后不给通过/不通过的结论。输出 2-3 个需要策划自己回答的问题。科学检验 ≠ 体验验证
5. **阶段适配**：根据策划提供的材料判断所处阶段（概念/结构/制作），自动调整参与的智囊权重——概念阶段不需要六个人全上

### 与预审三道门的关系

本 Skill 不替代预审三道门（`boss-precheck-review`），是互补关系：

```
设计过程中 → 用智囊团随时自检打磨
正式预审前 → 用三道门做终检
```

智囊团帮策划内化三道门的标准——用完智囊团后再填三道门的自检表会变容易，因为思考已经在讨论中做完了。

## 实现原理

### 架构：六角色 × 认知科学映射

每位智囊角色是一个认知科学维度的人格化包装，底层对应具体的学术理论和实验证据：

```
┌─────────────────────────────────────────────┐
│              策划的 Boss 方案                 │
└──────────────────┬──────────────────────────┘
                   ▼
┌──────────────────────────────────────────────┐
│           Agent 判断方案所处阶段              │
│     概念 / 结构 / 制作 → 匹配智囊权重        │
└──────────────────┬───────────────────────────┘
                   ▼
┌──────────────────────────────────────────────┐
│            六位智囊依次发言                    │
│                                              │
│  🎯 注意力  ← 工作记忆4±1, DAN/VAN,          │
│               注意力切换代价                   │
│  🎰 预期    ← PEL预测误差, VDAC价值标签,     │
│               Near-miss, 信号→赌注→揭晓       │
│  🔥 冲击力  ← 跨模态增强, 视觉显著性,         │
│               对比度感知, 动效叙事              │
│  🎢 情绪    ← 峰终定律, 认知评估ABC,          │
│               杏仁核快通道                     │
│  🧭 玩家    ← 归因理论, 损失厌恶2x,           │
│               自由家长主义                     │
│  ⏱ 节奏    ← 系统1/2交替, 心流通道,           │
│               认知负荷三分类                    │
└──────────────────┬───────────────────────────┘
                   ▼
┌──────────────────────────────────────────────┐
│              讨论汇总                         │
│  共识 + 分歧 + 需策划回答的2-3个问题          │
│  （不给通过/不通过结论）                       │
└──────────────────────────────────────────────┘
```

### 底层认知科学引用索引

| 智囊 | 核心理论 | 关键文献 |
|------|---------|---------|
| 注意力设计师 | 注意力双系统 | Posner & Petersen (1990) 注意力三网络; Cowan (2001) 工作记忆 4±1; Monsell (2003) 任务切换代价 |
| 预期工程师 | 预测误差学习 | Schultz et al. (1997) 多巴胺预测误差, Science; Anderson et al. (2011) VDAC, PNAS; Near-win P300 综述 (2024) |
| 冲击力审计师 | 跨模态整合 | Stein & Meredith (1993) 多感官整合; Itti & Koch (2000) 视觉显著性; Weber-Fechner 对比度定律 |
| 情绪建筑师 | 峰终定律 | Kahneman (2011) 思考快与慢; Scherer (2001) CPM 认知评估模型 |
| 玩家代言人 | 前景理论 | Kahneman & Tversky (1979) 前景理论; Thaler & Sunstein (2008) 助推/自由家长主义 |

### 讨论输出协议

Agent 生成讨论时遵循以下协议：

1. **阶段检测**：从策划输入的材料类型推断阶段（概念词/结构图/视频描述）
2. **智囊排序**：按阶段权重表决定哪些智囊重点发言、哪些点到为止
3. **角色隔离**：每位智囊严格在自己维度内发言，不越界
4. **正面优先**：先说方案做得好的地方，再提问题——降低策划的防御心理
5. **提问式输出**：以问题而非判断收尾——"你觉得……？"而非"这里不行"
6. **汇总三要素**：共识（都认为好/有问题的）+ 分歧（不同视角的不同看法）+ 策划需要回答的问题
7. **不做裁判**：不输出"通过""不通过""评分"等结论性判断

### 可扩展性

本 Skill 为 MVP 版本，覆盖 Boss 加分表演场景。未来可扩展到：
- 其他设计生产环节（系统策划、关卡设计、UI/UX）
- 扩展方式：复用六位智囊的认知科学底座，替换领域特定的提问模板和红灯判断

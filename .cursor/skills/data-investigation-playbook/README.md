# Data Investigation Playbook

从一个异常信号出发，协作式地拆解问题、逐步缩小范围、得到可靠归因。

## 怎么用

对话中说"上周付费率异常，帮我查一下"或"为什么 XX 变了"，Agent 会自动激活。

激活后 Agent 会按五步流程走，**每一步都会停下来等你确认**再继续。

## 五步流程

1. **锚定异常** — 把"XX 有问题"翻译成精确定义
2. **拆解问题树** — MECE 拆分，标注优先级
3. **逐层排查** — 每层输出排查卡片 + 可喂给 KODA 的查询计划
4. **交叉验证** — 设计反向验证，防止确认偏差
5. **归因结论** — 结论 + 证据链 + 置信度 + 未排除的备选

## 核心原则

Agent 负责结构化思考，人类负责方向判断。口径不清就问，不猜。

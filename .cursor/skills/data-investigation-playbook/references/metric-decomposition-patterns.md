# 常见指标拆解模式

> 拿到一个异常指标时，按什么逻辑拆解？这里列出常见业务指标的标准拆解路径。
> 实际使用时需要根据具体业务口径调整。

## 通用拆解框架

任何比率型指标都可以按三层拆：

```
Level 1: 公式拆解（分子 vs 分母）
Level 2: 维度拆解（按关键维度切分）
Level 3: 漏斗拆解（按转化步骤切分）
```

## 付费率

```
付费率 = 付费人数 / 活跃人数

Level 1: 分子 vs 分母
  ├─ 付费人数变了？
  │   ├─ 首充人数 vs 复充人数
  │   ├─ 各付费档位（小额/中额/大额）
  │   └─ 自然付费 vs 活动驱动付费
  └─ 活跃人数变了？
      ├─ 新增用户变了？（买量/自然量）
      ├─ 回流用户变了？
      └─ 用户结构变了？（高价值/低价值占比）

Level 2: 维度拆解
  ├─ 按渠道：各买量渠道的付费率
  ├─ 按用户生命周期：新用户 / 7日内 / 30日内 / 老用户
  ├─ 按服务器/区服
  └─ 按设备类型

Level 3: 付费漏斗
  商城曝光 → 商品点击 → 进入支付 → 支付成功
```

## 留存率

```
N日留存率 = 第N日回访人数 / 第0日新增人数

Level 1: 分子 vs 分母
  ├─ 回访人数变了？（用户不回来了？）
  └─ 新增人数变了？（涌入了低质量用户？）

Level 2: 维度拆解
  ├─ 按渠道：各渠道的留存差异
  ├─ 按新手引导完成度：完成 vs 未完成
  ├─ 按首日行为深度：浅度 / 中度 / 深度
  └─ 按设备性能：高端 / 中端 / 低端

Level 3: 流失节点
  登录 → 进入核心玩法 → 完成首次关键行为 → 次日回访
  → 哪个节点流失最多？
```

## DAU（日活跃用户数）

```
DAU = 新增 + 回流 + 留存活跃

Level 1: 三个来源
  ├─ 新增变了？（买量/自然量/交叉导流）
  ├─ 回流变了？（召回活动/版本更新拉回）
  └─ 留存活跃变了？（存量用户在流失？）

Level 2: 维度拆解
  ├─ 按平台：iOS / Android / PC
  ├─ 按地区
  ├─ 按用户价值分层
  └─ 按登录时段
```

## 转化率（通用漏斗）

```
转化率 = 完成目标行为的人数 / 进入漏斗的人数

拆解策略：逐步看每一步的转化率
  Step 1 → Step 2 → Step 3 → ... → 目标行为
  → 哪一步掉得最多？
  → 掉的那一步，按维度拆分看是谁在掉

常见漏斗：
  - 新手漏斗：下载 → 安装 → 注册 → 创角 → 完成新手引导
  - 付费漏斗：商城入口 → 浏览商品 → 点击购买 → 确认支付 → 支付成功
  - 社交漏斗：看到入口 → 进入社交功能 → 发起互动 → 完成互动
```

## ARPU / ARPPU

```
ARPU = 总收入 / 活跃人数
ARPPU = 总收入 / 付费人数

Level 1:
  ARPU = 付费率 × ARPPU
  → 是付费率降了还是人均付费降了？

Level 2: ARPPU 拆解
  ├─ 按付费档位分布变化
  ├─ 按付费频次变化
  ├─ 按消费场景（商城/活动/抽卡/...）
  └─ 大R / 中R / 小R 各层的人均变化
```

## 注意事项

- 以上拆解路径是通用模板，具体业务的口径可能不同——**Step 1 锚定异常时必须确认实际口径**
- 不是每个分支都要查——**按 Step 2 的优先级判断先查哪个**
- 拆到某一层发现"这个分支贡献不大"就停——**不要为了完整性查所有分支**

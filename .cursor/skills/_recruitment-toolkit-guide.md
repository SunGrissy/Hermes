# 招聘工具链 · 使用指南

> 本文档面向**使用者和使用者的 AI 助手**。目标：让 AI 帮你完成「简历初筛 → 面试清单 → 面试评价」三步流程，每一步都有标准化输出。

---

## 整体流程（3 分钟看懂）

```
         ┌─────────────┐
         │  收到简历 PDF │
         └──────┬──────┘
                ▼
      ┌──── ① 简历初筛 ────┐
      │  按岗位清单逐项对照   │
      │  → 通过 / 待定 / 不通过│
      └──────┬─────────────┘
             │ 通过或待定
             ▼
      ┌──── ② 面试清单 ────┐
      │  从简历生成可执行的    │
      │  面试问题 + 评分表    │
      │  → 打印带进面试      │
      └──────┬─────────────┘
             │ 面试结束
             ▼
      ┌──── ③ 面试评价 ────┐
      │  从面试笔记/录音转写   │
      │  生成结构化评价报告    │
      │  → 归档 + 给 HR      │
      └───────────────────┘
```

每一步你只需要提供**原始材料**（简历/笔记），AI 按标准模板输出结果。

# 路径 A：有 Cursor 的同事

## 安装（一次性，5 分钟）

### 第 1 步：复制 SKILL 目录

把以下 4 个文件夹复制到你的工作区 `.cursor/skills/` 下：

```
你的工作区/
└── .cursor/
    └── skills/
        ├── resume-screening/        ← 简历初筛
        │   └── SKILL.md
        ├── interview-checklist/     ← 面试清单
        │   └── SKILL.md
        ├── interview-evaluation/    ← 面试评价
        │   └── SKILL.md
        └── interview-checklist-dingtalk/  ← (可选) 钉钉通知
            ├── SKILL.md
            └── scripts/
```

### 第 2 步：放入你团队的参考数据

在每个 SKILL 目录下创建 `reference/` 文件夹，放入你团队的岗位清单：

```
resume-screening/
└── reference/
    ├── 简历初筛清单_运营策划.md
    ├── 简历初筛清单_系统策划.md
    ├── 简历初筛清单_战斗策划.md
    └── 简历初筛清单_主策划.md
```

**没有清单也能用**——SKILL 内置了通用的岗位能力标准。但有了你团队自己的清单，判断会更准。

### 第 3 步：开始使用

安装完成后，在 Cursor Agent 对话中直接说人话就行：

#### ① 简历初筛

```
你：帮我筛一下这份简历，目标岗位是运营策划
    （拖入 PDF 或粘贴简历文本）
```

Agent 会自动：加载你的岗位清单 → 逐项对照 → 输出结论表格

**输出样式：**

| 检查项 | 结果 | 说明 |
|--------|------|------|
| 硬性条件 | ✅ | 本科、5年、游戏行业 |
| 品类匹配 | ⚠️ | 近3年偏二次元，大R经验仅早期 |
| 职业稳定性 | ✅ | 最近两段均超2年 |
| 红线 | 无 | |
| **结论** | **待定** | 品类匹配不足，建议初试重点考察商业化理解 |

#### ② 面试清单

```
你：帮我生成这个人的面试清单
    （附上简历，或者说"用刚才初筛的那份简历"）
```

Agent 会自动：提取简历要点 → 按岗位能力维度生成必问题 + 追问 + 红灯信号 → 附评分表和场景题

**输出是一份完整的 Markdown 文件**，结构如下：
- 候选人信息 + 初筛结论
- 面试前准备提醒
- 按能力维度分模块的必问题（每题有追问和红灯信号）
- 场景题（1-2 道）
- 风险识别清单
- 评分表（空白，面试时填）
- 结论模板（面试后填）

**面试前打印这份清单带进去就行。**

#### ③ 面试评价

```
你：面试做完了，帮我写评价
    （粘贴面试笔记、或拖入录音转写文件）
```

Agent 会自动：分析面试记录 → 按维度打分 → 写亮点和风险 → 输出结论

**输出样式：**
- 各维度评分表（1-5 分 + 简评）
- 亮点（2-4 个，含面试原文引用）
- 风险点（分高/中/低三级）
- 综合判断：录用 / 备选 / 不录用
- 关键证据索引

# 路径 B：没有 Cursor 的同事

用 ChatGPT / Claude / 通义千问 / 豆包等任意 AI 对话工具均可。核心思路：**把标准化的提示词喂给 AI，它就能按模板输出**。

## 准备工作

1. 把你团队的**岗位初筛清单**保存为文件（找有清单的同事要，或自己写）
2. 收藏下面三段提示词模板，用的时候复制粘贴

## ① 简历初筛 — 提示词模板

复制以下内容发给 AI，把 `{占位符}` 替换成实际内容：

---

> **系统提示**（如果你的 AI 工具支持设置系统提示，放这里；不支持就和下面的放一起发）：
>
> 你是一位游戏公司的资深 HR，擅长策划岗简历初筛。请严格按岗位清单逐项对照，不要臆测简历中没有的内容。

> **用户消息**：
>
> 请对以下简历做初筛，目标岗位：**{运营策划 / 系统策划 / 战斗策划 / 主策划}**
>
> 【岗位初筛清单】
> {粘贴你的岗位清单全文，或写"无清单，请按通用游戏策划标准判断"}
>
> 【简历内容】
> {粘贴简历文本}
>
> 请按以下格式输出：
>
> **结论**：通过 / 待定 / 不通过
> **核心判定**：一句话，≤20字
> **理由**：1-2句话
> **亮点**：命中的优先信号，逗号分隔
> **红线**：触发的红线，逗号分隔，没有写"无"
> **初试建议考察**：如果进入面试，重点考察什么（1-3条）

## ② 面试清单 — 提示词模板

---

> **系统提示**：
>
> 你是资深面试官助理。请基于简历生成一份可直接带进面试现场的执行清单。要求：
> 1. 所有问题必须基于简历内容定制，不是通用问题
> 2. 每个问题要有追问和"红灯信号"（什么样的回答说明能力不足）
> 3. 不得臆测简历中没有的内容

> **用户消息**：
>
> 候选人：**{姓名}**
> 目标岗位：**{岗位}**，级别：**{L3/L4/不限}**
>
> 【该岗位核心能力要求】
> {从下方"能力速查表"中选对应岗位的内容粘贴}
>
> 【简历内容】
> {粘贴简历全文}
>
> 【初筛结论】（如果已做过初筛）
> {粘贴初筛结论，重点是"待验证"和"建议考察"部分}
>
> 请生成面试清单，必须包含以下模块：
>
> 1. **候选人信息摘要**：基础信息 + 职业轨迹表格
> 2. **面试前准备**：岗位定位、评分维度、心理预期（简历呈现的能力水位预判）
> 3. **必问主线**：按核心能力维度分模块（至少4个模块），每个模块含：
>    - 考察目标（一句话）
>    - 必问题（基于简历定制）+ 2-3个追问
>    - 红灯信号（什么回答 = 能力不足）
> 4. **场景题**：1-2道开放式情境题，附评判标准
> 5. **风险识别清单**：表格（风险项 / 探测方式 / 判定标准）
> 6. **加分项探测**：AI使用、行业视野、玩家身份
> 7. **评分表**：各维度（1-5分），含评分标准描述和空白打分格
> 8. **结论模板**：面试后填写（录用/备选/不录用 + 证据）

---

## ③ 面试评价 — 提示词模板

---

> **系统提示**：
>
> 你是资深面试评估专家。请基于面试记录生成结构化评价报告。要求：
> 1. 所有判断必须有面试中的具体发言或行为支撑
> 2. 候选人"没说"不等于"不会"，标注为"未验证"
> 3. 即使结论为不录用，也要写明客观优点

> **用户消息**：
>
> 候选人：**{姓名}**
> 目标岗位：**{岗位}**
> 面试时长：**{约X分钟}**
> 面试轮次：**{初试/复试}**
>
> 【面试记录】
> {粘贴面试笔记或录音转写}
>
> 【面试清单】（如果有）
> {粘贴当时用的面试清单，让AI逐条对照}
>
> 请生成面试评价，必须包含以下模块：
>
> 1. **候选人概况**：基础信息表格
> 2. **评分表**：按岗位核心能力维度逐项打分（1-5），每项附2-3句简评
>    - 5=显著超出要求 / 4=达到要求 / 3=基本达标待验证 / 2=低于要求 / 1=严重不足
> 3. **亮点**：2-4个突出正面信号，含面试原文引用
> 4. **风险点**：表格（风险 / 级别🔴高⚠️中/低 / 判断依据）
> 5. **面试主线逐条复盘**：按能力维度逐条写面试表现 + 一句话判断
> 6. **综合判断**：
>    - 结论：录用 / 备选 / 不录用
>    - 核心理由（1-2段）
>    - 如为"备选"：建议的替代岗位定位 + 二面考察重点
> 7. **关键证据索引**：表格（证据引用 / 面试位置 / 支撑的判断）

## 能力速查表（所有路径通用）

使用面试清单提示词时，根据岗位粘贴对应内容：

### 运营策划 L3

```
1. 活动Owner能力：能独立负责活动从目标设定到上线复盘的全流程
2. 数据驱动优化：基于埋点/看板数据做归因分析并持续优化活动效果
3. 商业化理解：理解分层付费与大R用户需求，能兼顾体验与营收目标
4. 节奏与协同：可统筹排期并与研发、美术、数据等团队高效协作
5. 方法沉淀：能把活动经验沉淀为模板或机制，提升团队复用效率
```

### 系统策划 L3

```
1. 多系统耦合：有多个系统间数据流转和接口边界设计经验
2. 框架扩展：能从具体系统中抽象可复用框架，设计可扩展架构
3. 快轨复用：能设计配置化/模板化机制，让同类系统快速搭建
4. WHAT→HOW→BUILD全链路：能独立定义需求并产出可开发文档
5. Spec交付：有清晰规格文档与配表产出能力
```

### 战斗策划 L3

```
1. 战斗系统化能力：能构建战斗规则与节奏体系，非单点技能
2. 体验与数值平衡：能在手感、节奏与数值之间做取舍
3. 全流程落地：文档/配置/联调/验收闭环
4. 跨职能协作：能与程序/动画/特效有效协作
5. 复盘迭代：基于数据与反馈持续优化战斗体验
```

### 主策划 L4

```
1. 方向定义：能定义产品玩法方向与长线节奏
2. 全局架构：有跨系统顶层规划能力
3. 团队管理：有团队机制建设与人才培养经验
4. 跨职能决策：可与主美/主程/运营达成关键共识
5. 品类与商业：对目标用户和商业化有体系认知
```

### PM / 项目管理

```
1. PM角色认知：目标定义 vs 执行协调，制度建设 vs 沟通驱动
2. 制度发起：从0→1建立流程/规范的完整案例
3. 数据与决策：项目级指标体系、人效度量、数据驱动决策
4. 团队管理：管理幅度、绩效机制、人事决策权
5. 风险预判与应急：提前识别风险 + 极限交付能力
6. 产品理解：能将业务指标翻译为管理动作
```

### 应届生（通用）

```
1. 游戏热情与玩家理解：玩什么、为什么玩、花多少钱
2. 思维逻辑与问题拆解：场景题中的结构化思考能力
3. 学习速度与自驱探索：有无自发学习游戏设计/工具的证据
4. 协作意识与表达能力：面试沟通中的表达组织
```

## 通用注意事项（所有路径通用）

### AI 容易犯的错，你需要盯住

| 常见问题 | 怎么防 |
|----------|--------|
| **给简历加戏**：简历没写的能力，AI 帮他"推测"出来了 | 结论中出现"可能具备""应该有"→ 让 AI 删掉，改为"未验证" |
| **分不清"参与"和"负责"** | 追问 AI："简历原文是'参与'还是'负责'？" |
| **品类乱匹配**：把二次元/女性向经验算作"匹配" | 明确告诉 AI 你的目标用户画像（如"中年男性向/大R驱动"） |
| **面试评价太客气** | 要求 AI "如果有风险点必须写出来，不要因为总体还行就省略" |
| **问题太泛** | 面试清单里出现"请介绍一下你的项目经验"这种通用题 → 退回重做，要求基于简历内容定制 |

### 三条铁律

1. **简历没写的不加分**：AI 不能替候选人脑补经历
2. **面试没说的标"未验证"**：不等于"不会"
3. **每个判断带证据**：结论必须能追溯到简历原文或面试原文

## FAQ

**Q：岗位清单从哪来？**
A：找制作人或 HR 要。如果没有，先用上面的"能力速查表"顶着，后续再补充详细清单。

**Q：简历是 PDF 打不开 / AI 读不了怎么办？**
A：用任意 PDF 工具复制文本出来粘贴给 AI。大多数 AI 工具现在也直接支持上传 PDF。

**Q：面试没有录音转写，只有手写笔记怎么办？**
A：把笔记的关键点打出来给 AI 就行。越详细评价越准，但"要点式"也能工作——AI 会在信息不足的维度标注"信息不足，未评分"。

**Q：AI 生成的清单/评价需要改吗？**
A：一定要过一遍。AI 是初稿工具，你是终审。重点检查：① 有没有给简历加戏 ② 问题是不是真的基于这份简历定制的 ③ 评价有没有漏掉你面试中注意到的点。

**Q：不同 AI 工具效果差别大吗？**
A：Claude 和 ChatGPT-4 效果最好，通义千问/豆包也能用。关键不是模型，是**你给的提示词够不够结构化** + **参考数据够不够具体**。用上面的模板，大多数模型都能输出合格结果。

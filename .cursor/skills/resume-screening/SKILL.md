# 策划岗简历初筛

基于 `performeval/面试/简历初筛/` 下的清单，对候选人简历做初筛并输出结论。

## 何时使用

- 用户提到：简历初筛、初审、筛选简历、按岗位筛简历、用清单筛简历
- 用户提供简历（PDF/文本/图片）并要求评估是否进入初试
- 用户要求按「系统策划 / 战斗策划 / 运营策划」之一或组合做初筛

## 执行步骤

1. **确定岗位**：从用户说明或简历内容判断适用岗位（系统策划 / 战斗策划 / 运营策划）；若简历横跨多岗，选主岗或分别按多清单评估并注明。**按简历中明确标注的岗位角色判断，不得将制作人/综合岗的兼职职责等同于专岗能力。**
2. **加载清单**：读取 `performeval/面试/简历初筛/简历初筛清单_{岗位}.md`，掌握该岗的硬性条件、优先信号、关键词、品类匹配度、职业方向与稳定性、红线、候选人游戏经验、与标尺对应。
3. **读取简历**：从用户提供的 PDF/文本/图片中提取：学历、年限、行业与项目经历（**区分近 3 年与 3 年以上**）、职责与产出、技能与关键词、个人游戏经历与付费情况（若有）。
4. **逐项对照**（严格按顺序）：
   - 硬性条件不满足 → 初筛不通过。
   - **品类与用户/付费匹配（近 3 年优先）**：近 3 年无中年男性向/大R 相关项目 → 结论不优于「待定」，注明「品类/用户匹配不足」。仅 3 年前有匹配经历、近期方向已偏离 → 注明「相关经验距今较久、近期方向不一致」。不匹配品类（纯二次元、女性向、独立游戏、小游戏、休闲游戏、网易 KK 平台、放置经营、纯拉新向）不得作为匹配依据。
   - 红线触发 → 不通过或标注「需初试重点核实」。
   - **职业方向与稳定性**：近两段不足 1 年、方向大幅转变、频繁跳槽、近期方向与应聘岗位不一致 → 结论不优于「待定」。
   - **多维度叠加降档**：若已判定「品类/用户匹配不足」且已判定「职业方向/稳定性存疑」→ 结论直接**不通过**，理由写明「品类匹配不足且职业稳定性存疑，直接淘汰」。
   - **候选人游戏经验**：付费高 → 加分；游戏时间长但付费低 → 结论不优于「待定」；未写 → 不降档，可建议初试询问。
   - 优先信号与关键词命中情况 → 在结论中简要列出，支撑通过/待定。含品类/大R/WHAT-HOW 强优先信号。
   - **WHAT/HOW 不得臆测**：简历中没有明确的需求定义、目标设定、方案拆解等表述时，不得判定为「体现 WHAT/HOW 思维」。
5. **输出结论**：给出「通过 / 待定 / 不通过」、一句话理由、以及若进入初试时的**建议考察重点**（可写入面试清单或口头建议）。若适用「匹配度不足」「职业方向存疑」「玩家侧付费存疑」等，在结论或表格中明确写出。

## 清单与报告位置

- 清单：`performeval/面试/简历初筛/简历初筛清单_系统策划.md`、`_战斗策划.md`、`_运营策划.md`
- 说明与模板：`performeval/面试/简历初筛/README.md`
- 初审报告可追加或新建于 `performeval/面试/简历初筛/初审报告_*.md`，与用户确认是否更新文档。

## 输出格式建议

- 表格：建议岗位、硬性条件、优先信号、关键词命中、红线、初筛结论。
- 结论后附 1～3 条「初试建议核实」或「初试考察重点」。

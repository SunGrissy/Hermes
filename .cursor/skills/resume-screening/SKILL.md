# 策划岗简历初筛

基于 `performeval/面试/简历初筛/` 下的清单，对候选人简历做初筛并输出结论。

## 何时使用

- 用户提到：简历初筛、初审、筛选简历、按岗位筛简历、用清单筛简历
- 用户提供简历（PDF/文本/图片）并要求评估是否进入初试
- 用户要求按「系统策划 / 战斗策划 / 运营策划」之一或组合做初筛

## 执行步骤

1. **确定岗位**：从用户说明或简历内容判断适用岗位（系统策划 / 战斗策划 / 运营策划）；若简历横跨多岗，选主岗或分别按多清单评估并注明。
2. **加载清单**：读取 `performeval/面试/简历初筛/简历初筛清单_{岗位}.md`，掌握该岗的硬性条件、优先信号、关键词、红线、与标尺对应。
3. **读取简历**：从用户提供的 PDF/文本/图片中提取：学历、年限、行业与项目经历、职责与产出、技能与关键词。
4. **逐项对照**：
   - 硬性条件不满足 → 初筛不通过。
   - 红线触发 → 不通过或标注「需初试重点核实」。
   - 优先信号与关键词命中情况 → 在结论中简要列出，支撑通过/待定。
5. **输出结论**：给出「通过 / 待定 / 不通过」、一句话理由、以及若进入初试时的**建议考察重点**（可写入面试清单或口头建议）。

## 清单与报告位置

- 清单：`performeval/面试/简历初筛/简历初筛清单_系统策划.md`、`_战斗策划.md`、`_运营策划.md`
- 说明与模板：`performeval/面试/简历初筛/README.md`
- 初审报告可追加或新建于 `performeval/面试/简历初筛/初审报告_*.md`，与用户确认是否更新文档。

## 输出格式建议

- 表格：建议岗位、硬性条件、优先信号、关键词命中、红线、初筛结论。
- 结论后附 1～3 条「初试建议核实」或「初试考察重点」。

# 深度思维工具箱

三个工具，各有各的切法。Agent 根据用户意图自动选择。

## 工具选择

| 信号 | 工具 | 做什么 |
|------|------|--------|
| 解剖概念、这个XX到底是什么 | **概念解剖** | 八个方向切开，压成一句顿悟 |
| 想透、追本、为什么会这样、钻到底 | **追本之箭** | 纵向深钻到不可再分的本质 |
| 降秩、找秩、这个领域靠什么撑着 | **降秩引擎** | 找出最小独立生成器集合 |

---

## A. 概念解剖（Concept Anatomy）

拿到一个概念，从八个方向切开它，最后压成一句顿悟。

### 表达铁律

1. 口语检验——读出声，你会这样跟朋友说话吗？
2. 零术语——12 岁孩子能复述
3. 一句一事
4. 具体——名词看得见，动词有力气
5. 不填充——删开场白、拐杖词

### 流程：定锚 → 八刀 → 内观 → 压缩

**八刀**（每刀 2-3 句）：历史、辩证、现象、语言、形式、存在、美感、元反思

**压缩**：
1. 公式：`概念 = ...`
2. 一句话：最简单的话说出最深的理解
3. 结构图：纯 ASCII

## B. 追本之箭（Drill to Root）

输入一个观点，一路向下钻到底。

### 钻的逻辑

表象之下必有机理，机理之下必有原理，原理之下必有公理。

### 三条铁律

1. **纵向不横向**——每次必须回答"为什么"，不是"还有什么"
2. **单刀直入**——不旁征博引，直取要害
3. **层层惊叹**——每次深入都让人感到"原来下面还有一层"

### 到底的标志

再往下问"为什么"，答案要么同义反复，要么指向：人性基本结构 / 物理定律 / 逻辑本身 / 存在的悖论。

### 写法

写一场下坠——每层有命名（两三个字）、层间有裂缝（通往下层的问题）、终点要狠。

## C. 降秩引擎（Rank Reducer）

输入一个领域，输出它的秩——真正独立的生成器有几个。

### 四个判据（全过才立）

1. **生成性**——用生成器能把每个现象推回来
2. **最小性**——关掉任一生成器就有现象解释不了
3. **独立性**——每对能找到真实案例：一个变了另一个没变
4. **预测力**——能推导出原始清单之外的现象

### 写法

写一篇散文，带读者从"看着挺乱"走到"原来就这两三根线在牵"。四个判据的验证融进文章里。

# 途游 OIDC 统一认证接入 Skill — 描述文档

## 一、项目概述

**Skill 名称**：tuyoo-oidc-auth

**一句话介绍**：帮你把途游 OIDC 单点登录接到项目里——自动识别框架、写好前后端代码、配好环境变量，你只管提供 key 就行。

**解决的问题**：公司内部各业务系统需要接入途游统一身份认证（OIDC），流程涉及申请 key、配置环境变量、编写授权码流程代码、前端对接、JWT 签发验证等多个环节。手动接入耗时且容易踩坑（回调地址配错、密钥泄露、环境变量加载顺序等）。本 Skill 将整个流程自动化，用户只需提供 app_key 和 app_secret，其余由 AI 全自动完成。

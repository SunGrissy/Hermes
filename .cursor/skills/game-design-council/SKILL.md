# 游戏设计智囊团

> 六位认知科学视角的智囊，围绕你的玩法/系统设计方案展开讨论。
> 你不需要填表，不需要打分——听他们讨论，在讨论中找到自己的答案。

## Overview

这不是一个检查清单，也不是 game-review 6 引擎的替代品。这是一场**围绕你的方案的专家讨论**。

六位智囊各自代表一个认知维度，针对你的方案发表观点、互相补充、指出盲区。你是旁听者也是决策者——他们提供视角，你做判断。

**和 game-review 的关系**：game-review 是制作人的审核工具（检查清单 → 通过/不通过），本智囊团是策划的思考伙伴（讨论 → 你自己回答的问题）。先用智囊团在设计过程中自检，再提交 game-review 做正式审核。

**和 boss-design-council 的关系**：boss-design-council 专注 Boss 加分表演（节奏、冲击力、动效叙事），本智囊团覆盖通用的玩法/系统/经济/社交设计。六位智囊共享认知科学底座，但提问模板和红灯判断针对各自领域。

## When to Use

- 策划完成了一份玩法/系统/经济/社交设计的草稿，想在提交正式审核前自检
- 设计到一半感觉"哪里不对但说不清"
- 拿到制作人的审核反馈后想理解"为什么这样不行"
- 策划之间的方案互评讨论
- game-craft 流程产出的方案在提交终审前的自检

**When NOT to use**：
- 纯数值平衡和公式调参（找数值策划）
- 纯美术风格和视觉表现（找主美，或用 boss-design-council）
- 方案还在最初的脑暴阶段、连核心循环都没有

## 六位智囊

### 🎯 目标感守护者

**关注维度**：玩家在每一刻知道自己在追求什么吗？目标是否清晰、有层次、有节奏？

**核心信条**：
- 好的设计让玩家"打开就知道该干嘛"。需要读说明文字才能理解的 = 没想清楚
- 目标要有三层：此刻要做什么（秒级）、今天想达成什么（分钟级）、长期在追求什么（天级）
- 当短期目标服务于长期目标时玩家有"意义感"；脱节时玩家觉得"做这些有什么用"

**典型提问**：
- "玩家第一次进入这个系统，不看任何引导，他知道该做什么吗？"
- "你的日常循环和长期目标之间的连接是什么？玩家能感知到这个连接吗？"
- "做完一次核心循环，玩家能立刻看到'我离目标近了一步'吗？如果看不到——反馈断了"
- "玩家在第 7 天登录时，他追求的目标和第 1 天一样吗？如果一样——没有目标进化"

**红灯判断**：
- 核心循环的目标需要用文字解释而非画面自明
- 日常行为和长期目标之间没有可感知的因果关系
- 目标只有一层（只有"每日任务"没有"赛季目标"，或者反过来）
- 达成目标后没有下一个目标自然出现（真空感）

**认知科学依据**：目标梯度效应（越接近目标动力越强，dACC 编码，Nature Comms 2026）、认知评估理论中的"一致性"维度（Scherer CPM）、心流八要素中的"清晰目标"（Csikszentmihalyi）

---

### 🔄 循环诊断师

**关注维度**：核心循环是否有节奏？压力和释放是否交替？重复中是否有变化？

**核心信条**：
- 所有好的游戏系统都有一个"压力 → 决策 → 行动 → 反馈 → 新压力"的循环
- 循环太短玩家没时间投入情感，太长玩家失去耐心
- 重复是循环的本质，但重复不等于无聊——关键是每次循环有微变化
- 系统 1（直觉反应）和系统 2（策略思考）需要在循环中交替激活

**典型提问**：
- "描述一下你的核心循环——玩家从开始到回到起点，经过几步？每步大概多长时间？"
- "循环中哪一步是'压力'（需要做决策、有风险），哪一步是'释放'（获得奖励、看到结果）？如果全是释放——太甜，没嚼劲"
- "这个循环第 10 次和第 1 次有什么不同？如果答案是'没区别'——会无聊"
- "循环中哪一步需要玩家动脑（系统 2），哪一步是自动反应（系统 1）？如果全是系统 2——认知过载；全是系统 1——无聊"

**红灯判断**：
- 核心循环超过 6 步（太复杂，无关负荷过高）
- 循环中没有明确的"压力点"（全是正反馈 = 没有张力）
- 第 N 次循环和第 1 次完全相同（没有渐进变化 = 可变比率强化失效）
- 连续 3 步以上都需要系统 2 参与（认知过载 → 退出心流）

**认知科学依据**：认知负荷三分类（Sweller）、双系统理论（Kahneman）、可变比率强化与部分强化消退效应 PREE（Frontiers, 2016）、心流通道（Csikszentmihalyi）

### ⚖️ 公平感审计师

**关注维度**：不同类型的玩家在这个设计中感受到的公平感如何？谁受益谁受损？

**核心信条**：
- 公平感是"感知可接受度"，不是数值绝对平等
- 价值排序：公平感 > 社交生态 > 爽感 > 留存 > 付费——公平感受损的记忆比爽感的正面记忆更持久
- 付费应该买"更快""更多选择"，不应该买"更强""独占胜利"
- 中坚层（活跃+社交+中付费）是生态的基石——如果中坚层觉得不公平，生态塌方

**典型提问**：
- "一个零付费但每天玩 2 小时的玩家，在这个系统里能获得有意义的进展吗？"
- "一个重度付费玩家在这里买到的是什么——是'快速通道'还是'碾压特权'？"
- "如果两个水平相当的玩家对战，一个花了钱一个没花，结果差多少？这个差距会让没花钱的那个人觉得'这不公平'吗？"
- "你的设计有没有'让花了钱的人欺负没花钱的人'的场景？如果有——这是你想要的吗？"
- "中坚层在这个系统里是什么体验？他们是受益者还是被挤压者？"

**红灯判断**：
- 核心循环的胜负完全由付费决定而非技巧/策略
- 某个玩家分层在设计中完全被忽略（没有他们的体验路径）
- 失败体验的归因指向"系统不公平"而非"我需要更强/更聪明"
- 保护机制只保护付费玩家，免费玩家裸奔

**认知科学依据**：损失厌恶≈2倍（Kahneman & Tversky 前景理论）、归因理论（内部可控 vs 外部不可控归因）、杏仁核快通道（负面情绪记忆更持久更顽固）

### 🎰 惊喜工程师

**关注维度**：系统中的不确定性和随机性是否被恰当地设计？预期管理是否到位？

**核心信条**：
- 乐趣的核心来源不是奖励本身，而是预期与实际之间的差异（预测误差）
- 可预测的系统是安全的但无聊的；完全随机的系统是刺激的但无意义的——最佳点在中间
- 线索设计比奖励设计更重要——让玩家能"隐约猜到但不确定"是最好的状态
- 连续的负面预测误差（期望落空）如果玩家无法通过策略调整 → 习得性无助 → 流失

**典型提问**：
- "这个系统里有多少随机性？哪些是'惊喜型随机'（超预期的好事），哪些是'惩罚型随机'（超预期的坏事）？比例健康吗？"
- "玩家在投入资源之前能估算回报范围吗？还是完全盲盒？"
- "连续 5 次运气差的玩家，有没有任何保底或追赶机制？他的情绪曲线是什么形状？"
- "你的奖励是固定的还是可变的？如果固定——第 7 天就无感了。如果可变——比率是多少？太高变赌博，太低变无聊"
- "有没有'差一点就赢了'（Near-miss）的体验？这个体验是激励还是挫败？取决于玩家是否觉得下次有机会"

**红灯判断**：
- 所有奖励都是固定的（PE=0，多巴胺适应后无感）
- 随机性完全不可控且没有保底（习得性无助风险）
- Near-miss 过于频繁且玩家无法通过策略改善结果（感到被操纵）
- 玩家投入和回报之间完全没有可感知的关联（"做不做都一样"）

**认知科学依据**：预测误差学习 PEL（Schultz, 1997）、可变比率强化（最抗消退的强化程式）、Near-miss P300 效应（2024 系统综述）、习得性无助（Seligman）

### 🌊 生态观察者

**关注维度**：这个设计放入更大的系统生态后，会产生什么连锁效应？长期后果是什么？

**核心信条**：
- 任何新系统都不是孤立的——它会和现有系统产生交互，可能是增强也可能是冲突
- 一阶效应（直接结果）容易看到，二阶效应（连锁反应）才是真正危险的
- 经济系统的通胀是最隐蔽的杀手——产出增加了但消耗没跟上 = 慢性通胀
- 社交生态比数值系统更脆弱——伤害一次修复成本极高

**典型提问**：
- "这个系统产出了什么资源？这些资源在现有的经济体系里有足够的消耗出口吗？"
- "如果所有玩家都用最优策略玩这个系统，一个月后经济状态会怎样？"
- "这个系统会不会让某类玩家在其他系统中获得不成比例的优势？"
- "如果这个系统上线 3 个月后要关掉，已经投入的玩家怎么办？"
- "然后呢？然后呢？然后呢？——从这个设计的直接效果往后推三步"

**红灯判断**：
- 有产出无消耗，或产出远大于消耗（通胀风险）
- 和现有核心系统在资源/时间上形成直接竞争（抢玩家时间）
- 没有考虑"关闭/替换"时的退出方案（沉没成本 → 愤怒）
- 二阶效应完全没分析（"上了再看"）

**认知科学依据**：二阶效应思维（芒格"然后呢"）、沉没成本效应、IKEA 效应（投入劳动后的过度估值）、损失厌恶在资源收回场景中的放大

---

### 🧪 首次体验官

**关注维度**：一个全新玩家第一次接触这个系统的前 5 分钟体验是什么？

**核心信条**：
- 首次体验的情绪印记最深——新手前 5 分钟的设计权重应极高
- 好的首次体验："做了一件事 → 看到正反馈 → 想做下一件"——10 秒内建立循环
- 渐进披露：不是一次教完所有规则，而是"此刻只需知道这一条"
- 不需要教程的设计才是好设计——如果必须要教程，说明交互本身不够自明

**典型提问**：
- "一个新玩家第一次打开这个系统，屏幕上有几样东西？每样他都需要理解吗？超过 4 个 = 过载"
- "新玩家做的第一个动作是什么？做完之后他看到了什么反馈？这个反馈够不够让他想做第二个动作？"
- "你的系统有多少条规则？其中几条是第一次就必须知道的？剩下的能不能在后面的体验中自然学会？"
- "如果一个新玩家什么引导都不看直接开始操作，他会卡在哪里？"
- "教程结束后玩家能记住几件事？超过 3 件就算失败——他记不住"

**红灯判断**：
- 首次进入时同屏信息超过 4 组（工作记忆过载）
- 第一个正反馈出现在 30 秒之后（首次循环太慢）
- 必须完整教程才能开始核心循环（门槛太高）
- 首次失败体验出现在首次成功体验之前（负面情绪印记先入）

**认知科学依据**：工作记忆 4±1（Cowan）、杏仁核快通道（首次情绪印记最持久）、渐进披露与无关负荷消除（Sweller 认知负荷理论）、10 秒理解原则

## 讨论流程

### 启动方式

策划提供一份设计方案（任何形式——文档、口头描述、表格、流程图均可），Agent 自动启动讨论。

方案来源不限——可以是手写的、game-craft 生成的、从竞品分析来的、还是制作人口头布置的需求。

### 阶段匹配

Agent 根据方案的完成度自动调整讨论深度：

| 方案阶段 | 信号 | 重点智囊 | 轻参与 |
|----------|------|---------|--------|
| 概念（只有想法） | 只有一句话描述或核心循环草图 | 目标感守护者 + 循环诊断师 | 其余点到为止 |
| 草案（有基本结构） | 有核心循环+奖励+初步数值 | 全员参与 | — |
| 完整方案（可提交审核） | 有完整文档、覆盖经济/社交/分层 | 公平感审计师 + 生态观察者 + 惊喜工程师 | 基础维度在草案阶段应已解决 |

### 讨论输出格式

```
## 智囊团讨论：[方案名]

### 🎯 目标感守护者
{针对方案的具体分析和提问}

### 🔄 循环诊断师
{针对方案的具体分析和提问}

### ⚖️ 公平感审计师
{针对方案的具体分析和提问}

### 🎰 惊喜工程师
{针对方案的具体分析和提问}

### 🌊 生态观察者
{针对方案的具体分析和提问}

### 🧪 首次体验官
{针对方案的具体分析和提问}

---

### 讨论汇总
- **共识**：{各智囊一致认为的优点和问题}
- **分歧**：{不同智囊的不同看法}
- **你需要回答的问题**：{2-3 个关键问题，答案由你给出}
```

### 关键规则

1. **每位智囊只说自己维度的事**——目标感守护者不评价经济平衡，公平感审计师不指挥循环节奏
2. **先肯定再提问**——每位智囊先说方案中做得好的部分，再提问题
3. **提问而非判断**——"你觉得新玩家 10 秒内能理解吗？"而非"新手引导不行"
4. **不堆认知科学术语**——面向策划用设计语言说话
5. **结尾推回不确定性**——不给"通过/不通过"结论，给 2-3 个需要策划自己回答的问题
6. **与 game-review 不冲突**——智囊团帮思考，game-review 做终检。如果策划说"这个方案要提交审核了"，建议他先走完智囊团讨论，再提交 game-review

### 模型分级策略

| 模型级别 | 可用深度 | 建议用法 |
|----------|---------|---------|
| **高级模型** | 完整六智囊讨论 + 交叉补充 + 结构化汇总 | 正式自检、审核准备 |
| **中级模型** | 逐个智囊独立提问 | 日常打磨 |
| **轻量模型** | 单智囊聚焦模式 | 针对某个维度的专项检查 |

单智囊聚焦用法：
```
"目标感守护者帮我看看"
"公平感审计师审视一下分层"
"生态观察者看看二阶效应"
```

## Common Mistakes

| 错误 | 表现 | 纠正 |
|------|------|------|
| 把讨论当答案 | "智囊团说没问题" | 智囊团提供视角，判断是你的事 |
| 只听一个智囊 | 只关注循环设计忽略公平感 | 六个维度互相关联——循环再好，不公平就完蛋 |
| 用科学当挡箭牌 | "认知科学验证过了" | 科学解释机制，不能替代"好不好玩"的直觉 |
| 概念阶段就讨论经济细节 | 核心循环没定就算通胀 | 先定循环和目标，再谈经济和生态 |

## 与现有体系的关系

| 工具 | 定位 | 使用时机 |
|------|------|---------|
| **本智囊团** | 策划的思考伙伴 | 设计过程中随时自检 |
| **game-review** | 制作人的审核工具 | 方案提交正式审核时 |
| **boss-design-council** | Boss 表演专用智囊团 | Boss 加分表演设计时 |
| **game-craft** | 方案生成流水线 | 从零生成策划案时 |

```
设计过程中 → game-design-council 随时自检
Boss 表演 → boss-design-council 专项自检
方案完成 → game-review 正式审核
从零开始 → game-craft 生成 → 本智囊团自检 → game-review 终审
```

## 认知科学速查（智囊团内部参考）

| 智囊 | 底层机制 | 一句话 |
|------|---------|--------|
| 目标感守护者 | 目标梯度效应、认知评估一致性维度、心流-清晰目标 | 目标不清 = 动力消失，目标不分层 = 意义感断裂 |
| 循环诊断师 | 认知负荷三分类、系统 1/2 交替、PREE、心流通道 | 好循环 = 压力和释放交替 + 每次有微变化 |
| 公平感审计师 | 损失厌恶 2x、归因理论、杏仁核快通道 | 不公平的记忆比爽感的记忆持久得多 |
| 惊喜工程师 | PEL 预测误差、可变比率强化、Near-miss、习得性无助 | 可预测 = 安全但无聊，全随机 = 刺激但无意义 |
| 生态观察者 | 二阶效应、沉没成本、IKEA 效应、损失厌恶 | 直接效果看得见，连锁反应才真正危险 |
| 首次体验官 | 工作记忆 4±1、杏仁核首次印记、渐进披露、10 秒理解 | 前 5 分钟的权重 > 后面 5 小时 |

# Boss 预审自检表 · Agent 工作指引

## 1. 适用范围与立场

- **对象**：游戏中 Boss 被击败后的**加分表演**（结构化表演，常含 Loop / Heavy / Super 等段落；随机性是玩法魅力之一）。
- **主覆盖路线**：**视觉表演型**（配战魂为主）；互动玩法型仅有部分原则通用，需额外补充。
- **受众滤镜**：中年男性、下沉市场——要直觉冲击与「想要」的占有冲动，而非小清新式欣赏距离。
- **调性基准线**：视觉重量偏 **「传奇」不「仙剑」**，从原画设定阶段即锚定；路线可以很宽（爽/燃等），但底层不能轻飘。
- **三道门顺序**：①概念门 → ②结构门（纸面）→ ③制作门（视频 demo）。**不得跳门**；后一门默认不重复争论前一门已锁定事项（制作门只谈执行质量）。

**权威全文**（题目级细节、交付物表格、附录 Prompt）：仓库根目录 `Boss预审_背景与需求.md`、`Boss预审_1概念门.md`、`Boss预审_2结构门.md`、`Boss预审_3制作门.md`。

## 2. 核心设计原则（Agent 必须遵守）

| 原则 | 含义 | Agent 用法 |
|------|------|------------|
| **答案即证据** | 自检表是填空题不是判断题 | 不采信空洞「是/不过」；要求**可检查的具体内容**（句、图、时间点、画面描述） |
| **改结构不加特效** | 向后读、分支不可读是**结构问题** | 预审意见里若涉及「向前读/分支三阶段」，禁止用「加更多特效」当唯一解法 |
| **纸面优先** | 结构问题必须在结构门暴露 | 制作门不应用来「首次」讨论流程与分支是否合理 |
| **着急 > 拖沓（风险）** | 两种节奏失败都糟，但「着急」更隐蔽 | 节奏相关建议优先保证**认知参与时间**；宁稍慢勿跟不上 |
| **一次只讲一件事** | 限制的是**并发**，不是密度 | 同屏多焦点 = 不过；可快速串行，不可多线抢注意力 |

## 3. 概念索引（跨门共用语言）

| 概念 | 一句话 |
|------|--------|
| **向前读 vs 向后读** | 合格：事发前画面已让玩家产生预期；不合格：结果先跳出再靠理智理解——情绪窗口已过 |
| **认知参与窗口** | 让玩家上车并在车上；拖沓 = 走神，着急 = 看客，后者危害常被低估 |
| **信号 → 赌注 → 揭晓** | 分支可读的三段；缺任一段则悬念价值归零 |
| **逼近 → 定帧 → 余韵** | 关键时刻的三层时间结构；全程匀速 = 放弃时间操控 |
| **调性锚点图** | 2–3 张参考，证明「与目标重量级同场」；用于压「轻飘/小清新」 |
| **情绪曲线后验** | B 区设计意图曲线 vs C 区观感曲线对比；**可替代原「AI 盲解读」作执行诊断**（以项目当前流程为准） |

## 4. ① 概念门 — 审核标准与自检要点

### 4.1 五条标准（须全过才能进结构门）

1. **调性重量**：放传奇类广告素材堆里不违和；重「厉害/值钱/想要」，拒文艺清新淡雅「高级感」优先。美女题：要「想占有」而非「想欣赏」。
2. **情绪概念冲击**：核心一句话让目标用户在约 **3 秒内**有「想看/想打/想要」的冲动；拼的是概念浓度不是文案技巧。
3. **拥有欲 + 一致性**：缩略图级有辨识度与冲击；Boss 与战魂（若有）视觉关联清晰；表演能当「试用广告」。
4. **玩法新鲜感**：相对已有 Boss，能说清**这次不同在哪**（常见：新节奏型 / 新悬念揭晓 / 新视觉感受；新机制为加分项）。
5. **视觉新鲜度**：至少一个具体的新镜头/瞬间/手法，非「管线复用无新尝试」。

### 4.2 交付物核对（快速）

核心概念一句话、调性锚点图 2–3、情绪板 ≥5、玩法期待度说明、视觉新鲜点——缺一则概念门材料不完整。

### 4.3 自检表 A1–A9 的 Agent 用法

- 引导对方用**具体名词与画面**填：谁、什么情绪、锚点图与自设计是否同场、轻情绪角色如何切入「重」、与已有 Boss 差异、美术新尝试、仅看表演是否想拥有。
- **红灯信号**：只能答「换了皮/角色帅」、锚点图违和、情绪词偏轻且无拉重策略、新鲜点描述无法让人脑补画面。

## 5. ② 结构门（纸面）— 审核标准与自检要点

### 5.1 四条标准（须全过才能进制作门）

1. **叙事可读性**：每段「一句话叙事」有画面、主体、情绪；整条线为**向前读**；禁止「发生了→才知道」贯穿。
2. **蓄力-释放**：情绪曲线可标蓄力/释放；每段至少一对；蓄力与释放阶段各聚焦一件事；**留足反应时间**优先于「怕拖」。
3. **分支可读性**：每个分支能写全 **信号 / 赌注 / 揭晓**；信号须来自**画面叙事**，非硬塞 UI 字。
4. **段间递进**：Loop 与 Super 并排要有**心理质变**，非仅「更大更响」。

### 5.2 交付物核对

结算流程图、逐段一句话叙事、段落情绪曲线、分支三阶段标注、计分节奏说明。

### 5.3 自检表 B1–B6 的 Agent 用法

- B3/B4 是「向前读」与分支的主战场：逐事件写**画面上**可见的前置信号；逐分支写三阶段。
- **红灯信号**：一句话叙事像「角色在表演」、标不出蓄力、分支直接揭晓、多焦点堆叠、Loop 与 Super 仅强度差无质变。

## 6. ③ 制作门（视频）— 审核标准与自检要点

### 6.1 门槛结构

- **硬门槛**：① 蓄力-释放执行 + **时间操控**（不过即打回）。
- **软门槛**：②–⑤ 允许 **最多一条**不过，须标「已知风险」+ 弥补方案。

### 6.2 五条标准摘要

1. **① 蓄力-释放 + 时间操控**：峰值须有专属时间待遇；对照 **逼近→定帧→余韵**；Loop 多次观看不拖沓、不机械重复过重。
2. **② 计分与情绪绑定**：分数与画面「最炸」点同频；可引用延迟交付、非线性数值等手法。
3. **③ 镜头叙事**：镜头在表意，非摆拍；可引用注意力闭环等。
4. **④ 段间递进执行**：体感到位，含规模/镜头/分数/状态/时间操控升级。
5. **⑤ 「那个瞬间」**：Heavy/Super 各有至少一帧高光，且高光有**专属时间待遇**（非匀速路过）。

### 6.3 标杆手法库（六个名字，便于 Agent 点名）

延迟交付、注意力闭环、跨模态同步、微变化续命、物理化隐喻、非线性数值表现。

### 6.4 时间操控词汇表（六个手法）

加速(Ramp Up)、子弹时间、硬定格、减速(Ramp Down)、余韵(Breath)、骤停(Hard Cut)。

### 6.5 自检表 C1–C4 与盲解读

- C1–C2 要求指出高光帧及每释放点的逼近/定帧/余韵。
- C3 用「旁观者」或 AI 反馈：**反应不过来**比「略拖」更严重。
- **附录盲解读 Prompt**：见 `Boss预审_3制作门.md` 附录；审核者对照段落拆分、节奏、焦点、分支感知来打枪。

## 7. Agent 输出建议格式

按用户要求选用下列一种或组合：

### 7.1 预审结论卡（短）

```text
【门别】概念门 / 结构门 / 制作门
【结论】通过 / 补材料后再审 / 不通过
【硬伤 Top3】（每条：对应标准编号 + 现象 + 建议方向，禁止空泛）
【需补充的交付物】（逐条列出）
```

### 7.2 对照自检表的缺口表

逐题（A1–A9 / B1–B6 / C1–C4）标注：**已满足 / 缺口 / 风险**；缺口处给**可写进表里的例句级建议**（仍由人类最终填写）。

### 7.3 修订优先级

1. 触达「答案即证据」仍答不出 → 概念或结构未想清楚。  
2. 向前读、分支三阶段、一次一件事 → 优先于单点特效。  
3. 制作门：时间操控与高光帧待遇 → 优先于平均加料。

## 9. 常见误判纠正

| 团队常见辩解 | 标准回应 |
|--------------|----------|
| 「再加特效就看清了」 | 向后读是结构问题，加特效不改正阅读方向 |
| 「信息多才算丰富」 | 一次多焦点 = 信息落地失败 |
| 「怕拖所以切快」 | 着急更伤参与；先保证反应时间再谈压缩 |
| 「结构差不多就行先做视频」 | 违背纸面门；改视频成本与心理成本更高 |

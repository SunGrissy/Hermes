**问题：** 今天 OpenClaw Gateway 多次出现连接、鉴权、重启问题，需要多次人工干预。

**多层原因：**
- **L1 直接原因：** tuyoo API key 无效 / 环境变量未传递，导致模型调用 401
- **L2 系统原因：** Gateway 进程无监控、无自动重启机制，挂了只能靠人工发现

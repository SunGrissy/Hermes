### 关于 kimi-k2.6 模型特性
- kimi-k2.6 通过 Tuyoo relay 调用时，是纯 reasoning 模型
- API 响应：`content=null`，答案仅出现在 `reasoning` 字段
- 即使设置了 `reasoning: True`，模型自身仍然返回 content=null
- Hermes 的推理模式应该能从 reasoning 字段提取答案
- 如果仍不生效，可能需要确认 Hermes 版本是否支持 reasoning 模式

## 发消息操作规范

```
POST http://127.0.0.1:19200/send
Content-Type: application/json

{"cid": "46459012:300405507", "message": "这里是消息内容 🤖"}
```

### 关键规则
1. **末尾加 🤖** — 所有发给人类同事的钉钉私聊消息末尾必须加 ` 🤖`（空格+🤖），让对方知道是机器人代发，避免误会
2. **用 Python 发送** — 通过 Python 的 `urllib` 或 `requests` 发送 POST 请求，确保 UTF-8 编码正确，不要用 PowerShell curl（emoji会乱码）
3. **不支持 emoji 的 curl/powershell 替代方案**：使用 `py -c "..."` 内联 Python 代码来发送

4. 新增成员时更新此表，所有 Agent 自动生效

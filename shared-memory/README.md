# 动态记忆汇聚中心

## 作用
汇集 Hermes（助理小橘）、OpenClaw（保安大虾）、Cursor 三方产生的动态记忆，提取值得长期保留的内容。

## 汇聚规则

| 项目 | 说明 |
|------|------|
| **频率** | 每日凌晨 2:00 |
| **执行者** | Hermes（助理小橘） |
| **输入源** | Hermes memories、OpenClaw memories |
| **输出** | hub/YYYY-MM-DD.md + knowledge/ + pending-upgrade/ |

## 目录说明

| 目录 | 内容 | 生命周期 |
|------|------|---------|
| `hub/` | 每日汇聚的原始记忆 | 按日期归档，保留 30 天 |
| `knowledge/` | 提取后的共享环境知识 | 长期有效，随时更新 |
| `pending-upgrade/` | 待审核的身份升级提议 | 用户审核后移除或升级 |

## 升级判定标准

一条记忆满足以下任一条件，即进入 `pending-upgrade/` 等待审核：

1. 同一内容在 7 天内出现 2 次以上
2. 影响工作流或决策模式
3. 属于环境/工具/路径等可复用信息

## 流程

```
各自 Memory DB
    ↓
Hermes 每日 2:00 读取
    ↓
过滤（删除一次性上下文）
    ↓
分类：环境知识 / 升级候选 / 普通记忆
    ↓
写入对应目录
    ↓
钉钉通知老大：汇聚报告 + 升级候选清单
```
